## Что такое FoundationX?

FoundationX это реализация responsive CSS-фреймворка Foundation от Zurb для MODX.

Пользователи с минимальными знаниями HTML и CSS могут за минуты настроить современный responsive-сайт: зарегистрируйтесь в MODX Cloud и установите Snapshot FoundationX.

Живое демо: <http://www.foundationx.net/>

## Требования

FoundationX доступен только как Snapshot в MODX Cloud. Если аккаунта MODX Cloud ещё нет, зарегистрируйтесь [здесь](https://modxcloud.com/signup/?ref=foundationx).

## История

FoundationX создан в 2012 году YJ Tso (@sepiariver) как настраиваемая «Super-Theme» для MODX Cloud.

## Установка

В панели MODX Cloud откройте «Marketplace» в главном меню. Выберите публичный Snapshot FoundationX. Нажмите «Inject Into Cloud». Если облако для установки ещё не создано, следуйте [документации](https://modxcloud.com/userguide/using-modx-cloud/clouds/create-cloud.html). В окне «Inject into Cloud» выберите облако для перезаписи и нажмите «Inject Into Cloud».

**Snapshot FoundationX перезапишет ваше облако**
Убедитесь, что в выбранном облаке нет данных, которые нужно сохранить. Если сомневаетесь, сначала сделайте резервную копию. Как создать backup, см. [здесь](https://modxcloud.com/userguide/using-modx-cloud/backups/create-a-new-backup.html). В MODX Cloud это один клик.

После успешной инъекции Snapshot вы получите уведомление. Откройте страницу редактирования этого облака и в правой панели нажмите Create Admin User. Введите имя пользователя, пароль и email, затем «Create Admin User». По завершении придёт ещё одно уведомление. После этого войдите в менеджер MODX с созданными учётными данными.
