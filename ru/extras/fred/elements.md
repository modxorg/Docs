Fred Elements это базовые блоки, из которых конечные пользователи собирают контент. Element может быть простым заголовком или абзацем, а может быть сложным блоком вроде hero с настраиваемым фоном, отступами текста, прозрачностью и т.д.

## Организация

Elements группируют по категориям, чтобы редакторам было проще находить нужные блоки. Например, тема может содержать такие категории Elements:

-   Page Intros
-   Feature Sections
-   Quotes
-   Code Blocks
-   Galleries
