При первой установке Fred добавляет политику `Fred Admin` во все контексты для группы `Administrators`. Участники с ролью `Super User` получают полный доступ к Fred в Manager и во всех фронтенд-контекстах.

Также создаётся более ограниченная политика `Fred Editor` для пользователей, которым не нужна настройка Fred. Настройка Fred включает создание Elements, Option Sets и другие админ-функции.

## Ограничение Fred отдельными контекстами

По умолчанию политика `Fred Admin` действует во всех существующих контекстах. Если не все контексты нужно вести через Fred, удалите эту политику у группы `Administrators`. Для нового контекста с Fred добавьте политику группе `Administrators` после создания контекста.

Чтобы включить Fred для участников вне группы `Administrators`, добавьте политику Fred их группе и нужным контекстам.

## Доступ к Manager и фронтенду

Веб-разработчики и авторы тем настраивают Fred Extra в Manager и создают темы. После запуска сайта ежедневное редактирование через Fred может обходиться без Manager.

Если пользователи должны работать только с Fred на фронтенде, сделайте два шага:

1. Установите [Login Extra](https://modx.com/extras/package/login) для входа авторов и редакторов с фронтенда.
2. Назначьте одну из политик Fred контексту `web` или другим контекстам.

## Создание кастомных политик Fred

Встроенных политик Fred может не хватить. Создать свои политики несложно.

1. В Manager откройте меню ACLs под иконкой шестерёнки справа вверху.
2. Перейдите на вкладку Access Policies.
3. Нажмите `Create Access Policy`, задайте имя и выберите шаблон `Fred`. В нём все возможные [права](extras/fred/site_admin/acls/permissions) для настройки доступа.
4. После сохранения политика появится в таблице. Правый клик и `Update Policy`.
5. Включите или снимите [права](extras/fred/site_admin/acls/permissions), которые нужно запретить пользователям.
