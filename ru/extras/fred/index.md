## Что такое Fred?

Fred это визуальный drag-and-drop **редактор фронтенда** для [MODX CMS](https://modx.com). Он позволяет обычным пользователям создавать качественный контент без знания кода и без сложных интерфейсов.

Вы создаёте контент в Fred, перетаскивая Elements из боковой панели туда, где они должны появиться. Выберите текст для правки или кликните по изображению, отредактируйте прямо в браузере и нажмите зелёную галочку, чтобы сохранить изменения.

### Что Fred даёт разработчикам и билдерам сайтов?

Fred помогает авторам тем выходить в экосистему MODX. Перенести существующую тему в Fred и экспортировать её для [MODX Extras](https://modx.com/extras/) несложно.

Для действующих разработчиков MODX Fred даёт способ делать интерфейс для владельцев сайта гибче и понятнее. С Fred можно реализовать макеты, для которых иначе понадобились бы десятки TV, сложный UI менеджера или кастомизация Manager.

Fred даёт редакторам контента привычные визуальные элементы: слайдеры, переключатели, выбор цвета. Эти элементы могут передавать параметры в сниппеты MODX и его API, что даёт надёжное и мощное решение для создания контента.

Коротко: Fred упрощает сборку сложных страниц даже для самых нетехнических пользователей.

### Чем Fred отличается от других визуальных конструкторов?

Fred следует главному принципу MODX: Creative Freedom. Он не заставляет вас использовать чужой фронтенд-фреймворк или чужой подход к вёрстке. Если вы можете представить или прототипировать макет, Fred его поддержит без компромиссов.

Разработчики и дизайнеры могут добиться pixel-perfect сайтов и спокойно передать создание контента, не боясь, что всё сломается.

Неважно, собран ли сайт из бесплатной стартовой темы или с нуля на 100%: Fred помогает всем строить сайты быстрее, стабильнее и с лучшим результатом.

### Что ещё умеет Fred?

Ниже пример возможностей Fred как платформы визуального создания контента:

-   Превращение статических Design Libraries в живой инструмент создания контента с соблюдением бренд-стандартов, понятный нетехническим участникам команды
-   Опциональная условная и циклическая логика шаблонов Twig для мощных Elements, ограниченных только вашей фантазией
-   Создание и организация коллекций Elements как строительных блоков страниц
-   Blueprints как шаблоны целых или частичных страниц с подстановкой вместо плейсхолдеров
-   Несколько dropzone для полного контроля макета каждой страницы
-   Настройка контента через переключатели, текстовые поля, выбор даты, select, слайдеры, выбор ресурсов и цветовые палитры
-   Поддержка сниппетов MODX с live Ajax-рендерингом изменений
-   Визуальный выбор иконок Font Awesome 5. Разработчики могут добавить и другие icon picker
-   Простое форматирование контента через TinyMCE по умолчанию
-   Перестановка и изменение порядка контента страницы drag-and-drop
-   Быстрое дублирование Elements для галерей и слайдеров
-   Контент Fred рендерится в кешируемый вывод для высокой скорости страниц
-   Готовый набор Elements Bootstrap 4, чтобы авторам тем быстрее начать работу
