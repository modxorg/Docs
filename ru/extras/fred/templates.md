Fred загружается только на страницах, чьи шаблоны MODX привязаны к теме Fred. В Manager это видно в меню `Extras` > `Fred`, вкладка `Themes`, раздел `Themed Templates` слева. Для страниц с шаблоном из этой таблицы область контента в Manager блокируется, а на фронтенде при входе для редактирования загружается Fred.

## Dropzones

В большинстве шаблонов есть dropzone _content_. Fred также поддерживает несколько dropzone для sidebar, header, footer и любых других зон. В dropzone вы перетаскиваете Elements и Blueprints из боковой панели Fred.
