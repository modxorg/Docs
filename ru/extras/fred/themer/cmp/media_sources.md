Как в MODX Manager, Media Sources помогают авторам тем организовать загрузки для сайтов на Fred. Разные Elements с загрузкой изображений могут сохранять файлы в разные места, например статьи, каталог или фото команды.

![Media Sources in Fred](img/media-sources.png)

При редактировании Media Source автор тем явно включает доступ Fred через переключатель `fred`. Опционально источник делают read-only для Fred через `fredReadOnly`.

![Update a Media Source](img/update-media-source.png)

Подробнее см. [документацию MODX Media Source](https://docs.modx.com/revolution/2.x/administering-your-site/media-sources).
