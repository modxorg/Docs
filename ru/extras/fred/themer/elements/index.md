Elements это строительные блоки и паттерны дизайна для сайтов и тем. Обычно Element включает HTML markup и набор элементов управления («[Settings](extras/fred/themer/options)») с иконки шестерёнки на фронтенде. В markup можно использовать Twig, чтобы показывать или скрывать части страницы по условиям из Settings.
