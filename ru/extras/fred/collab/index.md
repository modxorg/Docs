Совместная работа над темами помогает собрать надёжное решение для публикации в MODX Extras. Команда может разделить роли:

-   Front-end разработчики работают только с разметкой
-   Поддержка или project manager настраивают логичные и простые Option Sets
-   Владелец продукта готовит скриншоты, конфигурации по умолчанию, README и CHANGELOG
-   Разработчики пишут кастомный код под нужный функционал

## Простой способ

Проще всего пригласить группу людей на сайт и дать им работать. Когда результат вас устраивает, [экспортируйте тему](extras/fred/themer/cmp/themes) и на этом всё.

## «Правильный» способ

Если над темой работает команда, хранить компоненты в Git-репозитории удобно для совместной разработки. Работа версионируется, и случайная перезапись чужих правок перестаёт быть проблемой.

Остальная часть раздела описывает, как это делать с Gitify.
