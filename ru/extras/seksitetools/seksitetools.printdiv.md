## Что такое printdiv?

Printdiv копирует содержимое указанного div во всплывающее окно, открывает диалог печати «версии для принтера». После отправки на принтер окно закроется автоматически.

## Использование

Пример для printdiv:

``` php
[[printdiv? &divID=`test` &linkText=`link`]]
<div id="test">test data</div>
```

Можно задать ширину и высоту всплывающего окна:

``` php
[[printdiv? &divID=`test` &linkText=`link` &width=`200` &height=`300`]]
<div id="test">test data</div>
```

Дополнительные опции см. в свойствах сниппета.

## Свойства

| ----------- | ------------------------------------------------------------------------------------------- | ----------- | -------- | ------- |

| linkText    | Текст ссылки на «принтерную» версию.                       |             | Yes      | >0.0.1  |
| tplPrintDiv | Шаблон ссылки на всплывающее окно                                      | printdiv    |          | >0.0.1  |
| tplJs       | Шаблон с JavaScript, который создаёт окно и запускает печать. | printdiv.js |          | >0.0.1  |
| width       | Ширина всплывающего окна.                                                                 | 100         |          | >0.0.1  |
| height      | Высота всплывающего окна.                                                                | 100         |          | >0.0.1  |
| cssFile     | Путь к CSS-файлу.                                                |             |          | >0.0.1  |
