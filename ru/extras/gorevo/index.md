## Что такое GoRevo?

GoRevo это коммерческий extra для интеллектуальной миграции сайтов MODX Evolution в MODX Revolution.

### Возможности

**Переносит:**

- Manager Users
- Web Users
- Resources
- Chunks
- Templates
- Template Variables
- Resource Groups
- Categories
- Выбранные System Settings
- Custom Snippets
- Custom Plugins
- Выбранные файлы и/или каталоги

GoRevo пытается конвертировать теги Ditto, Breadcrumbs, WebLogin, WebLoginPE и PHX для Revolution. Теги Wayfinder обычно работают как есть. GoRevo также пытается воспроизвести User Groups, учётные данные входа и Resource Groups с Evolution-сайта.

Подробнее о GoRevo: [Bob's Guides](https://bobsguides.com/why-choose-gorevo.html).

## История

- Автор: Bob Ray [Bob's Guides](https://bobsguides.com)

Разработка GoRevo заняла около шести месяцев. Extra использовали для конвертации многих Evolution-сайтов в MODX Revolution, в том числе конвертаций от MODX LLC.

Эту версию extra GoRevo разработал Bob Ray в 2014 году. На 22 июня 2017 года последнее обновление было 21 декабря 2017 года, 190 коммитов, 61 загрузка. Пакет GoRevo состоит из 1 563 файлов и 32 211 строк кода.

Сейчас проект поддерживает Bob Ray.
