FirstChildRedirect это сниппет, который редиректит ресурс на его первого потомка. Есть версии для Revolution и Evolution. В Revolution настраивать проще.

## Установка и баги

FirstChildRedirect ставят через Package Manager MODX Revolution или вручную: скачайте пакет с сайта MODX Extras, загрузите в `core/packages` и добавьте через Package Manager из локального поиска.

Для MODX Evolution пакет тоже есть, но не все параметры ниже поддерживаются.

## Использование сниппета

Вызовите сниппет uncached в контенте или шаблоне контейнера, который нужно редиректить на первого потомка.

``` php
[[!FirstChildRedirect]]
```

Можно задать один или несколько параметров, которые влияют на редирект.

| Parameter     | Evo/Revo | Details                                                                                                                                                                                                                                                                                                                                                                                                                                        | Default                            |
| ------------- | -------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------- |
| &docid        | Yes/Yes  | ID другого ресурса: сниппет возьмёт его как контейнер и найдёт первого потомка.                                                                                                                                                                                                                                                                                                 | current resource ID (ie `[[*id]]`) |
| &default      | No\*/Yes | Куда редиректить, если потомков нет. ID ресурса или одно из: site\_start, site\_unavailable\_page, error\_page, unauthorized\_page. \* В Evolution по умолчанию тоже site\_start. При необходимости правьте код сниппета: найдите `$modx->config\['site\_start'\]` и замените на ID или системную настройку. | site\_start setting                |
| &sortBy       | No/Yes   | Любое поле ресурса для сортировки потомков.                                                                                                                                                                                                                                                                                                                                                                                    | menuindex setting                  |
| &sortDir      | No/Yes   | `desc` (на наибольший menuindex или поле &sortBy) или `asc` (на наименьший).                                                                                                                                                                                                                                                                            | "asc"                              |
| &responseCode | No/Yes   | Код ответа редиректа. По умолчанию 301 (`HTTP/1.1 301 Moved Permanently`). Есть shortcut для 302. Можно указать полный response code. _Добавлено в 2.3.1._                                                                                                                                                            | 301                                |

`&sortBy=`RAND()`` в 2.1.3 вроде работает :)

Удобно, например, для A/B Split Testing.
