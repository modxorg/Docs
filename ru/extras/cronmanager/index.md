## CronManager

Создавайте и запускайте cron-задачи через менеджер.

### Возможности

CronManager для MODX запускает сниппеты по crontab сервера. В менеджере MODX Revolution вы просто добавляете сниппеты в список cron.

Для cron через сниппеты нужны свойства. Их можно задать вручную парами ключ-значение или через property set (имя).

Управление пакетами MODX

### Использование

Установите через менеджер пакетов.
