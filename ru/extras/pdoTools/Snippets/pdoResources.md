Сниппет для вывода списка ресурсов. Продвинутая замена getResources: все возможности без его недостатков.

Умеет корректно сортировать TV, подключать таблицы к выборке, включать или исключать категории из разных контекстов и многое другое.

## Свойства

### Параметры выбора ресурсов

Эти параметры определяют, какие ресурсы попадут в список.

| Name                       | Default                                       | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| -------------------------- | --------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **&parents**               | Current resource                              | Список родителей для поиска результатов через запятую. 0 для без ограничений, +0 для верхнего уровня. Если id родителя начинается с минуса, он и его потомки исключаются из запроса.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| **&depth**                 | 10                                            | Глубина поиска дочерних ресурсов от родителя в дереве ресурсов.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| **&resources**             |                                               | Список ресурсов для добавления в результаты через запятую. Если id ресурса начинается с минуса, ресурс исключается из запроса.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| **&context**               |                                               | Ограничить ресурсы указанным контекстом.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| **&where**                 |                                               | Дополнительный массив параметров выборки в JSON.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| **&showHidden**            | 1                                             | Показывать ресурсы, скрытые в меню.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| **&showUnpublished**       | 0                                             | Показывать неопубликованные ресурсы.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| **&showDeleted**           | 0                                             | Показывать ресурсы, помеченные как удалённые.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| **&hideContainers**        | 0                                             | Исключить контейнерные ресурсы, то есть ресурсы с «isfolder = 1».                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| **&select**                | 0                                             | Список полей для выборки через запятую. | **&last**                  | Automatic, by the formula (total + first - 1) | Номер последнего элемента в результатах.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| **&loadModels**            |                                               | Список компонентов, модели которых нужно загрузить для построения запроса, через запятую. ### Свойства шаблонов

Эти параметры задают чанки с шаблонами форматирования вывода.

| Name                 | Description                                                                                                                                                                                                                                                                  |
| -------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **&returnIds**       | «1» вернёт строку со списком id ресурсов вместо полных результатов. Все шаблоны игнорируются.                                                                                                                                                    |
| **&tpl**             | Имя чанка для форматирования отдельных элементов. Если не указано, на экран выводятся поля ресурса.                                                                                                                                         |
| **&tplFirst**        | Имя чанка для первого элемента в результатах.                                                                                                                                                                                                                   |
| **&tplLast**         | Имя чанка для последнего элемента в результатах.                                                                                                                                                                                                                    |
| **&tplOdd**          | Имя чанка для каждого нечётного элемента в результатах.                                                                                                                                                                                                          |
| **&tplWrapper**      | Чанк-обёртка для всех результатов. Один плейсхолдер: `[[+output]]`. Не работает вместе с **&toSeparatePlaceholders**.                                                                                                                               |
| **&wrapIfEmpty**     | Выводить внешнюю обёртку **&tplWrapper**, даже если результатов нет.                                                                                                                                                                                                    |
| **&tplCondition**    | Поле ресурса для сравнения с ключами из **&conditionalTpls**.                                                                                                                                                                       |
| **&tplOperator**     | Необязательный оператор сравнения поля **&tplCondition** с массивом значений и чанков в **&conditionalTpls**.                                                                                                                                         |
| **&conditionalTpls** | JSON-объект: ключи это значения поля из **&tplCondition**, значения это tpl-чанки при совпадении. Оператор сравнения задаётся в **&tplOperator**. Для операторов вроде *isempty* массив ключей не нужен. |
| **&outputSeparator** | Необязательная строка-разделитель результатов.                                                                                                                                                                                                                                     |

## Примеры

Простой список дочерних ресурсов #1:

```php
[[pdoResources?
    &parents=`1`
    &depth=`0`
    &tpl=`ListRowTpl`
]]
```

Чтобы добавить TV «image», вызов такой:

```php
[[pdoResources?
    &parents=`1`
    &depth=`0`
    &tpl=`ListRowTpl`
    &includeTVs=`image`
]]
```

В чанке **ListRowTpl** теперь доступен плейсхолдер `[[+tv.image]]`.
