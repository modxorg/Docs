Сниппет pdoNeighbors выводит предыдущий и следующий ресурсы.

Может показать несколько соседей сразу, проверить их статус (неопубликован, опубликован) и задать сортировку.

Можно выводить предыдущий / следующий ресурс по «menuindex», дате публикации или другому полю ресурса.

## Параметры

Принимает все параметры [pdoTools](extras/pdoTools/General_settings) (кроме шаблонов чанков) и некоторые свои:

| Parameter          | Default              | Description                                                                                                                                                                    |
| ------------------ | -------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **&id**            | The current document | Id ресурса, для которого показываются соседи.                                                                                                                         |
| **&tplPrev**       | see below            | Чанк ссылки на предыдущий документ.                                                                                                                                      |
| **&tplUp**         | see below            | Чанк ссылки на родительский документ.                                                                                                                                        |
| **&tplNext**       | see below            | Чанк ссылки на следующий документ.                                                                                                                                     |
| **&tplWrapper**    | see below            | Чанк-обёртка для результатов. Плейсхолдеры: `[[+left]]`, `[[+top]]`, `[[+right]]` и `[[+log]]`. Не работает вместе с **&toSeparatePlaceholders**. |
| **&toPlaceholder** |                      | Если не пусто, сниппет сохранит все данные в указанный плейсхолдер вместо вывода при вызове.                                             |
| **&showLog**       | 0                    | Показывает лог работы сниппета. Только в контексте «mgr» для авторизованных.                                                                                                  |
| **&loop**          | 1                    | 0/1: скрыть/показать соседей первой/последней записи на краю списка                                                                                                               |

### Чанки шаблонов

| Template        | Default                                                                                |
| --------------- | -------------------------------------------------------------------------------------- |
| **&tplPrev**    | `@INLINE <span class="link-prev"><a href="/[[+uri]]">&larr; [[+menutitle]]</a></span>` |
| **&tplUp**      | `@INLINE <span class="link-up">&uarr; <a href="/[[+uri]]">[[+menutitle]]</a></span>`   |
| **&tplNext**    | `@INLINE <span class="link-next"><a href="/[[+uri]]">[[+menutitle]] &rarr;</a></span>` |
| **&tplWrapper** | `@INLINE <div class="neighbors">[[+prev]][[+up]][[+next]]</div>`                       |

## Примеры

По умолчанию сниппет показывает соседей как в дереве ресурсов, то есть по «menuindex»:

```php
[[pdoNeighbors]]
```

По умолчанию соседи выбираются от текущего документа, но можно указать другой id:

```php
[[pdoNeighbors?
    &id=`55`
]]
```

Сниппет удобен для ссылок на соседние новости (лучше сортировать по дате публикации):

```php
[[pdoNeighbors?
    &sortby=`publishedon`
    &sortdir=`asc`
]]
```
