Сниппет объединяет функциональность [getResourceField](extras/getresourcefield) и [UltimateParent][2]: выводит любое поле указанного ресурса или его родителя, включая значения TV.

В отличие от аналогов работает с документами в любом контексте и позволяет задавать дополнительные параметры при вызове, чтобы выводить ресурсы, которые обычно скрыты, например скрытые ресурсы. Через параметр **&class** можно получить поле любого объекта MODX. Можно вызывать как [Output Modifier] [3].

## Свойства

Принимает [общие свойства и параметры выборки результатов](extras/pdoTools/General_settings) pdoTools и некоторые свои:

| Property           | Default          | Description                                                                                                                      |
| ------------------ | ---------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| **&id**            | Current resource | Id ресурса.                                                                                                                     |
| **&field**         | pagetitle        | Поле ресурса.                                                                                                                  |
| **&top**           |                  | Выбирает родителя верхнего уровня указанного ресурса.                                                                         |
| **&topLevel**      |                  | Выбирает родителя ресурса на этом уровне от корня.                                                                 |
| **&default**       |                  | Поле ресурса, которое вернуть, если **&field** пусто. Быстрее, чем output filter *:default =*               |
| **&output**        |                  | Строка, которую вернуть, если пусты и **&default**, и **&field**.                                          |
| **&toPlaceholder** |                  | Если не пусто, сниппет сохранит значение поля в плейсхолдер с тем же именем вместо вывода на экран. |

*Если указать **&top** или **&topLevel**, но не **&context**, будет дополнительный запрос к БД для определения контекста.*

Не поддерживает работу с объектами чанков или сниппетов, так как возвращает только одно поле.

## Примеры

Сниппет можно использовать как Output Modifier:

```php
[[*id:pdofield=`longtitle`]]
```

Свойства можно указать в JSON-массиве. Например, выбор второго родителя ресурса и возврат его «longtitle»:

```php
[[*id:pdofield=`{"top":2,"field":"longtitle"}`]]
```

Но лучше обычный вызов сниппета: он быстрее и удобнее:

```php
[[pdoField?
    &id=`[[*id]]`
    &field=`longtitle`
    &top=`2`
]]
```
