Сниппет-генератор меню. Может заменить Wayfinder и даёт больше гибкости в параметрах.

Например, строит меню из нескольких родителей, показывая их вместе или отдельными ветками.

Даёт заметный прирост скорости, хотя только при первом просмотре страницы, если меню Wayfinder закэшировано.

Если вы не пользовались Wayfinder, прочитайте его документацию: pdoMenu переиспользует многие концепции и настройки Wayfinder. Документация [здесь][1], или скачайте ebook Wayfinder на 184 страницы [в этой теме][2].

### Свойства шаблонов

Эти параметры задают чанки с шаблонами частей генерируемого меню.

Как сказано выше, если вы не пользовались Wayfinder, хотя бы просмотрите его документацию перед своими чанками, хотя у pdoMenu чуть другая иерархия чанков.

Даже без документации обязательно включите `[[+wrapper]]` в чанки. Несмотря на имя, это плейсхолдер для содержимого обёртки (как `[[*content]]` в ресурсах). Он заменится содержимым подменю нижнего уровня. Без него часть меню или всё меню исчезнет без сообщения об ошибке.

| Name                    | Description                                                                                                                                                                                                                         |
| ----------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **&tplOuter**           | Чанк для всего блока меню. По умолчанию: `@INLINE <ul[[+classes]]>[[+wrapper]]</ul>`                                                                                                                                           |
| **&tpl**                | Чанк для каждого ресурса. Если не указано, на экран выводятся поля ресурса. По умолчанию: `@INLINE <li[[+classes]]><a href="[[+link]]" [[+attributes]]>[[+menutitle]]</a>[[+wrapper]]</li>` |
| **&tplParentRow**       | Чанк для контейнера с дочерними элементами.                                                                                                                                                                                             |
| **&tplParentRowHere**   | Чанк для текущего контейнера.                                                                                                                                                                                                   |
| **&tplHere**            | Чанк для текущего ресурса                                                                                                                                                                                                      |
| **&tplInner**           | Чанк-обёртка для секций подменю. Если пусто, используется **&tplOuter**                                                                                                                                                                 |
| **&tplInnerRow**        | Чанк для строк подменю.                                                                                                                                                                                                             |
| **&tplInnerHere**       | Чанк для текущего пункта подменю.                                                                                                                                                                                                     |
| **&tplParentRowActive** | Чанк для активной категории.                                                                                                                                                                                                          |
| **&tplCategoryFolder**  | Специальный чанк для категорий. Категории: isfolder = 1 и пустой шаблон или атрибут «rel = category». Для пунктов верхнего уровня без активной ссылки.                    |
| **&tplStart**           | Чанк для родительского ресурса при **&displayStart**. По умолчанию: `@INLINE <h2[[+classes]]>[[+menutitle]]</h2>[[+wrapper]]`                                                                                     |

### Свойства CSS-классов

Эти параметры задают значения плейсхолдеров `[[+classes]]` и `[[+classnames]]` для частей меню.

| Name              | Description                                                                                                    |
| ----------------- | -------------------------------------------------------------------------------------------------------------- |
| **&firstClass**   | Класс первого пункта меню. По умолчанию: **first**                                                              |
| **&lastClass**    | Класс последнего пункта. По умолчанию: **last**                                                                |
| **&hereClass**    | Класс активного пункта и его родителей. По умолчанию: **active**                                            |
| **&parentClass**  | Класс родительских пунктов.                                                                                        |
| **&rowClass**     | Класс каждой строки меню.                                                                                       |
| **&outerClass**   | Класс внешней обёртки.                                                                                       |
| **&innerClass**   | Класс внутренних обёрток подменю.                                                                              |
| **&levelClass**   | Класс каждого уровня меню. Например «level» даст «level1», «level2» и т. д. |
| **&selfClass**    | Класс текущего документа в меню.                                                                        |
| **&webLinkClass** | Класс для weblink-ресурсов.                                                                               |

## Примеры

Простое меню верхнего уровня:

```php
[[pdoMenu?
    &parents=`0`
    &level=`1`
]]
```

Двухуровневое меню с исключением родителей:

```php
[[pdoMenu?
    &parents=`-10,-15`
    &level=`2`
    &checkPermissions=`load,list,view`
]]
```

Меню из двух родителей с показом родителей:

```php
[[pdoMenu?
    &parents=`10,15`
    &displayStart=`1`
]]
```

Список всех ресурсов за один проход:

```php
[[pdoMenu?
    &parents=`0`
    &level=`2`
    &tplInner=`@INLINE [[+wrapper]]`
    &tplParentRow=`@INLINE <li[[+classes]]><a href="[[+link]]" [[+attributes]]>[[+menutitle]]</a> ([[+children]])</li>[[+wrapper]]`
    &countChildren=`1`
]]
```
