Общие параметры сниппетов на базе pdoTools / pdoFetch.

## Параметры выборки ресурсов

Эти параметры задают объекты выборки.

| Name                       | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            | По умолчанию                                       |
| -------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------ |
| **&class**                 | Класс выбираемого объекта                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              | modResource                                      |
| **&parents**               | Список родителей для поиска результатов через запятую. Если указать 0, выборка не ограничена. Если id родителя начинается с минуса, он и его потомки исключаются из выборки. Чтобы ограничить выборку по **&depth** от корня дерева ресурсов, используйте **&parents=`+0`**                                                                                                                                                                                                                                                                                                                                  | Текущий ресурс                                 |
| **&depth**                 | Глубина поиска дочерних ресурсов от родителя                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        | 10                                               |
| **&resources**             | Список ресурсов для поиска результатов через запятую. Если id ресурса начинается с минуса, этот ресурс исключается из выборки.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| **&templates**             | Список шаблонов для фильтрации результатов через запятую. Если id шаблона начинается с минуса, ресурсы с ним исключаются из выборки.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| **&context**               | Ограничение выборки по контексту ресурса                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| **&where**                 | Дополнительный массив параметров выборки в JSON                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| **&showHidden**            | Показывать ресурсы, скрытые в меню                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          | 0                                                |
| **&showUnpublished**       | Показывать неопубликованные ресурсы                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             | 0                                                |
| **&showDeleted**           | Показывать удалённые ресурсы                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 | 0                                                |
| **&hideContainers**        | Исключить контейнерные ресурсы, то есть ресурсы с «isfolder = 1».                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   | 0                                                |
| **&hideUnsearchable**      | Исключить ресурсы, скрытые от поиска                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| **&select**                | Список полей выборки через запятую. Можно указать JSON-массив, например **{"modResource":"id,pagetitle,content"}**.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| **&leftJoin**              | Аналог SQL left join                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| **&rightJoin**             | Аналог SQL right join                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| **&innerJoin**             | Аналог SQL inner join                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |

### Параметры шаблонов

Эти параметры настраивают чанки с шаблонами вывода, то есть меняются вместе с представлением.

| Name                 | Description                                                                                                                                                                                                                                                                                         |
| -------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **&tpl**             | Имя чанка для вывода ресурса. Если не указано, на экран выводится содержимое полей ресурса                                                                                                                                                                               |
| **&tplFirst**        | Имя чанка для первого ресурса в результатах                                                                                                                                                                                                                                                    |
| **&tplLast**         | Имя чанка для последнего ресурса в результатах                                                                                                                                                                                                                                                     |
| **&tplOdd**          | Имя чанка для каждого второго ресурса                                                                                                                                                                                                                                                                |
| **&tpl_N**           | Имя чанка для N-го ресурса, например **&tpl_4=`tpl4th`** задаст шаблон для 4-го ресурса                                                                                                                                                                                                           |
| **&tpl_nN**          | Имя чанка для каждого N-го ресурса, например **&tpl_n4=`tplEvery4th`** применится к каждому 4-му ресурсу                                                                                                                                                                                                    |
| **&tplCondition**    | Поле ресурса, из которого берётся значение для выбора чанка по условию в **&conditionalTpls**.                                                                                                                                                                                  |
| **&tplOperator**     | Необязательный оператор сравнения поля ресурса из **&tplCondition** с массивом значений и чанков в **&conditionalTpls**.                                                                                                                                                                    |
| **&conditionalTpls** | JSON-строка с массивом: ключи сравниваются с **&tplCondition**, значения это чанки для вывода при успешном сравнении. Оператор сравнения задаётся в **&tplOperator**. Для операторов «**isempty**» можно использовать массивы без ключей |
| **&outputSeparator** | Необязательная строка-разделитель результатов                                                                                                                                                                                                                                                         |

### Как вызывать чанки

Все чанки могут иметь один из этих префиксов:

* **@INLINE** или **@CODE**. Код после этого префикса используется как шаблон.

```php
[[!pdoResources?
    &tpl=`@INLINE <li>[[+pagetitle]]</li>`
]]
```

*Сниппеты, другие чанки и output filters нельзя указывать в INLINE-чанках: парсер MODX обработает их первым, и сниппет не получит то, что вы ожидали.*

* **@FILE**. Вместо чанка из БД используется содержимое файла. Путь к файлу задаётся системной настройкой **pdotools_elements_path**.
Имя файла с расширением `.tpl` или `.html`.

```php
[[!pdoResources?
    &tpl=`@FILE fileBasedRow.tpl`
]]
```

* **@TEMPLATE**. Указывается id или имя шаблона. Если пусто, для каждого ресурса используется его собственный шаблон.

```php
[[!pdoResources?
    &tpl=`@TEMPLATE 10`
]]
```

* **@CHUNK**. Аналогично указанию имени чанка.

```php
[[!pdoResources?
    &tpl=`@CHUNK tpl.Resource.row`
]]
[[!pdoResources?
    &tpl=`tpl.Resource.row`
]]
```
