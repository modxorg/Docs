## Информация

Главная идея pdoTools: скорость.

Первую версию pdoTools я сделал во время работы над **Tickets**. Задумывалась система тикетов, а в итоге получился простой блог с ajax-комментариями. Скорости популярных extras вроде getResources не хватало. Поэтому появилась своя библиотека. Сначала без сниппетов.

Две идеи:

1. Запрос к БД строится через xPDO, а выполняется через PDO. Без объектов для выбранных строк.
2. Быстрый разбор чанков. Без вызовов парсера MODX, если pdoTools может разобрать чанк сам.
