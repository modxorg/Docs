Показывает список файлов для скачивания без раскрытия URL файла.

Этот extra MODX выводит список файлов из каталога. Ссылка на скачивание каждого файла хешируется.
Так полный URL файла не виден, а файлы и каталоги можно разместить вне webroot.
Каждому файлу можно назначить счётчик скачиваний. Данные хранятся в отдельной таблице БД.

Проект FileDownloadR начал [Rico Goldsky](https://github.com/goldsky) в 2011 году как переписанная версия
пакета FileDownload для Evolution от Kyle Jaebker. С 2023 года поддерживает [Thomas Jakobi](https://github.com/Jako).

FileDownloadR устанавливается через менеджер MODX Revolution в [Управлении пакетами](developing-in-modx/advanced-development/package-management) или из репозитория MODX Extras:
[modx.com/extras/package/filedownloadr](https://modx.com/extras/package/filedownloadr)

Репозиторий на GitHub: [github.com/Jako/FileDownloadR](https://github.com/Jako/FileDownloadR). Ошибки сообщайте в [трекере issues](https://github.com/Jako/FileDownloadR/issues).

Документация пакета: [jako.github.io/FileDownloadR](http://jako.github.io/FileDownloadR/)
