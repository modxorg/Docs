---
title: "getUrlParam"
translation: "extras/geturlparam"
---

Простой сниппет: возвращает значение URL-параметра. Параметр проходит sanitizing и ограничение по длине.

В Revolution [URL-параметры](building-sites/resources) передавать легко. Этот сниппет упрощает их чтение.

#### OPTIONS

**name** - имя параметра, по умолчанию `p`
**int** - (опц.) `true`, чтобы допускать только целые
**max** - (опц.) максимальная длина значения, по умолчанию 20
**default** - (опц.) значение, если параметра в URL нет

Передача параметра:

``` php
[[~10? &val=`5`]]
```

Получение значения:

``` php
[[!getUrlParam? &name=`val` &int=`1`]]
```

Сниппет вызывайте uncached, чтобы получить актуальное значение.
