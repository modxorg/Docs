**Удалён**
См. [BannerY](extras/bannery "BannerY")

Выводит изображения с гиперссылками в заданных позициях страницы. Разработчик: Bezumkin / Jeroen Kenters.

## Версия

0.2.0 beta, релиз 10 мая 2012 года.

## Использование

``` php
[[BannerX? &position=`1` &sortby=`RAND()` &limit=`1`]]
```

Случайно выбирает один активный баннер для позиции 1.

## Доступные свойства

| Имя      | Описание                                                                               | По умолчанию |
| -------- | -------------------------------------------------------------------------------------- | ------------ |
| tpl      | Имя чанка, используемого как шаблон вывода                                             | bxAd         |
| sortdir  | Порядок сортировки результатов                                                         | ASC          |
| sortby   | Случайный порядок результатов                                                          | RAND()       |
| limit    | При ненулевом значении выводит только указанное число элементов                        | 5            |
| position | При ненулевом значении выбирает только изображения, назначенные указанной позиции      | 0            |

## Доступные плейсхолдеры

| Имя        | Описание                          |
| ---------- | --------------------------------- |
| adposition |                                   |
| image      | Изображение, назначенное баннеру  |
| name       | Имя, назначенное баннеру          |
| url        | URL, назначенный баннеру          |
