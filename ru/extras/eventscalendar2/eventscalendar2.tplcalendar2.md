## Использование

Чанк-контейнер календаря.

``` php
<div id='[[+calendar_id]]'>
    [[+ec.Calendar]]
    <div class='cover'></div>
</div>
```

## Плейсхолдеры

| Имя            | Описание                          |
| --------------- | ------------------------------------ |
| Calendar        | Сгенерированный календарь с событиями.      |
| calendar\_id    | Уникальный id таблицы календаря на странице. |
| class\_calendar | CSS-класс таблицы календаря.    |
