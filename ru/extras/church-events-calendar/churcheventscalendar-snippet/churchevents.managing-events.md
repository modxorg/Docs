## Добавление события

Инструкции для шаблона по умолчанию. При кастомном календаре элементы интерфейса могут отличаться.

1. Войдите в MODX и откройте страницу календаря на фронтенде.
2. Найдите дату и нажмите ссылку \[ + \].
  ![](add-plus.gif)
3. Заполните форму.

### Выбор дня и времени

Разовое событие без повторения

1. Does this event repeat: No.
2. Укажите дату события.
3. Выберите timed или all-day. Timed: встреча в 19:00 на час.
  _При Location Management и проверке конфликтов для локации пересекающиеся события в той же локации заблокируют сохранение._
    1. Yes: заполните Start Time и Duration, опционально setup time. Пример: с 19:00 до 20:00, Start Time 7:00 pm, Duration 1:00.
    2. No: дополнительных полей нет, событие отображается как All Day.

### Повторяющиеся события

Три режима: Daily, Weekly и Monthly. Daily: четырёхдневное событие с пн по чт или каждый третий день. Weekly: каждый вторник и четверг или через неделю по понедельникам. Monthly: встреча в первый понедельник месяца.

#### Daily

1. Выберите daily.
2. Интервал повторения: от Every Day до Every Seventh Day.
3. День начала.
4. День окончания.

**Примеры**:

1. Каждый день с пн 12/5 по пт 12/9.
    1. Repeat: Every day.
    2. Start: 12/5.
    3. End: 12/9.
2. Через день с вс 12/4 по пт 12/16: вс, вт, чт, сб, пн, ср, пт.
    1. Repeat: Every third day.
    2. Start: 12/4.
    3. End: 12/16.

#### Weekly

1. Выберите weekly.
2. Интервал: от Every week до Every sixth week.
3. Дни недели события.
4. День начала.
5. День окончания.

**Примеры**:

1. Каждый пн, ср и пт в январе 2012.
    1. Repeat weekly.
    2. Monday, Wednesday, Friday.
    3. Start 1/02/2011.
    4. End 1/30/2011.
2. Каждый второй вторник.
    1. Repeat weekly.
    2. Tuesday.
    3. Start и end date.

#### Monthly

Monthly кажется сложным, пока не разберётесь в сетке. Попробуйте на практике.

1. Выберите monthly.
2. Интервал: от Every month до Every sixth month.
3. Выберите день недели и номер недели в месяце. Вверху сетки дни недели, слева First по Fifth. В декабре 2011 **первое воскресенье**, 4-е число. Сетка для декабря 2011:
  ![](month-repeat-explain.png)
4. День начала.
5. День окончания.

**Примеры**:

1. Первый понедельник каждого месяца.
    1. Every month.
    2. Sunday в строке First Week (в оригинале опечатка: для Monday выберите Monday в First Week).
    3. Start и end.
2. Второй вторник и четвёртый понедельник каждого месяца.
    1. Every month.
    2. Tuesday во Second Week.
    3. Monday в Fourth Week.

## Редактирование события(ий)

1. В календаре нажмите заголовок события.
2. На странице описания при правах будет ссылка Edit this event.
3. Поля как при добавлении. У повторяющегося события появится дополнительная опция.
  ![](save-repeat-option.png)
  Override all обновит все связанные экземпляры, в том числе ранее изменённые отдельно.

## Удаление события

1. В календаре нажмите заголовок события.
2. На странице описания при правах будет Remove this event.
3. Подтвердите удаление. Для повторяющегося события выберите удалить все экземпляры или только выбранный.
  ![](delete-repeat-option.png)

## Запрос события

При churchevents.allowRequests = Yes гости без входа могут отправлять запросы. Запросы не публикуются, пока админ не одобрит. После отправки уходит email. Форма как при добавлении, без админ-опций. Подробнее в разделе «Добавление события».
