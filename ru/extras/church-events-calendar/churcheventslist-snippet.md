## Доступные свойства

Version 1.0

### Чанки list view

| Имя                           | Описание                                      | Значение по умолчанию |
| ------------------------------ | ------------------------------------------------ | ------------- |
| ChurchEvents\_listEventTpl     | Детали события в списке, ListDayHolderTpl |               |
| ChurchEvents\_listDayHolderTpl | Контейнер списка событий.                 |               |

### Прочее

| Имя       | Описание                                                                                                                                                                                                                                                                                                                                      | Значение по умолчанию |
| ---------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------- |
| skin       | Скопируйте tpl с префиксом ChurchEvents и задайте свой префикс, например MyCustomSkin. В вызове укажите skin вместо каждого tpl. Отдельное свойство tpl перекрывает skin. | ChurchEvents  |
| prominent  | Только prominent-события: Yes/No                                                                                                                                                                                                                                                                                                      | NULL          |
| limit      | Лимит записей, число                                                                                                                                                                                                                                                                                               | 15            |
| calendarID | Один календарь, по умолчанию все                                                                                                                                                                                                                                                                                                             |               |
| categoryID | Одна категория, по умолчанию все                                                                                                                                                                                                                                                                                                             |               |
| year       | Год начала, по умолчанию текущий (YYYY)                                                                                                                                                                                                                                                                                       |               |
| month      | Месяц начала, по умолчанию текущий (MM)                                                                                                                                                                                                                                                                                       |               |
| day        | День начала, по умолчанию текущий (DD)                                                                                                                                                                                                                                                                                          |               |

## Примеры

Следующие 15 событий списком

``` php
<ul>
[[!ChurchEventsList]]
</ul>
```

Prominent-события, лимит 10

``` php
[[!ChurchEventsList?
  &prominent=`Yes`
  &limit=`10`
]]
```
