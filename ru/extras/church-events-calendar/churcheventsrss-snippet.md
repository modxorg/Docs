## Доступные свойства

Version 1.0

### Чанки

| Имя       | Описание      | Значение по умолчанию |
| ---------- | ---------------- | ------------- |
| rssTpl     | Элемент RSS события   |               |
| rssItemTpl | Шаблон RSS |               |

### Прочее

| Имя       | Описание                                                | Значение по умолчанию |
| ---------- | ---------------------------------------------------------- | ------------- |
| prominent  | Только prominent: Yes/No                | NULL          |
| calendarID | Один календарь, по умолчанию все                       |               |
| categoryID | Одна категория, по умолчанию все                       |               |
| year       | Год начала, по умолчанию текущий (YYYY) |               |
| month      | Месяц начала, по умолчанию текущий (MM) |               |
| day        | День начала, по умолчанию текущий (DD)    |               |

## Создание RSS-ресурса

В MODX Manager создайте новый ресурс.

1. Задайте заголовок (например «Calendar Feeds») и alias (например feed).
2. Шаблон «(empty)», без шаблона. Подтвердите смену в диалоге.
3. Вкладка Page Settings, Content Type: RSS.
4. В содержимое вставьте сниппет. Отключите TinyMCE или другой редактор на вкладке Page Settings, чтобы не испортить код.
5. Вставьте: `[[!ChurchEventsRss?]]`
6. Сохраните ресурс.
7. Скопируйте ID новой страницы.
8. System Settings (System).
9. Отфильтруйте по churchevents.
10. RSS Page ID: двойной клик по значению, вставьте ID страницы.

### Базовый пример

Код в содержимом страницы:

``` php
[[!ChurchEventsRss?]]
```
