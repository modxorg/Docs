## Чанк Head Append

По умолчанию пустой. Добавьте CSS, JavaScript или meta-теги перед закрытием head. Удобное место для MetaX.

## См. также

``` php
[[getResources@section?
    &parents=`1316`
    &context=`extras`
    &limit=`0`
    &resources=`1316,[[*id]]`
]]
```
