## Placeholders

## Detail View (Event)

| Placeholder Name  | Description                                                                                                                                |
| ----------------- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| id                | Уникальный id события                                                                                                                            |
| title             | Значение поля заголовка                                                                                                                     |
| description       | Содержимое поля описания                                                                                                        |
| categoryid        | Уникальный id категории, если назначена                                                                                                  |
| link              | Разобранный URL, если указан id ресурса. Иначе прямой вывод введённого значения                                                  |
| linkrel           | Значение rel                                                                                                                   |
| linktarget        | Значение target, если выбрано                                                                                                                   |
| location\_name    | Название локации                                                                                                                        |
| location\_address | Адрес локации. Укажите полный корректный адрес для Google Map                                              |
| map               | Вывод Google Map, когда задан location\_address и                                                                     
| startdate         | Полная дата и время начала                                                                                                                    |
| enddate           | Полная дата и время окончания                                                                                                                      |
| repeating         | Boolean: повторяющееся событие (1 = да, 0 = нет)                                                         |
| repeattype        | Тип повторения, integer                                                                                                           |
| repeaton          | День недели (Sunday - Saturday) повторения                                                                            |
| repeatfrequency   | Интервал повторения, максимум 365                                                                                             |
| repeatenddate     | Только дата последнего повторения                                                                                                      |
| repeatdates       | Список всех дат события. Первая дата из startdate исключена                                                |
| source            | Тип источника feed (ical, xml)                                                                                                        |
| feeds\_id         | id feed, из которого создано событие                                                                                                |
| feeds\_uid        | Уникальный id feed                                                                                                                             |
| lastedit          | Полная дата и время последнего редактирования                                                                                                                |
| context           | Список контекстов через запятую. Если задан, рендер только в этих контекстах                                           |
| calendar\_id      | Календарь события. Если задан, рендер только для «all» или указанного calendar id                   |
| **form\_chunk**   | Форма, если выбрана на вкладке forms. Список из чанков с именем «form_»                     |
| createdon         | Дата и время создания                                                                                        |
| createdby         | ID пользователя, создавшего событие. Для feed по умолчанию 0 (zero)                                                                           |
| editedon          | Дата и время последнего редактирования                                                                                                                |
| editedby          | ID пользователя, создавшего событие. Для feed по умолчанию 0 (zero)                                                                           |
| active            | Boolean: событие активно и видимо. В этом представлении всегда 1                |
| category          | ID категории. Если задан, рендер только для «all» и соответствующего фильтра категории                     |
| foregroundcss     | CSS цвет текста категории, если задана                                                                      |
| backgroundcss     | CSS цвет фона категории, если задана                                                                      |
| inlinecss         | Inline CSS категории, если задана                                                                          |
| startdate\_fdate  | Форматированная дата по _dateformat_ в параметрах                                                                         |
| startdate\_ftime  | Форматированное время по _timeformat_ в параметрах                                                                         |
| enddate\_fdate    | Форматированная дата по _dateformat_ в параметрах                                                                         |
| enddate\_ftime    | Форматированное время по _timeformat_ в параметрах                                                                         |
| durYear           | Нечёткая длительность в годах                                                                                                              |
| durMonth          | Нечёткая длительность в месяцах, если событие длиннее месяца                                                                         |
| durDay            | Нечёткая длительность в днях, если длиннее суток (24 часа)                                                                    |
| durHour           | Нечёткая длительность в часах, если длиннее 60 (sixty) часов                                                                   |
| durMin            | Нечёткая длительность в минутах, если длиннее 60 (sixty) секунд                                                             |
| durSec            | Нечёткая длительность в секундах, если длиннее 1 (one) секунды                                                                  |
| mxcmodalClass     | CSS class для modal                                                                                                                   |
| detailURL         | URL детального просмотра. Совпадает с текущим, кроме modal (ajax), где resource id может отличаться |
| _allplaceholders_ | Список через запятую всех допустимых плейсхолдеров для этого представления                         |
