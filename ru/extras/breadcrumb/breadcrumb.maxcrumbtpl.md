## Чанк maxCrumbTpl в BreadCrumb

Это шаблон для свойства &maxCrumbTpl сниппета [BreadCrumb](extras/breadcrumb "BreadCrumb"). Используется для крошки-разделителя при превышении лимита.

## Значение по умолчанию

С версии BreadCrumb 1.3.0 maxCrumbTpl это не отдельный чанк, а свойство сниппета.
Свойства шаблонов могут быть именем чанка, путём к файлу (@FILE:) или кодом чанка (@CODE:)

``` html
<li>...</li>
```
