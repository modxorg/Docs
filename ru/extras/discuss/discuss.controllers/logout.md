Контроллер Logout выполняет выход пользователя. Он разлогинивает пользователя во всех контекстах, кроме менеджера. После выхода выполняется редирект на главную страницу форума.

## Основная информация

| Since Version         | 1.0                              |
| --------------------- | -------------------------------- |
| Controller File       | controllers/web/logout.class.php |
| Controller Class Name | DiscussLogoutController          |
| Controller Template   | None                             |
| Manifest Name         | logout                           |

## Опции

У контроллера Logout нет опций manifest. Он не зависит от системных настроек.

## Шаблон контроллера

У контроллера Logout нет шаблона.

## Системные события

На этом контроллере не срабатывают пользовательские системные события.
