Ниже перечислены основные возможности Discuss (не все):

### Гибкая структура

- Подфорумы с неограниченной вложенностью
- Категории
- Личные сообщения на основе тем
- Поддержка древовидных обсуждений (будущая функция)
- Архивные и неактивные доски
- Заблокированные доски и темы
- Простая темизация
- Ограничение доступа к доскам для отдельных групп пользователей

### Публикация

- Полная поддержка BBCode
- Вложения с учётом скачиваний
- Поддержка метки «отредактировано» для постов
- Courtesy Edit Wait
- Подписи на BBCode (с ограничением длины)
- Закреплённые и «горячие» темы с настраиваемыми порогами

### Управление в менеджере

- Перетаскивание досок и категорий для сортировки
- Удобное управление группами пользователей и участниками
- Просмотр постов пользователей, модерация и редактирование

### Модерация

- Глобальные модераторы
- Жалоба на пост модератору
- Права модератора на основе ACL
- Поддержка корзины
- Поддержка спам-бокса
- Административные группы

### Статистика

- Статистика пользователей
- Общая статистика форума

### Управление пользователями

- SSO через Login Extra, FormIt и Rampart
- Подписка пользователей на темы
- Игнорирование досок
- Аватары (с поддержкой Gravatar)
- Счётчики постов
- Настройки пользователя
- Просмотр «кто онлайн»
- Пользовательские звания

### Прочее

- Непрочитанные посты (и с момента последнего визита)
- RSS-ленты досок
- Скрипт импорта из SMF
- Опция ограничения доступа для гостей
- Интеграция поиска с Solr и Sphinx
