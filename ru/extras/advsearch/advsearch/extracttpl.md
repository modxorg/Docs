## Чанк extractTpl AdvSearch

С AdvSearch поставляется чанк «**extract**». Его имя задаётся свойством &extractTpl сниппета [AdvSearch](extras/advsearch/advsearch "AdvSearch.AdvSearch").

## Значение по умолчанию

``` php
<p class="advsea-extract">[[+extract]]</p>
```

## Доступные плейсхолдеры

| Name    | Description      |
| ------- | ---------------- |
| extract | Один фрагмент |
