## Использование сниппета mhPayPal

_Этот документ описывает сниппет mhPayPal, его свойства и примеры. Обзор пакета mhPayPal см. в [mhPayPal](extras/mhpaypal "mhPayPal")._

## Введение

Сниппет mhPayPal это ядро пакета mhPayPal. Он выводит форму, валидирует ввод, отправляет посетителя в PayPal для оплаты и обрабатывает настроенные хуки. Есть два основных сценария: пожертвования, где пользователь сам указывает сумму, или оплата одного товара по цене из вызова сниппета.

Результат зависит от пользователя, параметров URL и т. д., поэтому **сниппет mhPayPal всегда вызывайте некешированным!**

## Примеры использования

Подробнее о хуках и шаблонах см. отдельные страницы. Примеры предполагают корректную установку и настроенный доступ к API PayPal.

### Минимальный вызов

Стандартная форма с настройками по умолчанию: пожертвование от 5 EUR/USD/GBP.

``` php
[[!mhPayPal]]
```

### Фиксированная цена одного товара

Пример с формой по умолчанию (для товара, скорее всего, нужен свой чанк): валюта USD, сумма 15 + налог 2.85 и описание. Хорошая база для быстрого checkout с кастомным tpl и хуками.

``` php
[[!mhPayPal?
  &amount=`15`
  &amountTax=`2.85`
  &description=`Product XYZ ([[+currency]][[+amount]])`
  &currencies=`USD`
]]
```
