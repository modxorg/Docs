Типы полей выполняют две задачи. Сначала они задают тип ввода (контент от пользователя) с полным контролем HTML-разметки. Затем у каждого типа есть «field rule type», который связан со свойством display. Rule type также определяет дополнительные ограничения для ввода. Например, для rule type number можно задать min и max, которые проверяются при отправке. Полный список см. в разделе [rules types](#ruletypes) ниже.

При отправке значения проверяются. Для типа «_text_» можно задать min и max длины строки. |                    |
| Options List | Список опций для типов _selectlist, radiogroup, checkbox mulitple_. Экономит время: не нужно каждый раз создавать опции в сетке. Используйте так же, как Input Options Values у TV.                                                                                                                                                                                                                                             |

Good==good||Fair==fair||Bad==bad

| Content | HTML поля ввода в выводе. Содержит плейсхолдеры поля и даёт полный контроль над HTML-структурой. |  |
| Context | Ограничивает rule type конкретными контекстами. Например, можно создать набор типов полей для mobile, видимый только в mobile-контексте. По умолчанию пустое значение делает тип доступным во всех контекстах. |  |
