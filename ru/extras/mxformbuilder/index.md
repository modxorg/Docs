## Назначение

mxFormBuilder даёт единый и удобный интерфейс для управления всеми аспектами форм на сайте MODX. Дополнительный акцент сделан на встроенной защите от типичных угроз, связанных с формами.

## Начало работы

### Установка

Сначала установите компонент, если вы ещё этого не сделали. В менеджере сайта, на котором нужен mxFormBuilder, выберите «System» → «Package Management». Когда откроется страница Package Management, нажмите «Download Extras». В поле поиска слева введите «mxFormBuilder». Когда пакет появится в списке, нажмите «Download». После загрузки нажмите «Back to Package Management» над списком пакетов. Теперь можно нажать «Install» рядом с mxFormBuilder в локальном списке пакетов.
