## TV из списка форм mxFormBuilder

Вы можете быстро создать TV, чтобы редакторы контента выбирали любую опубликованную форму из mxFormBuilder. Для этого используйте встроенный сниппет **_mxfbTVFormList_**.

### Создание TV

В менеджере откройте вкладку Elements на левой панели. Щёлкните правой кнопкой по _Elements_ или нажмите иконку TV в панели инструментов. В окне новой template variable на вкладке General Information укажите нужные данные. В нашем примере:

- **Name**: mxform
- **Caption**: Select Form
- **Description**: (дополнительная информация о конкретном сценарии в ваших шаблонах)

Перейдите на вкладку **Input Options** и выберите тип ввода. Обычно подходит Listbox (Single-Select). Чтобы TV заполнялась из сниппета, в поле **Input Options Values** укажите:

``` php
@EVAL return '-- Select --||' . $modx->runSnippet('mxfbTvFormList');
```

Должно получиться примерно так:

![](mxfb-tv-create.png)

По умолчанию в списке только активные формы, а также формы с пустым (не заданным) контекстом и/или текущим контекстом.
Чтобы изменить фильтрацию, задайте параметры &context или &active.
Пример: **$modx->runSnippet('mxfbTvFormList', _array('context'=>'web')_ )**

Затем задайте остальные свойства под ваш сценарий. Обычно достаточно указать шаблоны, где TV будет доступна. На вкладке **Template Access** отметьте каждый нужный шаблон. Сохраните TV.

### Выбор в TV

После сохранения откройте ресурс с одним из разрешённых шаблонов. TV по умолчанию отображается на вкладке **Template Variables** ресурса.

![](mxfb-tv-example.jpeg)

В примере TV помещена в категорию mxFormBuilder. У вас категория может отличаться в зависимости от настроек при создании TV и Form Customization.

### Вывод формы, выбранной в TV

Когда TV создана и в ресурсе выбрана форма, выведите её на странице. В нужном месте вызовите сниппет **mxfb** и передайте параметр **_&formid_** из TV.

``` php
[[!mxfb? &formid=`[[*mxform]]` ]]
```

**mxform**: имя TV из нашего примера. Замените его на имя вашей TV.

mxFormBuilder обработает вызов только при корректном значении formid.
