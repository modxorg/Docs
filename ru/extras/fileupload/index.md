## Что такое FileUpload?

FileUpload это версия сниппета FileUpload Michel van de Wetering для Revolution.

FileUpload выводит форму загрузки файлов.

- Вы контролируете разрешённые группы пользователей, максимальный размер файла, допустимые расширения, каталог загрузки и т.д.
- Каталог загрузки можно задать в TV.
- Пользователь получает ответ об успехе или ошибке для каждого файла.
- Можно использовать несколько раз на одной странице.
