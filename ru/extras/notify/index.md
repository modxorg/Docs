## Что такое Notify?

Notify отправляет email-обновления пользователям сайта и при необходимости публикует в Twitter и Facebook. Пользователей можно выбрать по User Group и/или тегам интересов. Обновления ручные: Notify отправляет их только когда вы это запускаете. [Extra Subscribe](https://bobsguides.com/subscribe-tutorial.html) работает с Notify, чтобы пользователи управляли настройками и членством в группах.

По умолчанию Notify автоматически добавляет ссылку на страницу, которую вы редактировали при запуске, но extra также подходит для произвольных email-сообщений выбранным или всем пользователям.

Notify предзаполняет форму обновления на основе Tpl-чанков, которые вы можете менять. При предзаполнении Notify при необходимости сокращает URL через один из сервисов. Для Google, bit.ly, StumbleUpon и TinyURL Notify использует ваш API key.
