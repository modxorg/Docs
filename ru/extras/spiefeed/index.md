## Description

RSS/Atom feeder на базе [SimplePie](http://simplepie.org/) 1.2, уже включён в пакет: <http://github.com/rmccue/simplepie/downloads>

## Requirements

- MODX Revolution 2.0.0-RC-2 или новее
- PHP5 или новее

## Download

Скачайте через менеджер MODX Revolution в [Package Management](developing-in-modx/advanced-development/package-management "Package Management") или из MODX Extras Repository: <https://modx.com/extras/package/spiefeed> или здесь: <https://modx.com/extras/package/spiefeed>

## Development and Bug Reporting

spieFeed на GitHub: <https://github.com/goldsky/spiefeed>

Баги: <https://github.com/goldsky/spiefeed/issues>

## Usage

spieFeed вызывают сниппетом в контенте с параметром 'url':

``` php
[[!spieFeed? &setFeedUrl=`http://path.com/to/my/rss.feed.rss`]]
```

Для нескольких источников:

``` php
http://feeds.feedburner.com/modx-announce | http://www.voanews.com/templates/Articles.rss?sectionPath=/russian/news
```

разделяйте символом pipe ( | ).
