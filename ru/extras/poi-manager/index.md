Этот extra позволяет создавать и управлять POI. Вы можете создавать контейнеры POI (категории) и включать каждый POI в один или несколько контейнеров. Также можно создавать типы POI с дополнительными атрибутами.

Extra включает RESTful-сервер. Запросы отправляйте на **/assets/components/marvin/api.php**. Документация RESTful-сервера: [docs.poimanager.apiary.io](http://docs.poimanager.apiary.io).

**Extra не включает слой представления.**

После установки через управление пакетами выполните шаги:

1. Создайте новый тип POI
    + В меню компонентов откройте POI types и создайте тип
    + Добавьте хотя бы одно поле к типу POI
2. Создайте контейнер POI
    + Контейнеры POI это отдельный тип ресурса. Чтобы создать контейнер, щёлкните правой кнопкой в дереве ресурсов и выберите **Create a POI Container**
3. Добавьте POI в созданный контейнер
    + Заполните данные POI
    + Чтобы поставить маркер на карте, щёлкните правой кнопкой по нужной точке или введите lat и lng в поля над картой
