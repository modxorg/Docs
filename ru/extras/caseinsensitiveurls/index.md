## Что такое CaseInsensitiveURLs?

Плагин CaseInsensitiveURLs перенаправляет запросы страниц со смешанным регистром в URL на версию в нижнем регистре, если вариант со смешанным регистром не найден. Параметры query string не меняются. Плагин не замедляет сайт, потому что срабатывает только при событии page-not-found.

Плагин полезен, если все псевдонимы ресурсов у вас в нижнем регистре.
