## Что такое Captcha?

Утилита добавляет проверку captcha при входе в менеджер MODX.

Использует 5 системных настроек:

    - captcha.enabled - Если включено, captcha активна
    - captcha.use\_mathstring - Если включено, на изображении простое уравнение для решения
    - captcha.words - Набор слов для изображения, когда captcha.use\_mathstring выключена
    - captcha.height - Высота изображения captcha в пикселях
    - captcha.width - Ширина изображения captcha в пикселях

Компоненты Captcha также можно использовать в других extras для captcha-проверки на фронтенде.

Установите через Package Management, затем настройте системные параметры captcha по необходимости.
