## Что такое QuickCrumbs

QuickCrumbs это быстрый и эффективный [сниппет](developing-in-modx/basic-development/snippets "Snippets") генерации хлебных крошек для MODX Revolution. Он поддерживает чанки tpl для крошек, настраиваемый разделитель и многое другое.

### История

Разрабатывается с 11 октября 2010 года [Jason Coward](https://modx.com/extras/author/opengeek).

### Требования

- MODX Revolution

### Разработка и сообщения об ошибках

QuickCrumbs сейчас развивается на GitHub. Там же можно **[сообщать об ошибках](https://github.com/opengeek/quickcrumbs/issues)**, подавать **запросы функций** и **улучшения**. Последние коммиты доступны в ветке Develop.

Github: <https://github.com/opengeek/quickcrumbs>

## Использование

Сниппет QuickCrumbs вызывают так:

``` php
[[QuickCrumbs]]
```

Вызов без свойства &tpl просто выведет массив с каждым найденным ресурсом и его полями.

## Доступные свойства

Для сниппета QuickCrumbs доступны следующие свойства.

### Свойства шаблонов

| Name         | Description                                                                                                                                            | Default Value                                  |
| ------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------- |
| tpl          | Имя чанка-шаблона для крошки ресурса. **ПРИМЕЧАНИЕ: если не задано, свойства выводятся в pre для каждой крошки** |                                                |
| siteStartTpl | Необязательный чанк-шаблон для site_start.                                                                                           | По умолчанию \***tpl***, если не задан.   |
| selfTpl      | Необязательный чанк-шаблон для текущего ресурса.                                                                                | По умолчанию \***tpl***, если не задан.   |
| outerTpl     | Необязательный чанк-обёртка для всего вывода крошек.                                                                        | По умолчанию пусто, вывод как есть. |

### Свойства выбора крошек

| Name          | Description                                                                                                                                      | Default Value                                 |
| ------------- | ------------------------------------------------------------------------------------------------------------------------------------------------ | --------------------------------------------- |
| fields        | Список полей ресурса через запятую как плейсхолдеры. **ПРИМЕЧАНИЕ: id, class\_key и context\_key выбираются всегда.** | По умолчанию 'pagetitle,menutitle,description' |
| showSiteStart | Показывать ли крошку для ресурса site_start.                                                                  | По умолчанию 1 (true).                      |
| showSelf      | Показывать ли крошку для текущего ресурса.                                                                      | По умолчанию 1 (true).                      |

### Прочие свойства

| Name          | Description                                                                                                               | Default Value             |
| ------------- | ------------------------------------------------------------------------------------------------------------------------- | ------------------------- |
| separator     | Строка-разделитель между крошками.                                                                            | По умолчанию `»`           |
| toPlaceholder | Если не пусто, вывод сохраняется в плейсхолдер с указанным именем вместо прямого возврата из сниппета. | По умолчанию пусто.         |
| debug         | При true отладочная информация пишется в лог MODX.                                                              | По умолчанию 0 (false). |

### Свойства parent-Titles

| Name                    | Description                                                                                                                                               | Default Value            |
| ----------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------ |
| parentTitlesPlaceholder | Если не пусто, pagetitle всех родительских крошек собираются в плейсхолдер с указанным именем для контента ресурса. | По умолчанию пусто.        |
| parentTitlesReversed    | Выводить ли pagetitle родителей в обратном порядке.                                                                                     | По умолчанию 0 (false). |
| titleSeparator          | Разделитель между pagetitle в parentTitlesPlaceholder.                                                                             |                          |
