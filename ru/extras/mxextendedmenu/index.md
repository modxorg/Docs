## Назначение

mxExtendedMenu ускоряет большие меню контента за счёт снижения накладных расходов на чанки. Он также даёт гибкий набор шаблонов по глубине ресурса, типу и другим параметрам. Если у вас мега-меню или сложная HTML-структура, это хорошая альтернатива. По умолчанию для производительности все свойства шаблонов ожидают готовый HTML-блок кода. Параметр enableModifiers описывает использование чанков и output modifiers для дополнительного контроля.

## Параметры

| Параметр      | Тип    | По умолчанию    | Назначение                                                         |
| ------------- | ------ | --------------- | ------------------------------------------------------------------ |
| docid         | int    | `[[*id]]`       | ID начального ресурса, от которого строится меню                   |
| depth         | int    | 10              | Максимальная глубина меню                                          |
| contextFilter | string | current context | Переопределяет контекст и берёт ресурсы из внешнего контекста      |
