---
title: "bdRedirect"
description: "Сниппет перенаправления с отслеживанием кликов по объявлениям bdListings"
translation: "extras/bdlistings/bdredirect"
---

bdRedirect это простой сниппет для страницы перенаправления с отслеживанием кликов по объявлению. Укажите свойство `&redirectResource` в вызовах bdListings, чтобы сниппет корректно формировал плейсхолдер `redirect_url`.

Создайте ресурс и поместите в содержимое некэшированный вызов bdRedirect:

``` php
[[!bdRedirect]]
```

Сниппет перенаправит пользователя на URL поля «website» или на страницу ошибки, если объявление не найдено.
