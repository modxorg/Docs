SocialSuite сейчас в разработке и выйдет позже. Документацию расширим перед релизом.

SocialSuite это растущий набор инструментов для MODX Revolution. Вы встраиваете элементы социальных сетей в свои шаблоны без лишних усилий. Проект ведёт Mark Hamstra на GitHub. Лицензия GPL v2 (или новее): свободное использование и доработка.

## Ссылки и общая информация

## Доступные инструменты

Откройте страницы ниже, чтобы узнать о каждом сниппете и способах использования. Мы стараемся придерживаться одних соглашений, но это не всегда возможно. Проверяйте доступные свойства и инструкции по шаблонам там, где они есть.

| Snippet             | Service  | Description                                                                                                                                                                               | More information |
| ------------------- | -------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------- |
| getFacebookShares   | Facebook | Сниппет getFacebookShares возвращает, сколько раз указанный URL лайкнули или поделились им. Для числа лайков или друзей страницы или пользователя используйте getFacebookProfile. |                  |
| getFacebookPhotos   | Facebook | Сниппет getFacebookPhotos возвращает альбомы и фото для указанного пользователя или страницы.                                                                                                   |                  |
| getFacebookProfile  | Facebook | getFacebookProfile получает всю публичную информацию о пользователе или странице: обычно имя, местоположение, число лайков или друзей и т. д.                                    |                  |
| getGooglePlusShares | Google+  | Сниппет getGooglePlusOne использует _неофициальный API_ (см. ниже), чтобы узнать, сколько раз URL получил +1.                                                                      |                  |
| getTwitterProfile   | Twitter  | Сниппет getTwitterProfile получает всю публичную информацию об указанном аккаунте Twitter: обычно имя, местоположение и число подписок или подписчиков.                          |                  |
| getTwitterShares    | Twitter  | Сниппет getTwitterShares использует _неофициальный API_ (см. ниже), чтобы узнать, сколько раз URL твитнули.                                                                   |                  |

Кроме сниппетов выше, в SocialSuite есть вспомогательные инструменты:

| Name          | Description                                                                                                                                                                                                                                            | More information |
| ------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ---------------- |
| prettyNumbers | Как [output filter](building-sites/tag-syntax/output-filters "Input and Output Filters") prettyNumbers принимает число и выводит его в удобном формате. Например, 156874 превращается в 156k. |                  |

### Примечание о неофициальных API

Часть инструментов, например getGooglePlusShares и getTwitterShares, использует неофициальные API. Сервисы часто применяют их внутри, но не документируют и не объявляют готовыми для публики. Сейчас они работают, но завтра поддержку могут убрать. Мы постараемся сохранить совместимость, но гарантий нет. Нужна гарантия? Обращайтесь к сервису с просьбой выпустить официальный API! :)
