## Что такое getDynaDescription?

Конвертация и переписывание сниппета Evolution getDynaDescription.

Создаёт meta-теги из TV, поля description ресурса или поля content.

Вы задаёте число слов из content, полный тег или только содержимое и источник текста description.

При установке можно создать TV, привязать к выбранным шаблонам и/или вставить meta-теги в выбранные шаблоны.

Скачивание через Package Manager.
