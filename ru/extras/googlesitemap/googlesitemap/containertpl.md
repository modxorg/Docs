## Чанк containerTpl GoogleSiteMap

Чанк для свойства &containerTpl сниппета [GoogleSiteMap](en/extras/googlesitemap/googlesitemap "GoogleSiteMap.GoogleSiteMap"). Оборачивает элементы результата.

## Значение по умолчанию

``` xml
<urlset xmlns="[[+schema]]">
[[+items]]
</urlset>
```

## Доступные плейсхолдеры

| Имя   | Описание            |
| ------ | ---------------------- |
| items  | Элементы результата.      |
| schema | URL схемы Google. |
