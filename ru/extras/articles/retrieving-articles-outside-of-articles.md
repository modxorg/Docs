Статьи Articles хранятся как ресурсы MODX, поэтому их легко использовать в других extras. По умолчанию у статей включён hidemenu (они скрыты из меню). Это нужно, чтобы они не попадали во все меню сайта. Представьте сайт с 10 000 статей: меню было бы огромным.

Например, этот вызов [getResources](extras/getresources "getResources") берёт 8 последних статей из контейнера с ID 10:

``` php
[[getResources?
  &parents=`10`
  &tpl=`myTpl`
  &showHidden=`1`
  &limit=`8`
]]
```

Вот и всё.

## Сниппет Articles

Начиная с Articles 1.4+, в пакете есть сниппет «Articles». Он выдаёт плейсхолдеры контейнера на **любом** ресурсе сайта. Например, на главной странице с контейнером ID 10:

``` php
[[Articles? &container=`10`]]
[[+latest_posts]]
```

...покажет последние записи этого контейнера. Сниппет делает доступными все плейсхолдеры из шаблона по умолчанию:

- `[[+latest_posts]]`: виджет «Latest Posts» справа в sample-шаблоне.
- `[[+latest_comments]]`: виджет «Latest Comments» справа в sample-шаблоне.
- `[[+comments_enabled]]`: 1 или 0 в зависимости от того, включены ли комментарии для контейнера.
- `[[+tags]]`: список самых частых тегов блога.
- `[[+archives]]`: список последних месяцев (или лет) в формате архива.

Параметр &placeholderPrefix у сниппета Articles добавляет префикс к этим плейсхолдерам. Так можно разместить несколько вызовов Articles на одной странице.
