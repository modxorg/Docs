## Что такое EmailResource?

EmailResource отправляет HTML-версию любого ресурса с inline CSS на основе ваших CSS из файлов, ресурсов или чанков. Плагин привязан к системному событию OnWebPagePrerender и срабатывает при предпросмотре ресурса из менеджера.

Поддерживается массовая рассылка ресурса и отправка по тегам, в связке с пакетом Subscribe.

Extra создан при поддержке [WorkDay Media](http://workdaymedia.com.au).

## Загрузка

EmailResource устанавливается через менеджер MODX Revolution в [Менеджере пакетов](developing-in-modx/advanced-development/package-management "Package Manager") (Extras -> Installer) или из [репозитория MODX Extras](https://modx.com/extras/package/emailresource).
