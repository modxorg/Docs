После установки Slideshow Manager через package manager обновите страницу. В меню MODX Manager появится Components -> Slideshow Manager. Здесь вы управляете слайдшоу.

## Albums

Альбом: одно слайдшоу.

### Create an Album

Альбом: набор слайдов или отдельное слайдшоу.

1. Components -> Slideshow Manager
2. Вкладка Album
3. Create an Album
4. Заполните форму и сохраните. Width и Height в пикселях, только числа. Slideshow Manager не примет изображения, не соответствующие критериям.
   
![](add-album.png)

## Slides

Slides: изображения альбома. У альбома много слайдов, но каждый слайд привязан только к одному альбому.

### Create a Slide

1. Components -> Slideshow Manager
2. Вкладка Slides
3. Выберите нужный Album.
4. Create a Slide
  ![](add-slide.png)
5. Заполните форму и сохраните.

### Edit a Slide

1. Первые 3 шага как в Create a Slide
2. Двойной клик по полю в сетке для редактирования. Сохранение при переходе на другой элемент.
  ![](edit-slide.png)
3. Или правый клик и Edit Slide. Этот путь нужен для замены изображения.
  ![](update-slide.png)
