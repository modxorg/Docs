## Что такое getPage?

Универсальный сниппет для вывода, навигации и опционального кеширования многостраничных представлений из любого элемента, который принимает свойства limit и offset для ограничения набора данных и устанавливает плейсхолдер с общим числом элементов для постраничной навиции.

## Требования

- MODX Revolution 2.0.0-beta5 или новее
- PHP5 или новее

## История

getPage написал Jason Coward (opengeek). Релиз вышел 19 марта 2010 года.

### Скачать

Скачайте через менеджер MODX Revolution в разделе [управление пакетами](developing-in-modx/advanced-development/package-management "Package Management") или из репозитория MODX Extras: <https://modx.com/extras/package/getpage>

Сам по себе этот сниппет ничего не выводит. Он оборачивает другой сниппет и возвращает результат для указанной страницы (или диапазона данных в полном наборе). Например, сниппеты [getResources](extras/getresources "getResources"), [getFeed](extras/getfeed "getFeed") и [Archivist](extras/archivist/archivist) можно обернуть в getPage.

## Использование

Вызов getPage:

``` php
[[!getPage?
    &elementClass=`modSnippet`
    &element=`getResources`
]]
```

**Не кешируйте**
 getPage нельзя вызывать кешируемым на кешируемом ресурсе. Всегда вызывайте getPage с некешируемым префиксом `!`, оставляя остальной вывод ресурса кешируемым. То же правило для плейсхолдера из свойства `pageNavVar` (по умолчанию `page.nav`), чтобы навигация не попала в кешируемое содержимое страницы.

**Обязательные свойства**
 Укажите свойство element и все дополнительные свойства, которые требует оборачиваемый элемент.

#### Свойства шаблонов навигации

Эти tpl-свойства нельзя менять прямо в теге сниппета из-за порядка разбора тегов в Revolution. Чтобы изменить значения по умолчанию, используйте набор свойств:

- На вкладке «Элементы» откройте дерево сниппетов и найдите getPage.
- Откройте вкладку «Свойства элемента».
- Создайте новый набор свойств кнопкой «Добавить набор свойств» и отметьте «Создать новый набор свойств».
- Задайте имя набора и сохраните.
- Теперь можно менять значения свойств. При обновлении они не перезапишутся.
- Укажите имя набора в вызове сниппета:

``` php
[[!getPage@PropertySetName? &element=`getResources` &parents=`3` ...]]
```

| Имя             | Описание                                                                       | Значение по умолчанию                                                                                                          | Добавлено в версии |

## Примеры

Постраничный вывод дочерних ресурсов текущего ресурса с чанком myRowTpl:

``` php
[[!getPage? &element=`getResources` &parents=`[[*id]]` &tpl=`myRowTpl`]]
<div class="pageNav">[[!+page.nav]]</div>
```

Постраничный вывод всех ресурсов под ресурсом с ID 5, кроме ресурса 10, с чанком myRowTpl:

``` php
[[!getPage? &element=`getResources` &parents=`5` &resources=`-10` &tpl=`myRowTpl`]]
<div class="pageNav">[[!+page.nav]]</div>
```

Если вы пишете свой сниппет для работы с getPage, он должен поддерживать три вещи:

- limit
- offset
- totalVar
