## Что такое LexiconHelper?

LexiconHelper помогает разработчикам add-on компонентов интернационализировать свои компоненты.

Сравнивает файлы кода с языковыми файлами и сообщает о пропущенных, пустых или неиспользуемых строках. Список пропущенных строк можно вставить в языковой файл для заполнения.

LexiconHelper можно использовать отдельно, но расширенная версия входит в [MyComponents Extra Development System](https://bobsguides.com/mycomponent-tutorial.html). Эта автономная версия LexiconHelper больше не развивается и не поддерживается.

Примечание: LexiconHelper не утилита для переводчиков.
