## Что такое DirWalker?

DirWalker это класс для рекурсивного обхода каталогов. Вы можете исключать каталоги по имени и включать или исключать файлы по строке или регулярному выражению.

Список файлов можно получить из класса после поиска или обрабатывать каждый файл по мере обнаружения.
