**Без JavaScript!**
Этот плагин не требует, не создаёт и не использует лишний JavaScript, снижая нагрузку на браузер клиента.

## Что делает

Плагин MODX Revolution работает прозрачно в фоне и обфусцирует все найденные email-адреса: и в ссылках, и как обычный текст на странице. Находит все распространённые адреса по RFC2822, включая необычные, но допустимые символы.

## Как работает

Превращает shawn@shawnwilkerson.com в:

``` php
s&#x68;&#97;wn&#64;&#x73;&#x68;&#97;&#119;&#x6e;&#x77;&#105;&#x6c;&#107;&#x65;&#x72;&#115;&#111;&#110;.&#x63;&#111;&#x6d;
```

## Для кого работает

Для всех пользователей проекта, ссылок на внешние адреса, адресов того же сайта и т.д.
Работает со _всеми_ email-адресами.

## Дополнительная функциональность

Пока плагин работает в фоне, он также постоянно рандомизирует кодирование адреса, чтобы оно выглядело меняющимся, хотя в почтовых клиентах и при копировании всё работает корректно.

## Примеры

Это добавляет ещё один слой защиты. Три строки ниже это один и тот же адрес с одной страницы:

``` php
&#115;&#104;&#97;&#119;&#110;&#64;&#x73;&#x68;&#x61;&#x77;&#x6e;&#119;&#105;&#x6c;&#107;&#x65;r&#x73;&#111;&#110;.&#99;&#x6f;&#x6d;
```

``` php
s&#x68;&#97;wn&#64;&#x73;&#x68;&#97;&#119;&#x6e;&#x77;&#105;&#x6c;&#107;&#x65;&#x72;&#115;&#111;&#110;.&#x63;&#111;&#x6d;
```

``` php
&#x73;&#x68;&#97;&#x77;&#x6e;&#x40;&#x73;&#104;&#97;&#119;&#x6e;&#119;&#x69;&#x6c;&#107;&#101;&#114;&#x73;&#x6f;&#x6e;&#x2e;c&#x6f;&#x6d;
```

## Установка через Package Manager

Скачайте и установите через Package Manager. Если в проекте уже есть другие события OnWebPagePreRender, при необходимости задайте порядок выполнения в соответствующих плагинах.

## Код на GitHub

Исходный код: <http://github.com/wshawn/ObfuscateEmail>

## Ручная установка

1. Создайте новый plugin
2. Вставьте код с <http://github.com/wshawn/ObfuscateEmail>
3. На вкладке events отметьте OnWebPagePreRender (внизу)
4. Сохраните plugin

## Защитите проект и пользователей

С этим плагином легко защитить почтовые ящики всех адресов на ваших страницах.
Защитите пользователей и улучшите репутацию проекта.

## История

Плагин изначально вышел для MODX Evolution от Aloysius Lim: <https://modx.com/extras/package/obfuscateemail>. При переходе на MODX Revolution я перенёс его, потому что он хорошо служил клиентам. С релизом MODX Revolution 2.1 и отказом от legacy-кода потребовались обновления.
Надеюсь, ObfuscateEmail-Revo будет так же полезен, как и раньше.
