Компонент **ещё в разработке**. Мы над ним работаем.

Image Styles это коллекции свойств для масштабировщика изображений phpThumb. Они дают аккуратные URL по имени стиля. Каждый стиль содержит свойства, которые передаются в phpThumb для масштабирования по имени стиля и его параметрам. Имена файлов с Image Styles читаемы для человека, а ссылки на изображения могут быть намного короче, чем без этого компонента.
