## Кратко: как добавить шаблоны

Иногда нужен один и тот же фрагмент кода, чтобы вставка всегда выглядела одинаково. Для этого в TinyMCE есть Templates.

Ниже короткое руководство для Revolution (найдено на форумах после долгого поиска).

- В Менеджере откройте **Система → Системные настройки**.
- В пространстве имён выберите **TinyMCE**, в фильтре области: **General**.
- Найдите **Custom Plugins** (ключ `tiny.custom_plugins`). Добавьте в конец списка значение **template**.
- Измените **Template List** (ключ `tiny.template_list`). Добавьте шаблоны через запятую в формате:

```php
name:path-to-the-template:description
```

Для одного шаблона три поля разделяются точкой с запятой. Следующий шаблон добавляйте через запятую.

В теории список можно отдать сниппетом, но на практике это часто не срабатывает.

- Добавьте значение **template** в один из списков кнопок (фильтр области **Custom buttons**).

Загрузите код шаблона по пути, который указали в списке.
