## Что такое selfLink?

selfLink это простой сниппет для MODX Revolution, который помогает создавать ссылки или якоря на страницу по направлению: «up», «next» и «previous».

selfLink впервые выпущен 8 марта 2011 года. Автор: Bert Oost.

## Требования

selfLink создан как сниппет Revolution и должен работать на всех версиях с 2.0.0. Если заметите несовместимость в конкретной версии, сообщите разработчику в теме на форуме.

## Загрузка и установка

Чтобы начать работу со сниппетом selfLink, откройте System -> Package Manager -> Add new extra -> provider: modxcms.com -> MODX add-ons -> Content и найдите selfLink. Скачайте пакет и установите его в основном рабочем пространстве менеджера пакетов.

## Использование selfLink

selfLink прост в использовании. Вы задаёте поведение через параметры.

| Parameter | Description                                                                        | Default value             |
| --------- | ---------------------------------------------------------------------------------- | ------------------------- |
| direction | Одно из значений: 'up', 'next' или 'previous'                             |                           |
| id        | (необязательно) ID ресурса, от которого строится ссылка                | ID текущей страницы           |
| tpl       | (необязательно) Имя чанка для оформления ссылки                          | `<a href="...">Title</a>` |
| linktext  | (необязательно) Альтернативный текст ссылки. Если пусто, берётся pagetitle ресурса |                           |

## Примеры

Минимальный вызов для ссылки на следующий ресурс в дереве:

``` php
[[selfLink? &direction=`next`]]
```
