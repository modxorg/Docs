## Что такое CacheMaster?

На большом сайте поведение MODX по умолчанию, когда при сохранении ресурса или элемента очищается кэш всех ресурсов, сильно замедляет работу для посетителей. Плагин CacheMaster для MODX Revolution очищает кэш только одного ресурса или элемента при сохранении, не трогая остальное.

По желанию он также снимает галочку «Empty Cache» по умолчанию при редактировании ресурса или элемента.
