## Как использовать FX2: обзор

<iframe sandbox="allow-same-origin allow-forms allow-popups allow-scripts" src="https://player.vimeo.com/video/76491147" width="640" height="360" frameborder="0" webkitallowfullscreen mozallowfullscreen allowfullscreen></iframe>

FX2 рассчитан на два типа пользователей. Разработчики MODX и авторы тем используют его как «foundation» (да, каламбур) для пакетов сайтов, которые конечный пользователь легко настраивает. Конечный пользователь _может_ использовать FX2 как «бесплатную» тему, но оформлению уделено мало внимания. Шаблоны FX2 опираются на sample HTML Zurb с минимальными правками, кроме динамических частей MODX.

Есть документация для обоих типов пользователей.
