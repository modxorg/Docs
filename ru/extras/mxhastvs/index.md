mxHasTvs возвращает значение по TV ресурса (docid). Вы быстро строите шаблоны без ловушек conditional modifiers. Полезен для сложных правил UI (шаблон, чанк и т.д.), когда вывод зависит от значения TV. Возвращает строки true и false или пустоту, если найдено совпадение по любому из указанных TV.

## Свойства

| Параметр               | Тип      | Описание                                                                                                                                                                                                                  |
| ---------------------- | -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| @docid                 | (int)    | ID ресурса, для которого ищутся значения TV                                                                                                                                                                               |
| @tvIds                 | (mixed)  | Список ID TV через запятую для ресурса                                                                                                                                                                                    |
| @true                  | (string) | Необязательно. Строка для вывода при найденных значениях TV: чанк, сниппет или другое значение. Если не задано, сниппет вернёт 1                                                                                       |
| @false                 | (string) | Необязательно. Строка при отсутствии совпадающих значений TV, может быть пустой. Если не задано, сниппет вернёт 0 (blank, null, '', значение TV по умолчанию)                                                           |
| @forceTrueResource     | (mixed)  | Список ID ресурсов через запятую для принудительного ответа true                                                                                                                                                          |
| @forceFalseResource    | (mixed)  | Список ID ресурсов через запятую для принудительного ответа false                                                                                                                                                         |
| @forceTrueTemplate     | (mixed)  | Список ID шаблонов через запятую для принудительного ответа true                                                                                                                                                          |
| @forceFalseTemplate    | (mixed)  | Список ID шаблонов через запятую для принудительного ответа false                                                                                                                                                         |
| @forcePriorityResrouce | (int)    | 1 (по умолчанию): сначала проверка принудительных TV ресурса. 0: приоритет у принудительных TV шаблона                                                                                                                    |

## Пример

Возвращает чанк при успехе или если у ресурса есть совпадающие значения TV.
Если значений для указанных TV нет, ответ пустой. Также принудительно возвращает true для ресурса с id 1.

``` php
[[!mxhastvs?
    &tvIds=`11,20`
    &true=`[[$doSomethingChunkName]]`
    &false=``
    &forceTrueResource=`1`
]]
```
