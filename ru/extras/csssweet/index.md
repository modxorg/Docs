## Зачем это нужно

cssSweet позволяет управлять CSS сайта внутри MODX. Зачем это может понадобиться, описано в [документации на GitHub](http://sepiariver.github.io/cssSweet/). Один из примеров: вы делаете тему, а технический уровень владельца сайта неизвестен. Вы не можете рассчитывать на знание Sass, но хотите дать контроль над частью оформления. Для этого cssSweet и создан.

Версия 2 добавляет много возможностей. На [полном сайте документации](http://sepiariver.github.io/cssSweet/) есть важная информация об обновлении с версии 1.

## Что нужно для установки

Установите cssSweet через Package Manager в MODX Revolution 2.2.x или новее. Полезно также установить [ClientConfig](extras/clientconfig). Тогда конечные пользователи смогут менять глобальные настройки без раздела System Settings в менеджере.

## Как использовать

Пакет cssSweet включает 2 плагина и три сниппета. О сниппетах см. дочерние страницы. Перед этим обратите внимание на несколько системных настроек.

IMPORTANT: Начиная с версии 2, системные настройки cssSweet устарели в пользу свойств плагина. НЕ используйте системные настройки в cssSweet версии 2 и выше. Они не сработают.

### Системные настройки cssSweet

| **Key**                    | **What it does**                                                              | **Default value**                  |
| -------------------------- | ----------------------------------------------------------------------------- | ---------------------------------- |
| csss.custom\_css\_path     | Путь, куда плагин saveCustomCss сохранит статический CSS-файл. | {assets\_path}components/csssweet/ |
| csss.custom\_css\_chunk    | Имя чанка, содержимое которого попадёт в CSS-файл.           | csss.custom.css                    |
| csss.custom\_css\_filename | Имя статического CSS-файла на выходе.                                           | csss-custom.css                    |
| csss.minify\_custom\_css   | Включить или отключить минификацию CSS.               | true                               |

### Как плагин использует эти настройки

При значениях по умолчанию, когда в менеджере нажимают Site » Clear Cache, плагин парсит чанк «csss.custom.css» и записывает результат в файл «{assets\_path}components/csssweet/csss-custom.css». Чтобы подключить файл в шаблоне, используйте системную настройку assets\_url:

``` html
<link rel="stylesheet" href="[[++assets_url]]components/csssweet/csss-custom.css" />
```

Содержимое файла сожмёт пробелы, табы и переносы строк до одного пробела, потому что csss.minify\_custom\_css равен «true».
