## Описание

Этот сниппет выводит вопросы и ответы опросов, созданные в менеджере. Вы задаёте две пары чанков: одну для формы голосования и одну для экрана результатов после голосования. Ниже описаны шаблоны и доступные параметры.

## Использование

Вставьте тег PollsLatest в шаблон или содержимое ресурса:

``` php
[[!PollsLatest]]
```

Параметры см. в таблице ниже.

## Доступные свойства

### Свойства шаблонов

| Name            | Description                                               | Default                 |
| --------------- | --------------------------------------------------------- | ----------------------- |
| tplVote         | Основной шаблон формы для последнего опроса           | pollsLatestVoteOuter    |
| tplVoteAnswer   | Шаблон ответов внутри основной формы    | pollsLatestVoteAnswer   |
| tplResult       | Основной шаблон результатов для последнего опроса         | pollsLatestResultOuter  |
| tplResultAnswer | Шаблон ответов внутри внешнего шаблона результатов | pollsLatestResultAnswer |

### Свойства выборки

| Name     | Description                                                                                                                            | Default |
| -------- | -------------------------------------------------------------------------------------------------------------------------------------- | ------- |
| category | (Необязательно) Берёт последний опрос из категории (id). Несколько категорий через запятую |         |
| sortby   | (Необязательно) Поле сортировки, любое поле из списка                                                             | id      |
| sortdir  | (Необязательно) Направление сортировки                                                                                     | DESC    |

Примечание: параметры sort обычно менять не нужно!

### Свойства ссылок

| Name           | Description                                                                                | Default |
| -------------- | ------------------------------------------------------------------------------------------ | ------- |
| resultResource | (Необязательно) ID ресурса для страницы результатов опроса  |         |
| resultLinkVar  | (Необязательно) При resultResource имя GET-параметра, который ищет сниппет | poll    |

## Плейсхолдеры шаблонов

В шаблонах сниппета доступны такие плейсхолдеры:

### tplVote

| Placeholder          | Description                                                                           |
| -------------------- | ------------------------------------------------------------------------------------- |
| `[[+id]]`            | ID вопроса текущего опроса                                              |
| `[[+question]]`      | Текст вопроса                                                                     |
| `[[+publishdate]]`   | Дата публикации вопроса                                                       |
| `[[+unpublishdate]]` | Дата снятия с публикации                                                     |
| `[[+totalVotes]]`    | Общее число голосов в опросе                                                |
| `[[+category_name]]` | Имя категории опроса _(только при свойстве category)_     |
| `[[+results_url]]`   | URL страницы результатов _(только при свойстве resultResource)_ |
| `[[+answers]]`       | Вывод ответов, сгенерированный для этого вопроса                   |

### tplVoteAnswer

| Placeholder    | Description                                           |
| -------------- | ----------------------------------------------------- |
| `[[+id]]`      | ID записи ответа                           |
| `[[+idx]]`     | Номер в цикле списка ответов (с 1)        |
| `[[+answer]]`  | Текст ответа                                       |
| `[[+votes]]`   | Число голосов за этот ответ                   |
| `[[+percent]]` | Доля голосов за этот ответ в процентах |

Примечание: для экрана результатов доступны те же плейсхолдеры плюс один дополнительный.

| Placeholder    | Description                                                           |
| -------------- | --------------------------------------------------------------------- |
| `[[+logdate]]` | Дата и время голоса текущего посетителя (по IP-адресу) |

## Примеры

Вызов по умолчанию даёт базовый вид формы голосования и результатов. Меняйте параметры выше или используйте propertyset.

``` php
[[!PollsLatest? &tplVote=`myVoteOuter` &tplVoteAnswer=`myVoteAnswer`]]
```

Последний опрос из категории: укажите category

``` php
[[!PollsLatest? &category=`1`]]
```

Последние вопросы из нескольких категорий:

``` php
[[!PollsLatest? &category=`1,3,5`]]
```
