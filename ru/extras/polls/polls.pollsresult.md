## Описание

Показывает результат опроса по заданному poll-id. По сути тот же вид, что после голосования через PollsLatest, но без обязательного голосования.

## Использование

Добавьте тег в шаблон или содержимое ресурса:

``` php
[[!PollsResult]]
```

Свойства см. в таблицах ниже.

## Доступные свойства

### Свойства шаблонов

| Name      | Description                                               | Default                 |
| --------- | --------------------------------------------------------- | ----------------------- |
| tpl       | Основной шаблон результатов опроса                | pollsLatestResultOuter  |
| tplAnswer | Шаблон ответов внутри внешнего шаблона | pollsLatestResultAnswer |

### Свойства ссылок

| Name          | Description                                                                                                    | Default |
| ------------- | -------------------------------------------------------------------------------------------------------------- | ------- |
| resultLinkVar | (Необязательно) При resultResource в PollsLatest то же имя GET-параметра, который ищет этот сниппет | poll    |

## Плейсхолдеры шаблонов

В шаблонах сниппета доступны такие плейсхолдеры:

### tpl

| Placeholder          | Description                                                                       |
| -------------------- | --------------------------------------------------------------------------------- |
| `[[+id]]`            | ID вопроса текущего опроса                                          |
| `[[+question]]`      | Текст вопроса                                                                 |
| `[[+totalVotes]]`    | Общее число голосов в опросе                                            |
| `[[+category_name]]` | Имя категории опроса _(только при свойстве category)_ |
| `[[+answers]]`       | Вывод ответов, сгенерированный для этого вопроса               |

### tplAnswers

| Placeholder    | Description                                                           |
| -------------- | --------------------------------------------------------------------- |
| `[[+id]]`      | ID записи ответа                                           |
| `[[+answer]]`  | Текст ответа                                                       |
| `[[+votes]]`   | Число голосов за этот ответ                                   |
| `[[+percent]]` | Доля голосов за этот ответ в процентах                 |
| `[[+logdate]]` | Дата и время голоса текущего посетителя (по IP-адресу) |

## Примеры

Базовый вызов без свойств. Можно создать propertyset.

``` php
[[!PollsResult?
  &tpl=`myVoteOuter`
  &tplAnswer=`myVoteAnswer`
  &resultLinkVar=`myPoll`
]]
```
