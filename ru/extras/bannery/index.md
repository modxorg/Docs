Показывает изображения со ссылками в заданных позициях на странице. Fork от BannerX Jeroen Kenters (автор убрал его из репозитория MODX).

## Использование

``` php
[[BannerY? &position=`1` &sortby=`RAND()` &limit=`1`]]
```

Случайным образом вернёт один активный баннер для позиции 1.

## Available Properties

| Name     | Description                                                                            | Default |
| -------- | -------------------------------------------------------------------------------------- | ------- |
| tpl      | Имя чанка-шаблона ресурса                                         | byAd    |
| sortdir  | Порядок результатов                                                                   | ASC     |
| sortby   | Случайный порядок результатов                                                         | RAND()  |
| limit    | Если не ноль, показать не больше X элементов                                   | 5       |
| position | Если не ноль, только изображения для указанной позиции. | 0       |

## Available Placeholders

| Name        | Description                          |
| ----------- | ------------------------------------ |
| adposition  |                                      |
| idx         | Индекс баннера в этой позиции |
| image       | Изображение баннера    |
| name        | Имя баннера     |
| url         | URL баннера      |
| description | Текст для баннера     |
