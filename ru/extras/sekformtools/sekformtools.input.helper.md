## Что такое input.helper?

Input helper обрабатывает jquery-вызовы для sekFormTools. Когда input.combobox или input.autocomplete вызываются с filter, input.helper по умолчанию указывает на helper.filter. Если из input.combobox или input.autocomplete передан helper\_snippet, input.helper вызывает указанный сниппет.

## Использование

Пример input.helper:

``` php
[[input.helper]]
```
