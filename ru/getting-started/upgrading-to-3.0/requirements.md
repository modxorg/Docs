MODX 3.0 поднял минимальную версию PHP до **PHP 7.2.5** (ранее для 2.x это был PHP 5.3). Обратите внимание на патч-версию: 7.2.0 требованию не удовлетворяет.

Планку подняли снова позже:

| Ветка MODX | Минимальный PHP (из `composer.json`) |
| --- | --- |
| 3.0 | 7.2.5 |
| 3.1 | 7.4 |
| 3.2+ | 8.1 |

Если вы обновляетесь с 2.x сразу до актуального релиза 3.x, закладывайте PHP 8.1+, а не только исходное требование 3.0 (7.2.5).

> Примечание: проверка PHP в самом установщике всё ещё ждёт PHP 7.4.0 (рекомендуемый 8.0.0), а `composer.json` требует 8.1. На PHP 7.4 Setup проходит, но `composer install` при обновлении упадёт — запускайте установщик на PHP 8.1+.

Ожидается, что минимальные требования дальше будут ближе следовать [официальным датам поддержки PHP](https://www.php.net/supported-versions.php).

Требования к веб-серверу и базе данных описаны на основной странице [Требования к серверу](getting-started/server-requirements).

Поддержка баз sqlsrv удалена. Потребуется [миграция на MySQL](getting-started/upgrading-to-3.0/sqlsrv).
