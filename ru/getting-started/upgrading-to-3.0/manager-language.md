В MODX 2.x, язык менеджера управлялся с помощью системного параметра `manager_language` (встроенных переопределений на уровне контекста или пользователя не было). В MODX 3 этот параметр был удален, и язык диспетчера вместо этого сохраняется в сеансе пользователя.

Текущий язык доступен в конфигурации MODX под ключом `cultureKey`: `$modx->config['cultureKey']`. Клиентские скрипты нужно перевести с `MODx.config.manager_language` на `MODx.config.cultureKey`.

При посещении менеджера он автоматически выберет наиболее вероятный желаемый язык на основе языка браузера. В нижней части экрана входа в систему можно выбрать другой язык.

Для динамического изменения языка при входе в систему используйте меню Admin > Переключить язык. (В 3.0 этот пункт находился в меню «Пользователь»; в 3.1 он переехал в «Admin» — на скриншоте ниже показано меню 3.0.)
