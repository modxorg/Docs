MODX отлично работает на большинстве виртуальных и облачных хостингов, а также на VPS и выделенных серверах. MODX написан на PHP, обычно использует базу данных MySQL и нуждается в веб-сервере вроде Apache или nginx для обработки запросов.

| Компонент | Минимум | Рекомендация |
| --------- | ------- | ------------ |
| PHP | 8.1 | 8.2 или выше |
| База данных | MySQL 5.7.x | MySQL 8.0+ / MariaDB 10.6+ / Percona Server 8.0+ |
| Веб-сервер | * | NGINX 1.18 или Apache 2.4 |

## PHP

Текущие релизы MODX 3 требуют **PHP 8.1 или выше**. Рекомендуется PHP 8.2+.

MODX 3.0 изначально требовал PHP 7.2. Минимум подняли до **PHP 8.1 в MODX 3.2**. Если вы ещё на более раннем релизе 3.x, проверьте требования той версии перед обновлением. Переход на 3.2 или новее означает, что хостинг должен поддерживать PHP 8.1+.

### Обязательные расширения

Эти расширения PHP требует ядро (тот же список `ext-*`, что в `composer.json`):

- `curl`
- `dom`
- `fileinfo`
- `gd`
- `json`
- `pdo`
- `simplexml`
- `xml`
- `xmlwriter`
- `zip`
- `zlib`

Для MySQL ещё нужен драйвер PDO MySQL (`pdo_mysql`). Setup проверяет его, когда вы выбираете драйвер MySQL.

На многих хостингах это пакеты вроде `php-xml` (покрывает `dom`, `simplexml`, `xml`, `xmlwriter`), `php-gd`, `php-curl`, `php-zip` и `php-mysql` / `php-pdo`.

### Рекомендуемые расширения

Composer также *предлагает* их. Для голой установки они не обязательны, но на практике почти всегда нужны:

- `mbstring`: при включённом `use_multibyte` и во многих дополнениях
- `iconv`: встроенная транслитерация псевдонимов
- `imagick`: более сильная обработка изображений, чем один `gd`
- `intl`: интернационализация

Рекомендуется `memory_limit` не ниже 64M.

## База данных

MODX поддерживает базу `mysql`. Есть сторонняя реализация `postgres`. Важно: дополнения тоже должны реализовать драйверы для своих таблиц, и чаще всего это делают только для `mysql`, поэтому MySQL: самый надёжный выбор.

> Примечание: поддержка sqlsrv удалена в MODX 3.0. См. [заметки о миграции с sqlsrv](getting-started/upgrading-to-3.0/sqlsrv), если нужно перевести старый сайт с SQL Server.

Минимальная поддерживаемая версия MySQL: 5.7. Рекомендуется MySQL 8.0+ или MariaDB 10.6+. Можно использовать кластеры вроде Galera.

Поддерживаются механизмы хранения MyISAM и InnoDB, а также наборы символов utf8 и utf8mb4. Для широкой поддержки UTF-8 лучше utf8mb4.

Требуются следующие разрешения: `SELECT`, `INSERT`, `UPDATE`, `DELETE` для обычной работы, `CREATE`, `ALTER`, `INDEX`, `DROP` для установки и обновления ядра и дополнений, а также `CREATE TEMPORARY TABLES`: некоторыми сторонними дополнениями.

## Веб-серверы

MODX работает на большинстве современных веб-серверов. Рекомендуются Apache 2.4+ или nginx 1.18.x.

Чтобы использовать [friendly urls](getting-started/friendly-urls), может понадобиться дополнительная настройка в зависимости от веб-сервера. Инструкции есть для [apache](getting-started/friendly-urls/apache), [nginx](getting-started/friendly-urls/nginx) и [lighttpd](getting-started/friendly-urls/lighttpd).

## Поддержка браузера для Менеджера

Для интерфейса менеджера поддерживаются такие браузеры на десктопе:

- Edge (последние 2 версии)
- Chrome (последние 2 версии)
- Firefox (последние 2 версии)
- Safari (последние 2 версии)

Мобильные и планшетные:

- Chrome for Android (последний)
- Safari on iOS (последний)

Менеджер может работать и в более старых браузерах, но официально они не поддерживаются.

Эти требования только для менеджера. Какие браузеры поддерживает ваш сайт, решаете вы.
