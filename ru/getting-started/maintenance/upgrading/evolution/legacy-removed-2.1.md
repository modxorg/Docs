## Методы, константы и переменные

Константы, переменные и методы API, помеченные к удалению в 2.0 или 2.1, окончательно удалены из кодовой базы MODX Revolution 2.1.

| Удалено                       | Примечания о замене или возможном обходном пути                                |
| ----------------------------- | ------------------------------------------------------------------------------ |
| IN\_PARSER\_MODE              | проверка контекста не mgr                                                      |
| IN\_MANAGER\_MODE             | проверка контекста mgr                                                         |
| `$_SESSION["mgrValidated"]`   | `modX->user->isAuthenticated('mgr')`                                           |
| `_SESSION["webValidated"]`    | `modX->user->isAuthenticated('web')`                                           |
| `$_SESSION["mgrInternalKey"]` | `modX->user->get('id')` при `modX->user->isAuthenticated('mgr')`          |
| `$_SESSION["webInternalKey"]` | `modX->user->get('id')` при `modX->user->isAuthenticated('web')`          |
| `$_SESSION["mgrShortname"]`   | `modX->user->get('username')` при `modX->user->isAuthenticated('mgr')`    |
| `$_SESSION["webShortname"]`   | `modX->user->get('username')` при `modX->user->isAuthenticated('web')`    |
