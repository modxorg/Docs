Наиболее важные изменения в MODX 2.3 (полный список не приводится):

| Изменение | Что это даёт |
| --- | --- |
| Маршрутизация на основе URL вместо modAction | Действие задаёт URL; modAction сохранён для обратной совместимости |
| Более мощные пространства имён: пользовательские типы ввода ТВ больше не требуют плагина и читаются из определённых каталогов | Пользовательский тип ввода ТВ можно положить в каталог вместо плагина |
| Заметно меньше connectors, которые нужно устанавливать | Значительно меньше файлов для установки |
| Новый дизайн интерфейса | Менеджер выглядит иначе |
| Новые классы REST Server для построения REST API на xPDOObjects. Пример <https://gist.github.com/splittingred/2346752> | REST-интерфейс поверх xPDOObjects почти без шаблонного кода |
| Темы Manager теперь используют Grunt и Sass, что позволяет быстро перекрашивать пользовательские темы | Пользовательскую тему можно перекрасить одной сборкой |
| Настройки можно применять на уровне группы пользователей | Значение настройки может отличаться для группы пользователей |
| Контексты можно переименовывать | Существующий контекст получает новое имя |
| Сжатие CSS/JS можно отключить при установке | Выход, если сжатие ломает сайт |
| Пол «Другой» в профилях пользователей | Профиль не ограничен двумя полами |
| Отдельная страница Media Manager в менеджере | Файлы медиа живут на отдельной странице менеджера |
| Предпросмотр ресурсов даже при отключённых front-end сессиях | Предпросмотр работает на сайтах, где отключены сессии посетителей |
| Системные настройки (`welcome_action`/`welcome_namespace`) для действия по умолчанию после входа или когда не передана переменная `?a` | Экран после входа настраивается |
| Редактирование ресурса в новом окне по Shift или щелчку средней кнопкой мыши по дереву ресурсов | Ресурс открывается во втором окне, дерево остаётся на месте |
| Выходной фильтр toPlaceholder больше не возвращает своё значение | Фильтр задаёт плейсхолдер и ничего не выводит |
