## Источники файлов

Главное изменение 2.2 — [источники файлов](building-sites/media-sources "Источники файлов"). Они абстрагируют вкладку «Файлы» в MODX: у дерева файлов может быть несколько источников — файловая система, корзина S3 и другие типы. Они встроены в большую часть менеджера, включая `MODX.Browser`, [переменные шаблона](building-sites/elements/template-variables "Переменные шаблона") и общие операции с файлами.

При обновлении это значит, что **все настройки `filemanager_*` и параметры ввода TV `basePath`/`baseUrl` устарели**. Менеджер MODX их больше не использует: `basePath` и `baseUrl` дерева задаёт источник, а не настройки или параметры ввода TV. Такой подход стабильнее.

MODX изменяет `baseUrl` и `basePath` источника по умолчанию для системных настроек `filemanager_*`. Для параметров ввода TV с собственным `basePath` создаются новые источники и автоматически связываются с этими TV.

Настройки `filemanager_*` **пользователя** переносить придётся вручную: пользовательских базовых путей источника больше нет. Используйте ACL у источника файлов с группой пользователей — как это сделать, описано [здесь](building-sites/media-sources/securing "Защита источника файлов").

## Статические элементы

MODX 2.2 вводит «статические» элементы: элементы, которые лежат в файловой системе через источник файлов. Создайте элемент (чанк, сниппет, шаблон и т. д.) и установите флажок «Статический». Появятся два поля:

- **Статический источник** — источник файлов, через который ищется статический файл. Выберите «Нет», чтобы указать абсолютный путь к файлу.
- **Статический файл** — путь к файлу относительно выбранного источника (или «Нет» для абсолютных путей). В этом поле можно использовать теги, например системные настройки.

Например, у источника файловой системы с относительным базовым путём `assets/` и статическим файлом `templates/test.tpl` шаблон найдут в `/path/to/my/modx/assets/templates/test.tpl`.

## Панели управления

Основная панель будет выглядеть немного иначе, но базовые виджеты и функции те же. Теперь можно создавать отдельные панели для групп пользователей и назначать им виджеты. См. документацию [Панели управления](building-sites/client-proofing/dashboards "Панели управления").

## Другие изменения

Настройки из этого раздела в одном месте:

| Настройка | Значение | Что меняется |
| --- | --- | --- |
| `context_tree_sort`, `context_tree_sortby` | `Yes`, `rank` | Сортировка контекстов в дереве ресурсов перетаскиванием (по умолчанию выключена) |
| `compress_js`, `compress_css` | `0` | Отключает сжатие CSS и JS в Менеджере (по умолчанию включено) |
| `tvs_below_content` | `Yes` | Показывает переменные шаблона под панелью «Содержимое» при редактировании ресурса |

### Сортировка контекстов в дереве

Сортировка контекстов в дереве ресурсов есть, но по умолчанию выключена. Установите системной настройке `context_tree_sort` значение Yes и измените поле `context_tree_sortby` на «rank»: тогда контексты в дереве можно сортировать перетаскиванием.

### Основная группа пользователей

У пользователей появилась «основная» группа — та, где их ранг равен 0. Если пользователь состоит только в одной группе, она и становится основной.

### Минификация в Менеджере

Менеджер MODX сжимает CSS и JS через [Google Minify](http://code.google.com/p/minify/). По умолчанию это включено; чтобы выключить, установите системные настройки `compress_js` и `compress_css` в `0`.

### Улучшения настройки формы

Из-за новых улучшений на экране редактирования ресурса настройка формы теперь может целиться в конкретные столбцы вкладок, куда переносятся TV. Их идентификаторы перечислены на вкладке «Вкладки» при редактировании набора настроек формы.

### Теги комментариев

В контенте можно использовать теги комментариев:

```php
[[- Тут комментарий]]
```

Всё внутри такого тега удаляется до отрисовки страницы.

### Перемещение TV под панель «Содержимое»

В 2.2 переменные шаблона при редактировании в ресурсе можно переместить под панель «Содержимое»: для этого измените параметр `tvs_below_content` на «Да».

### Обновление и установка через командную строку

В 2.2 MODX можно установить и обновить из командной строки. Подробнее — [Установка из командной строки](getting-started/installation/cli "Установка из командной строки").

### Предварительная обработка свойств по умолчанию и наборов свойств

Элементам можно включить предварительную обработку тегов MODX в значениях свойств по умолчанию и наборов свойств. Если флажок установлен на вкладке «Свойства», элемент разбирает все такие теги, и поведение совпадает со случаем, когда свойство задано прямо в строке тега. Без флажка теги приходят в элемент необработанными.
