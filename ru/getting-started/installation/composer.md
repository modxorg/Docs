Самый простой способ для разработчика попробовать MODX 3: Composer:

``` bash
composer create-project modx/revolution www 3.x-dev
```

MODX 3 установится в каталог `www`. Имя каталога можно заменить. После установки откройте `http://your-path-to-modx.tld/setup/` и пройдите обычный setup MODX.
