Небольшие руководства, каждое доводит одну задачу в MODX от начала до конца: собрать рабочий Extra, описать свои таблицы в базе, добавить своё поле в форму менеджера.

- [Developing an Extra](extending-modx/tutorials/developing-an-extra "Developing an Extra") — собрать рабочий Extra: Namespace, лексикон, страницу менеджера, грид, форму и транспортный пакет, который его устанавливает.
  - [Part 1](extending-modx/tutorials/developing-an-extra "Developing an Extra") — каркас.
  - [Part 2](extending-modx/tutorials/developing-an-extra/part-2 "Developing an Extra, part 2") — страница менеджера: грид, форма создания, редактирование в строке.
  - [Part 3](extending-modx/tutorials/developing-an-extra/part-3 "Developing an Extra, part 3") — скрипт сборки, который упаковывает компонент.
- [Using Custom Database Tables](extending-modx/tutorials/using-custom-database-tables "Using Custom Database Tables") — описать свои таблицы в схеме xPDO, сгенерировать модель, создать таблицы, прочитать и записать записи.
- [Custom Fields in the Manager](extending-modx/tutorials/custom-manager-fields "Custom Fields in the Manager") — добавить своё поле в форму менеджера через Плагин.
