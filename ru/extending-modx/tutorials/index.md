Небольшие руководства, каждое доводит одну задачу в MODX от начала до конца.

- [Developing an Extra, часть 1](extending-modx/tutorials/developing-an-extra "Developing an Extra") — каркас рабочего Extra: Namespace, модель, лексикон, сниппет.
- [Developing an Extra, часть 2](extending-modx/tutorials/developing-an-extra/part-2 "Developing an Extra, part 2") — страница менеджера: контроллер, грид с поиском и редактированием на месте, формы создания и обновления.
- [Developing an Extra, часть 3](extending-modx/tutorials/developing-an-extra/part-3 "Developing an Extra, part 3") — скрипт сборки, который упаковывает всё это в транспортный пакет.
- [Using Custom Database Tables](extending-modx/tutorials/using-custom-database-tables "Using Custom Database Tables") — описать свои таблицы в схеме xPDO, сгенерировать модель, создать таблицы, прочитать и записать записи.
- [Custom Fields in the Manager](extending-modx/tutorials/custom-manager-fields "Custom Fields in the Manager") — добавить своё поле в форму менеджера через Плагин.
