## xPDOTransport::getAttribute

Возвращает атрибут транспортного пакета, например его сигнатуру или версию.

## Синтаксис

```php
mixed getAttribute (string $key)
```

## Пример

```php
$signature = $transport->getAttribute('signature');
```
