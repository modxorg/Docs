## xPDOTransport::writePreserved

Записывает список файлов, которые нужно сохранить (не перезаписывать) при установке или удалении транспорта.

## Синтаксис

``` php
boolean writePreserved ()
```

## Пример

``` php
$transport->writePreserved();
```
