## xPDOTransport::loadPreserved

Загружает список файлов, которые нужно сохранить (не перезаписывать) при установке или удалении транспорта.

## Синтаксис

``` php
array loadPreserved ()
```

## Пример

``` php
$preserved = $transport->loadPreserved();
```
