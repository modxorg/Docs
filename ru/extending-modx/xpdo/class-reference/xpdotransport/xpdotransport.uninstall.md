## xPDOTransport::uninstall

Удалите vehicles в пакете из экземпляра спонсора xPDO.

## Синтаксис

```php
boolean uninstall ([array $options = array ()])
```

## Пример

Удалите этот транспортный пакет:

```php
$transport->uninstall();
```
