## xPDOTransport::install

Установите vehicles в упаковке в экземпляр xPDO спонсора.

Возвращает `true` в случае успеха.

## Синтаксис

```php
boolean install ([array $options = array ()])
```

## Пример

Устанавливает транспортный пакет:

```php
$transport->install();
```
