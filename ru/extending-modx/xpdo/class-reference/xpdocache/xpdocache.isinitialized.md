## xPDOCache::isInitialized

Показывает, был ли провайдер кеша успешно инициализирован и готов хранить и возвращать записи.

## Синтаксис

```php
boolean isInitialized ()
```

## Пример

```php
if ($provider->isInitialized()) {
    // safe to use the provider
}
```
