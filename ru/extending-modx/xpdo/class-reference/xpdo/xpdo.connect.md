## xPDO::connect

Создает соединение с базой данных PDO для использования xPDO. Возвращает `true`, если соединение было создано успешно.

## Синтаксис

```php
boolean connect ([array $driverOptions = array ()])
```

## Пример

```php
$xpdo->connect();
```
