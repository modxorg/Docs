## xPDO::getLogLevel

Возвращает текущий уровень журналирования экземпляра xPDO в виде целочисленной константы (например, `xPDO::LOG_LEVEL_INFO`).

## Синтаксис

```php
integer getLogLevel ()
```

## Пример

```php
$level = $xpdo->getLogLevel();
```
