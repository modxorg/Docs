## xPDOObject::validate()

Проверяет значения полей с помощью валидатора, который возвращает [`getValidator()`](extending-modx/xpdo/class-reference/xpdoobject/validation/getvalidator "getValidator"); по умолчанию это `xPDO\Validation\xPDOValidator`.

## Синтаксис

```php
boolean validate ([array $options = array()])
```
