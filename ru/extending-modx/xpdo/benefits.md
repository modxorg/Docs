Есть несколько причин использовать xPDO. Кратко по верхнему уровню:

- Object-relational bridge (ORB): постоянные объекты отображаются на структуры реляционной БД с учётом платформы

- Использует PDO, стандартный слой доступа к БД для PHP 5.1+, для быстрой работы с разными СУБД

- Даёт реализацию PDO для PHP 4.3.x, 4.4.x и 5.0.x. На части 5.0.x PDO может быть из PECL, но не везде. Поддержка PHP 4 (с ограничениями по полному PDO) была одной из целей проекта xPDO

- Код лёгкий и подгружает только нужное, почти без накладных расходов. Используются общие методы и аксессоры, ядро на чистом PHP без разбора XML-конфигов и лишней сериализации

- Сочетает оптимизацию под платформу с объектной абстракцией

- Работает с любой БД, доступной через PDO-драйвер. (Примечание: для первых релизов OpenExpedio-реализаций PDO планировались MySQL, PostgreSQL и SQLite)

- Быстро генерирует классы и карты метаданных из модели xPDO. (Модель: XML-схема object-relational map)

- Быстро строит определение модели xPDO по уже существующей БД
