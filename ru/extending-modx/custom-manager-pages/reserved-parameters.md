При создании [страниц CMP](extending-modx/custom-manager-pages "Custom Manager Pages") или других интеграций обычно можно использовать любые параметры, но есть исключения.

## Зарезервированные параметры внутри менеджера MODX

Ниже приведен список параметров, используемых менеджером MODX в различных целях. Следует избегать их использования на [страницах CMP](extending-modx/custom-manager-pages "Custom Manager Pages"):

- **a** используется для определения действия или контроллера
- **namespace** указывает, к какому пространству имен принадлежит действие; если не указано, по умолчанию `core`
- **context_key** указывает один из ваших контекстов (например, "web" или "mgr")
- **wctx** указывает "рабочий контекст" — контекст, которому принадлежит текущий объект, а не контекст "mgr"
- **class_key** указывает имя класса, например, при создании веб-ссылки или статического ресурса
- **id** указывает идентификатор, с которым действие или контроллер работает по умолчанию

Примечание: `action` **не** является параметром менеджера — менеджер читает только `a`. Параметр `action` используется коннекторами для выбора процессора.

Системные настройки, влияющие на маршрутизацию менеджера и ресурсы: `manager_theme` (выбирает тему, чьи каталоги `controllers/` и `templates/` ищутся первыми), `welcome_action` (действие страницы Welcome менеджера), а также `manager_path` / `manager_url` (физическое расположение менеджера и его URL).

## Зарезервированные параметры на стороне сайта

- **q** используется, когда включены дружествые URL, для маршрутизации запроса к нужному ресурсу. Можно изменить системной настройкой `request_param_alias`, но рекомендуется оставить без изменений.
- **id** используется, когда дружествые URL отключены, для получения текущего ресурса. Можно изменить системной настройкой `request_param_id`, но рекомендуется оставить без изменений.
