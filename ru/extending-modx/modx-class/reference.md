## modX Класс

Это базовый класс MODX Revolution: он используется для многих основных методов MODX. Он расширяет [xPDO](extending-modx/xpdo "xPDO") класс.

## Методы

Полный список методов `modX` ведётся на странице [modX объект](extending-modx/modx-class/index "modX объект").
