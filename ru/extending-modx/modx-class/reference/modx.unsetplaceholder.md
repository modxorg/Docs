## modX::unsetPlaceholder

Сбрасывает значение плейсхолдера по ключу.

## Синтаксис

``` php
void unsetPlaceholder (string $key)
```

## Пример

``` php
$modx->unsetPlaceholder('myPlaceholder');
```
