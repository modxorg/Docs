## modX::removeAllEventListener

Удаляет все зарегистрированные события для текущего запроса.

## Синтаксис

``` php
void removeAllEventListener ()
```

## Пример

Предотвратить запуск любых событий:

``` php
$modx->removeAllEventListener();
```
