## modX::reloadConfig

Перезагружает настройки конфигурации. Полезно в тех случаях, когда вы загружали некоторые настройки динамически.

## Синтаксис

``` php
array reloadConfig ()
```

## Пример

``` php
$modx->reloadConfig();
```
