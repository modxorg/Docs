## Событие: OnResourceToolbarLoad

Событие запускается при загрузке панели инструментов дерева ресурсов в менеджере и позволяет плагинам изменять элементы панели.

- Служба: 1 - Parser Service Events
- Group: Resources

## Параметры события

| Имя   | Описание                                                    |
| ----- | ----------------------------------------------------------- |
| items | Массив элементов панели инструментов, передаётся по ссылке. |
