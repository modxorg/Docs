## Событие: OnUserActivate

Может использоваться сторонними компонентами (такими как [Login](/extras/login "Login")) когда пользователь активируется.

Также запускается, когда пользователь установлен как «активный» из менеджера.

- Служба: 1 - Parser Service Events
- Group: Users

## Параметры события

| Имя  | Описание                                                                                                              |
| ---- | --------------------------------------------------------------------------------------------------------------------- |
| id   | ID активированного пользователя.                                                                                      |
| user | Ссылка на объект modUser.                                                                                             |
| mode | `modSystemEvent::MODE_UPD`, когда редактируется один пользователь через форму пользователя, или `multiple` при массовой активации пользователей. |
