## Событие: OnPropertySetBeforeRemove

Событие запускается непосредственно перед удалением набора свойств.

- Служба: 1 - Parser Service Events
- Group: Property Sets

## Параметры события

| Имя         | Описание                                        |
| ----------- | ----------------------------------------------- |
| propertySet | Ссылка на объект `modPropertySet`.              |
| ancestors   | Массив предков для каскадной операции удаления. |
