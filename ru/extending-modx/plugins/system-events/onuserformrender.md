## Событие: OnUserFormRender

Событие запускается при построении страницы формы пользователя в менеджере; вывод, возвращённый плагином, встраивается в страницу (кавычки и переводы строк экранируются), поэтому его можно использовать для внедрения JavaScript в форму пользователя.

- Служба: 1 - Parser Service Events
- Group: Users

## Параметры события

| Имя  | Описание                                                                                           |
| ---- | -------------------------------------------------------------------------------------------------- |
| id   | ID редактируемого пользователя или 0 при создании нового пользователя.                             |
| user | Ссылка на объект `modUser`; передаётся только при редактировании существующего пользователя.       |
| mode | `modSystemEvent::MODE_NEW` при создании пользователя, `modSystemEvent::MODE_UPD` при редактировании.|
