## Событие: OnManagerAuthentication

Событие запускается непосредственно перед тем, как пользователь аутентифицируется или его сеанс добавляется в контекст менеджера. Это событие может использоваться для обеспечения внешней аутентификации. Это событие используется для разрешения входа в систему.

Если его вывод равен `true` или массиву, в котором хотя бы один индекс равен `true`, MODX будет считать, что пользователь успешно вошел в систему, и пропустит аутентификацию по умолчанию с помощью пароля.

- Служба: 2 - Manager Access Events
- Group: Security

## Параметры события

| Имя                | Описание                                                                                    |
| ------------------ | ------------------------------------------------------------------------------------------- |
| **&** user         | Ссылка на объект `modUser`. **Передаётся по ссылке**                                        |
| password           | Предоставленный пароль.                                                                     |
| rememberme         | Запоминать ли пользователя с помощью cookie.                                                |
| lifetime           | Время жизни файла cookie сеанса.                                                            |
| **&** loginContext | Ключ контекста, в котором происходит вход в систему. **Передаётся по ссылке**               |
| **&** addContexts  | Дополнительные контексты, в которых вход в систему также происходит. **Передаётся по ссылке** |

## Рабочий процесс входа в систему

1. _[_OnBeforeWebLogin_](extending-modx/plugins/system-events/onbeforeweblogin)_ || _[OnBeforeManagerLogin](extending-modx/plugins/system-events/onbeforemanagerlogin)_ - Внутри этого события разработчик может проверить наличие ошибочных параметров, которые **запретят** дальнейший процесс входа. Если плагины, выполняемые этим событием, возвращают что-то, кроме `true`, вход в систему будет прерван с указанной ошибкой.
2. _[OnUserNotFound](extending-modx/plugins/system-events/onusernotfound)_ - Это событие выполняется, только если указанное имя пользователя не найдено в базе данных MODX. Разработчик может передать в выводе события собственный объект `modUser`, чтобы продолжить процесс входа в систему.
3. _[OnWebAuthentication](extending-modx/plugins/system-events/onwebauthentication)_ || **_OnManagerAuthentication_** - Внутри этого события разработчик может проверить параметры, которые **отменят проверку по умолчанию паролем** и **позволят** продолжить процесс входа. Если один из плагинов, выполняемых этим событием, возвращает `true`, пользователь считается проверенным и вошедшим в систему.
4. _[OnWebLogin](extending-modx/plugins/system-events/onweblogin)_ || _[OnManagerLogin](extending-modx/plugins/system-events/onmanagerlogin)_ - Это событие вызывается после завершения процесса входа в систему; пользователь считается вошедшим в систему. Оно **не меняет поведение** процесса входа.
