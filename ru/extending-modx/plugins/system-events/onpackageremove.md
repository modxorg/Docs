## Событие: OnPackageRemove

Срабатывает после удаления или очистки пакета через менеджер пакетов.

- Служба: 2 - Manager Access Events
- Group: Package Manager

## Параметры события

| Имя     | Описание                                                             |
| ------- | -------------------------------------------------------------------- |
| package | Ссылка на экземпляр modTransportPackage, который был удалён.          |
