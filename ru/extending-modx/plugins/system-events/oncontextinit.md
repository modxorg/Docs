## Событие: OnContextInit

Событие запускается после успешной инициализации контекста.

- Служба: 1 - Parser Service Events
- Group: Contexts

## Параметры события

| Имя        | Описание                                                  |
| ---------- | --------------------------------------------------------- |
| contextKey | Ключ инициализированного контекста.                       |
| options    | Массив опций, использованных для инициализации контекста. |
