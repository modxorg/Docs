## Событие: OnMediaSourceFormDelete

Событие запускается после удаления медиа-источника.

- Служба: 1 - Parser Service Events
- Group: Media Sources

## Параметры события

| Имя    | Описание                                          |
| ------ | ------------------------------------------------- |
| id     | ID удалённого медиа-источника.                    |
| source | Ссылка на объект `modMediaSource`.                |
| object | Ссылка на объект `modMediaSource`.                |
