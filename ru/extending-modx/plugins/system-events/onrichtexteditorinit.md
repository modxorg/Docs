## Событие: OnRichTextEditorInit

Вызывается каждый раз, когда может быть использован Richtext Editor.

- Служба: 1 - Parser Service Events
- Group: RichText Editor

## Параметры события

Когда событие вызывается из контроллера редактирования ресурса:

| Имя       | Описание                                                       |
| --------- | -------------------------------------------------------------- |
| editor    | Указанный редактор, который пользователь хочет использовать.   |
| elements  | Массив элементов для преобразования в RTE.                     |
| id        | ID ресурса (пусто для нового ресурса).                         |
| resource  | Ссылка на объект ресурса.                                      |
| mode      | `new` или `upd`, в зависимости от того, новый ли ресурс.       |

Когда событие вызывается из контроллеров создания/редактирования чанка, ключ `editor` **не** передаётся; отправляются только `elements` и `mode` (контроллер обновления также передаёт `chunk` — ссылку на редактируемый чанк).

Передаётся, когда событие вызывается из рендерера вывода RTE ТВ на фронтенде:

| Имя         | Описание                                                     |
| ----------- | ------------------------------------------------------------ |
| forfrontend | Загрузить RTE во фронтенд-контексте, а не в менеджере.       |
| width       | Запрашиваемая ширина RTE.                                    |
| height      | Запрашиваемая высота RTE.                                    |
