## Событие: OnFileManagerFileUpdate

Событие запускается после обновления файла через менеджер.

- Служба: 1 - Parser Service Events
- Group: System

## Параметры события

| Имя    | Описание                                   |
| ------ | ------------------------------------------ |
| path   | Содержит полный путь к обновлённому файлу. |
| source | Содержит объект `modMediaSource`.          |
