## Событие: OnBeforeRegisterClientScripts

Событие запускается перед добавлением зарегистрированных клиентских скриптов в вывод веб-страницы. Оно срабатывает только для ответов `text/html`; бинарные и другие типы содержимого пропускаются.

- Служба: 5 - Template Service Events
- Group: System

## Параметры события

Отсутствуют.
