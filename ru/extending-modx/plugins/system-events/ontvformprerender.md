## Событие: OnTVFormPrerender

Событие запускается в контроллере создания/обновления TV после обработки страницы и непосредственно перед рендерингом шаблона формы; возвращённый вывод вставляется в HTML страницы.

- Служба: 1 - Parser Service Events
- Group: Template Variables

## Параметры события

| Имя | Описание                                                                     |
| --- | ---------------------------------------------------------------------------- |
| mode| `'new'` или `'upd'` в зависимости от ситуации.                               |
| id  | ID TV. Для новых элементов равен 0.                                          |
| tv  | Ссылка на объект `modTemplateVar`. Не передаётся при создании нового элемента.|
