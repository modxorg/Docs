## Событие: OnResourceDelete

Событие запускается сразу после удаления ресурса — из процессора `Resource\Delete`. Оно также вызывается процессором `Resource\Update`, когда ресурс удаляется через форму редактирования; при этом вызов передаёт только `id` и `resource`.

- Служба: 1 - Parser Service Events
- Group: Resources

## Параметры события

| Имя       | Описание                                                                                                     |
| --------- | ------------------------------------------------------------------------------------------------------------ |
| id        | Идентификатор удалённого ресурса.                                                                            |
| children  | Массив идентификаторов дочерних ресурсов, удалённых вместе с ним. Не передаётся при удалении из формы редактирования ресурса. |
| resource  | Ссылка на удалённый объект `modResource`.                                                                    |
