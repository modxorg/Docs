## Событие: OnUserDeactivate

Событие запускается после деактивации пользователя, когда изменение сохранено — когда при редактировании формы пользователя снимается флаг активности, либо когда пользователи деактивируются массово из сетки пользователей.

- Служба: 1 - Parser Service Events
- Group: Users

## Параметры события

| Имя  | Описание                                                                                                   |
| ---- | ---------------------------------------------------------------------------------------------------------- |
| id   | ID деактивированного пользователя.                                                                         |
| user | Ссылка на объект `modUser`.                                                                                |
| mode | `modSystemEvent::MODE_UPD` при редактировании одного пользователя или `multiple` при массовой деактивации. |
