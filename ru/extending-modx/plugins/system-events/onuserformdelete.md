## Событие: OnUserFormDelete

Срабатывает после удаления пользователя.

- Служба: 1 - Parser Service Events
- Group: Users

## Параметры события

| Имя    | Описание                                                                                   |
| ------ | ------------------------------------------------------------------------------------------ |
| user   | Ссылка на объект modUser.                                                                  |
| id     | ID пользователя.                                                                           |
| object | Ссылка на удалённый объект (тот же экземпляр modUser, что и `user`).                       |

Событие также вызывается для каждого пользователя при массовом удалении из сетки пользователей.
