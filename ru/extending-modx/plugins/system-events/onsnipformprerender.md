## Событие: OnSnipFormPrerender

Событие запускается в контроллере создания/обновления сниппета после обработки страницы и непосредственно перед рендерингом шаблона формы; возвращённый вывод вставляется в HTML страницы.

- Служба: 1 - Parser Service Events
- Group: Snippets

## Параметры события

| Имя    | Описание                                                                    |
| ------ | --------------------------------------------------------------------------- |
| mode   | `'new'` или `'upd'` в зависимости от ситуации.                              |
| id     | ID сниппета. Для новых элементов равен 0.                                   |
| snippet| Ссылка на объект `modSnippet`. Не передаётся при создании нового элемента.  |
