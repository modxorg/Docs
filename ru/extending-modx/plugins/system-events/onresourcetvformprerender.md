## Событие: OnResourceTVFormPrerender

Событие запускается перед рендерингом вкладки Template Variables в редакторе ресурса (и при создании, и при редактировании ресурса).

- Служба: 1 - Parser Service Events
- Group: Resources

## Параметры события

| Имя      | Описание                                    |
| -------- | ------------------------------------------- |
| resource | ID редактируемого ресурса.                  |
