## Событие: OnEmptyTrash

Событие запускается после очистки корзины для сайта. Также вызывается процессором `resources/trash/purge` при очистке уже удалённых ресурсов.

- Служба: 1 - Parser Service Events
- Group: Resources

## Параметры события

| Имя          | Описание                                                                    |
| ------------ | --------------------------------------------------------------------------- |
| ids          | Массив идентификаторов ресурсов, которые были успешно удалены навсегда.     |
| resources    | Массив объектов `modResource`, которые были удалены. **Передаётся по ссылке.** |
| num\_deleted | Количество фактически удалённых ресурсов.                                   |
