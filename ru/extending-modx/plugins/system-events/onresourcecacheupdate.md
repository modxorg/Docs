## Событие: OnResourceCacheUpdate

Событие запускается после очистки кэшированной страницы ресурса.

- Служба: 1 - Parser Service Events
- Group: Resources

## Параметры события

| Имя | Описание                                             |
| --- | ---------------------------------------------------- |
| id  | ID ресурса, кэш которого был очищен.                 |
