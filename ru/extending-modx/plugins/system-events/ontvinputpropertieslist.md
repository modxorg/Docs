## Событие: OnTVInputPropertiesList

Событие запускается, пока процессоры свойств ввода TV собирают каталоги с файлами определений свойств ввода, — так плагины могут добавить собственные.

- Служба: 1 - Parser Service Events
- Group: Template Variables

## Параметры события

| Имя     | Описание                                          |
| ------- | ------------------------------------------------- |
| context | Ключ контекста, для которого собираются каталоги. |
