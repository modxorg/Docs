## Событие: OnTVOutputRenderList

Событие запускается, пока собирается список каталогов рендеринга вывода TV, — в `modTemplateVar::getRenderDirectories()` и в процессоре `GetOutputs`.

- Служба: 1 - Parser Service Events
- Group: Template Variables

## Параметры события

| Имя     | Описание                                                 |
| ------- | -------------------------------------------------------- |
| context | Ключ контекста, для которого собираются каталоги.         |
