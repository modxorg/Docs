## Событие: OnUserBeforeAddToGroup

Событие запускается перед сохранением записи о членстве, когда пользователь добавляется в группу пользователей — при добавлении участника на форме группы, при сохранении пользователя с назначенными группами на форме пользователя или при создании нового пользователя с назначенными группами.

- Служба: 1 - Parser Service Events
- Group: User Groups

## Параметры события

| Имя        | Описание                                           |
| ---------- | -------------------------------------------------- |
| user       | Ссылка на объект `modUser`.                        |
| usergroup  | Ссылка на объект `modUserGroup`.                   |
| membership | Ссылка на создаваемый объект `modUserGroupMember`. |

Возврат непустого сообщения из плагина не позволяет добавить пользователя в группу.
