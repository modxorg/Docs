## Событие: OnResourceAutoPublish

Событие запускается сразу после автоматической публикации.

- Служба: 1 - Parser Service Events
- Group: Resources

## Параметры события

| Имя     | Описание                                                                                                                                                                                                                                       |
| ------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| results | Массив результатов автоматической публикации: `published` и `unpublished` (количество затронутых ресурсов), `published_resources` и `unpublished_resources` (массивы записей ресурсов), а также `errors`. Событие вызывается только если состояние изменил хотя бы один ресурс. |
