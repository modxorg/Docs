## Событие: OnMediaSourceBeforeFormDelete

Событие запускается непосредственно перед удалением медиа-источника.

- Служба: 1 - Parser Service Events
- Group: Media Sources

## Параметры события

| Имя    | Описание                           |
| ------ | ---------------------------------- |
| id     | ID медиа-источника.                |
| source | Ссылка на объект `modMediaSource`. |
| object | Ссылка на объект `modMediaSource`. |
