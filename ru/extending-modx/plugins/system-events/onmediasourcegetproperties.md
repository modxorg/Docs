## Событие: OnMediaSourceGetProperties

Событие запускается после сбора свойств медиа-источника и позволяет их изменять.

- Служба: 1 - Parser Service Events
- Group: Media Sources

## Параметры события

| Имя        | Описание                                       |
| ---------- | ---------------------------------------------- |
| properties | Массив свойств медиа-источника.                |
