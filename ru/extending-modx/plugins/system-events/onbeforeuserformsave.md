## Событие: OnBeforeUserFormSave

Событие запускается после отправки формы, но перед тем, как пользователь будет сохранён в менеджере.

- Служба: 1 - Parser Service Events
- Group: Users

## Параметры события

| Имя    | Описание                                                     |
| ------ | ------------------------------------------------------------ |
| mode   | Либо 'upd' или 'new', в зависимости от обстоятельств.        |
| user   | Ссылка на объект modUser.                                    |
| id     | Идентификатор пользователя. Будет 0 для новых пользователей. |
| data   | Текущие поля пользователя в виде массива.                    |
| object | Псевдоним `user` — ссылка на тот же объект.                  |
