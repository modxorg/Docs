## Событие: OnTVInputRenderList

Событие запускается, пока собирается список каталогов рендеринга ввода TV, — в `modTemplateVar::getRenderDirectories()` и в процессоре `GetInputs`.

- Служба: 1 - Parser Service Events
- Group: Template Variables

## Параметры события

| Имя     | Описание                                          |
| ------- | ------------------------------------------------- |
| context | Ключ контекста, для которого собираются каталоги. |
