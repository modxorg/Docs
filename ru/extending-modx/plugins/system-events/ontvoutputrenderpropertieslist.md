## Событие: OnTVOutputRenderPropertiesList

Событие запускается, пока процессоры свойств рендеринга вывода TV собирают каталоги с файлами определений свойств рендеринга, — так плагины могут добавить собственные.

- Служба: 1 - Parser Service Events
- Group: Template Variables

## Параметры события

| Имя     | Описание                                                 |
| ------- | -------------------------------------------------------- |
| context | Ключ контекста, для которого собираются каталоги.         |
