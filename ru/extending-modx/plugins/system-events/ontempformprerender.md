## Событие: OnTempFormPrerender

Событие запускается в контроллере создания/обновления шаблона после обработки страницы и непосредственно перед рендерингом шаблона формы; возвращённый вывод вставляется в HTML страницы.

- Служба: 1 - Parser Service Events
- Group: Templates

## Параметры события

| Имя      | Описание                                                                     |
| -------- | ---------------------------------------------------------------------------- |
| mode     | `'new'` или `'upd'` в зависимости от ситуации.                               |
| id       | ID шаблона. Для новых элементов равен 0.                                     |
| template | Ссылка на объект `modTemplate`. Не передаётся при создании нового элемента.  |
