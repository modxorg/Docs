## Событие: OnParseDocument

Событие запускается каждый раз, когда разбираются теги элементов. Это может происходить много раз во время загрузки ресурса. Чтобы ссылаться на содержимое ресурса, используйте `$modx->documentOutput`.

- Служба: 5 - Template Service Events
- Group: System

## Параметры события

| Имя     | Описание                                                                                            |
| ------- | --------------------------------------------------------------------------------------------------- |
| content | Разбираемое содержимое документа, передаётся по ссылке. Также доступно как `$modx->documentOutput`. |
