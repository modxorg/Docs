Управление меню в MODX осуществляется через пользовательское меню (справа вверху) → **Админ → Меню** (`?a=system/action`; страница требует права `actions`).

До MODX 2.3 вам также необходимо использовать [Действия](extending-modx/menus/actions) для подключения пункта меню к контроллеру — у действий были собственные ID и объекты (`modAction`). Начиная с 2.3 действия устарели, а в 3.x удалены совсем; пункт меню теперь напрямую указывает на контроллер по имени. [Узнайте больше о добавлении пользовательских страниц менеджера.](extending-modx/custom-manager-pages)

## Объект modMenu

Пункт меню — это запись таблицы `menus` (`MODX\Revolution\modMenu`):

| Поле | Назначение |
| --- | --- |
| `text` | Подпись: ключ лексикона вроде `mycomponent_menu_desc` или обычный текст |
| `parent` | Ключ родительского меню (`main`, `components`, `admin`, …) или пусто для верхнего уровня |
| `action` | Путь к контроллеру строкой, например `resource/update` или `home` (не ID) |
| `namespace` | Компонент, которому принадлежит action; по умолчанию `core` |
| `handler` | Необязательный JavaScript; если задан (и нет `action`), пункт выполняет его вместо открытия страницы |
| `params` | Дополнительные параметры URL, дописываемые к `?a=…` |
| `permissions` | Ключи прав через запятую; без них пункт скрывается, а его страница возвращает отказ доступа |
| `description`, `icon`, `menuindex` | Подпись, класс иконки, порядок сортировки |
