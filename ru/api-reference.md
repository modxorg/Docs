Сгенерированная документация по PHP-классам: [api.modx.com](https://api.modx.com/revolution/2.2/).

Опубликованное дерево относится к MODX Revolution **2.2**. Сигнатуры там из эпохи 2.x. Для MODX 3 опирайтесь на этот сайт как на ориентир и сверяйте поведение с [исходниками revolution 3.x](https://github.com/modxcms/revolution/tree/3.x), если что-то выглядит иначе.

Полезные точки входа:

- [xPDO](https://api.modx.com/revolution/2.2/db_core_xpdo_xpdo.class.html)
- [xPDOObject](https://api.modx.com/revolution/2.2/db_core_xpdo_om_xpdoobject.class.html)
- [modX](https://api.modx.com/revolution/2.2/db_core_model_modx_modx.class.html)

Развёрнутые руководства по тем же API — в разделе [Разработка с MODX](extending-modx) и в [xPDO](extending-modx/xpdo).
