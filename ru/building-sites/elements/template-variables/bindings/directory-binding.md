## Что такое @DIRECTORY привязка?

Привязка DIRECTORY перечисляет читаемые файлы и каталоги одной папки. Ставьте её с типом ввода **Listbox (Single-Select)**, когда редактор выбирает файл, например логотип или mp3. Из списка выпадают только `.`, `..`, `.svn`, `.git` и `.DS_Store`. Файл вроде `.htaccess` в список попадает.

## Использование

Когда вы создаете переменную шаблона, поместите следующий текст в поле **Значения параметров ввода**:

``` php
@DIRECTORY /path/to/some_directory
```

Рядом с ней ставьте тип ввода **Listbox (Single-Select)**, чтобы редактор выбрал один файл из списка.

В MODX Revolution путь, используемый для привязки @DIRECTORY, относится к корню сайта. Это **НЕ** абсолютный путь к файлу. Если вы хотите перечислить файлы выше корня вашего сайта, вы должны использовать синтаксис "..", например, **@DIRECTORY /../dir\_above\_root** Эта привязка будет работать с косой чертой в имени каталога или без нее.

Шаблон может вывести выбранный путь:

``` html
<img src="[[*myTV]]" alt="" />
```

## Дополнительная информация

Маска вроде `*.jpg` список не фильтрует. Так не работает:

``` php
@DIRECTORY /list/*.jpg  # doesn't work!
```

Существуют сниппеты кода PHP, которые эмулируют эту функцию. Смотрите следующую ветку форума: <https://forums.modx.com/index.php/topic,3124.0.html>

## Безопасность

От того, как выбранный файл попадает на страницу, зависит риск. Не берите этой привязкой JavaScript, который страница потом выполняет: пользователь, который может загрузить файл, сможет его запустить. Осторожно показывайте пользователям структуру каталогов.
