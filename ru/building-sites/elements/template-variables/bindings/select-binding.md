## Что такое @SELECT привязка?

Привязка @SELECT вызывает запрос к базе данных на основе предоставленного значения и возвращает результат.

## Синтаксис

``` sql
@SELECT `pagetitle` AS `name`,`id` FROM `[[+PREFIX]]site_content` WHERE `published` = 1 AND `deleted` = 0
```

Сначала напишите запрос на [MySQL](http://dev.mysql.com/doc/refman/5.1/en/) и выполните его в командной строке MySQL. Ловушки перечислены в разделе «Ошибки». Когда запрос выполняется, сделайте из него привязку:

- добавьте `@` перед SELECT
- не ставьте точку с запятой в конце запроса

Привязку ставят в одно из двух мест:

- Поле TV на ресурсе. У этого ресурса должен быть [шаблон](building-sites/elements/templates "Шаблоны"), к которому назначена эта [переменная шаблона](building-sites/elements/template-variables "Переменные шаблона"). Вставьте в поле текст `@SELECT`.
- Поле **Значение по умолчанию** у переменной шаблона. Если вы меняете умолчание TV, которую ресурсы уже используют, страницы могут ждать той формы вывода, которую возвращает эта привязка.

Выберите два столбца. MODX дописывает `SELECT ` впереди того, что вы написали. Первый столбец служит подписью, второй сохраняемым значением. Они склеиваются как `подпись==значение`. Строки склеиваются через `||`. Запрос с одним столбцом используется как есть. Перевод строки привязку не обрывает.

Например, чтобы получить список активных пользователей в окне SELECT:

``` sql
@SELECT `username` AS `name`,`id` FROM `[[+PREFIX]]users` WHERE `active` = 1
```

## Альтернативы

Ту же работу может сделать [сниппет](extending-modx/snippets "Сниппеты"). Берите сниппет, если запрос должен читать другие TV или выводу нужно своё оформление. Привязка даёт короткий путь.

## Наличие пустой Опции

У списка из этого запроса нет пустой строки, пока её не вернёт сам запрос. Добавьте её через `UNION ALL`:

``` sql
@SELECT '-none-' AS username, 0 AS id UNION ALL
SELECT `username`,`id` FROM `[[+PREFIX]]users` WHERE `active` = 1 ORDER BY username ASC
```

`ORDER BY` может увести пустую строку с первого места. В примере имя пользователя начинается с дефиса, поэтому оно сортируется первым.

## Как выглядят строки

Запрос из двух столбцов, как в примере с пользователями, возвращает строки вида `username==id`. Между строками стоит `||`. Такой список `подпись==значение` ждёт Listbox. Запрос со соединениями по значениям TV проще написать сниппетом.

## ОШИБКИ


Запрос может выполниться в командной строке MySQL и всё равно сорваться в привязке:

- Не заканчивайте запрос точкой с запятой.
- Перевод строки привязку не обрывает.
- Проверьте имена таблиц и префикс, прежде чем вставлять запрос в TV. Если запрос не выполнился, смотрите журнал ошибок MODX.

## Следующий шаг: форматирование

Тип вывода может отформатировать возвращённое значение. Для оформления, которого в типах вывода нет, используйте [сниппет](extending-modx/snippets "Сниппеты").

## Безопасность

Привязка выполняет ваш текст одним запросом, который начинается с SELECT, через соединение MODX с базой. Код не ищет в этом тексте UPDATE, INSERT, DELETE или DROP. Сам он эти команды не запускает. Кто может править привязку, может прочитать строки, доступные этому соединению. Сюда входит сохранённый хэш чужого пароля и чужие ресурсы.
