## Что такое @INHERIT привязка?

Привязка @INHERIT ищет ту же TV у родительского ресурса. Если у родителя тоже стоит @INHERIT, поиск идёт выше. Если цепочка дошла до корня и значения нет, TV пустая. Это не `0`. Запасное значение у корня пишите после команды: `@INHERIT запас`.

Пока ребёнок показывает унаследованное значение, MODX не хранит для него отдельное значение.

**Будь осторожен**
Значение не всегда записывается в базу данных, когда вы используете @INHERIT.

Пока значение ребёнка совпадает с тем, что вернул бы `@INHERIT`, MODX не хранит для ребёнка отдельное значение. Поздние правки родителя видны у ребёнка. Своё значение на ребёнке поиск останавливает. Очистка поля поиск не включает: пустое значение сохраняется, и ребёнок остаётся пустым. Чтобы снова наследовать, задайте ребёнку значение, которое совпадёт с уже обработанным `@INHERIT`. Тогда MODX уберёт собственное значение ребёнка.

## Использование

Это используется, когда вы определяете переменную шаблона. Вы вставляете следующее в поле «Значение по умолчанию» TV:

``` php
@INHERIT
```
