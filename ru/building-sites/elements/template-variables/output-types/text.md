## Тип вывода TV - Текст

Этот тип вывода печатает значение TV как текст.

Одно текстовое значение выводится как сохранено. У **Check Box** и **Listbox (Multi-Select)** из значения убирается `||`, и выбранные пункты склеиваются без разделителя между ними.

## Свойства вывода

Своих полей у этого типа нет.
