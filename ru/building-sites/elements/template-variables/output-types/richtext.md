## Тип вывода TV - Rich Text

Этот тип вывода ставит на страницу textarea и запускает в ней редактор. Сохранённый HTML как содержимое страницы он не печатает.

## Свойства вывода

| Имя | Описание |
| --- | --- |
| Ширина | Ширина textarea. В форме с самого начала стоит `100%`. |
| Высота | Высота textarea. В форме с самого начала стоит `300px`. |

Если оставить **Высота** пустой, textarea будет 400px, хотя подсказка формы говорит 300px.
