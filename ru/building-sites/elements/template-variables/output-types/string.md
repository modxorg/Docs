## Тип вывода TV - String

Этот тип вывода позволяет изменять регистр строки, например, верхний регистр, нижний регистр, предложение или капитализацию.

## Свойства вывода

| Имя | Описание |
| ---- | -------- |
| Format | Изменить регистр строки. Опции: none, Upper Case, Lower Case, Sentence Case, Capitalize. |

## Примеры

| Формат | Ввод | Вывод |
| ------ | ---- | ----- |
| Upper Case | hello world | HELLO WORLD |
| Lower Case | Hello World | hello world |
| Sentence Case | hello world | Hello world |
| Capitalize | hello world | Hello World |
