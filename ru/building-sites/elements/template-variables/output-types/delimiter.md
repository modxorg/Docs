## Тип вывода TV - Разделитель

Этот тип вывода режет значение TV по `||` и склеивает части заданным разделителем.

Если разделитель ни разу не сохраняли, разделителем будет запятая.

**Check Box** и **Listbox (Multi-Select)** хранят `||`, поэтому этот тип их разделяет. **Tag** и **Auto-Tag** уже хранят список через запятую. Этот тип такой список не режет.

## Свойства вывода

| Имя | Описание |
| --- | --- |
| Разделитель | Символы между пунктами. Несохранённое свойство даёт запятую. |
