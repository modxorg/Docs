[Сниппет](extending-modx/snippets "Сниппеты") это PHP, который страница выполняет при запросе. Обычно так делают меню, список новостей или форму поиска.

## Использование сниппетов

Поставьте тег сниппета туда, где нужен его вывод: в шаблон, чанк, TV или содержимое ресурса.

``` php
[[MySnippet]]
```

Если вы ожидаете, что код сниппета будет динамическим для разных пользователей, вы также можете вызвать сниппет без кэширования:

``` php
[[!MySnippet]]
```

## Свойства сниппета

[Свойства](building-sites/properties-and-property-sets "Свойства и наборы свойств") передаются в вызове сниппета:

``` php
[[!Wayfinder? &startId=`0` &level=`1`]]
```

[Набор свойств](building-sites/properties-and-property-sets "Свойства и наборы свойств") хранит эти свойства под одним именем. Привяжите набор к сниппету или к другому элементу.

Допустим, набор свойств называется `Menu`, в нём `startId` равен 0 и `level` равен 1. Привяжите этот набор к сниппету. Тогда:

``` php
[[!Wayfinder@Menu]]
```

Этот вызов подставит свойства набора. Если набор к этому сниппету не привязан, `@Menu` ничего не добавит. Свойства в теге по-прежнему перекрывают набор:

``` php
[[!Wayfinder@Menu? &level=`2`]]
```

ставит `level` равным 2 вместо `1` из набора.
