## Что такое шаблоны?

Шаблон хранит HTML, который задаёт раскладку страницы. Когда ресурс запрашивают, MODX загружает этот ресурс и его шаблон, подставляет в теги шаблона значения ресурса и отдаёт страницу в браузер.

![](template-info1.jpg)

[Ресурс](building-sites/resources "Ресурсы") использует один шаблон за раз. Позже шаблон можно сменить. В шаблоне обычно лежат шапка, подвал, боковая колонка или навигация.

## Использование

Чтобы создать шаблон, раскройте в дереве **Элементы**, щёлкните правой кнопкой **Шаблоны** и выберите **Создать шаблон**. Вставьте HTML в поле **Код шаблона (HTML)**. Ниже короткий пример:

```html
<html>
    <head>
        <title>[[*pagetitle]]</title>
        <meta name="description" content="[[*description]]" />
    </head>
    <body>
        <h1>[[*longtitle]]</h1>

        Идентификатор страницы: [[*id]]<br />
        Вступительный текст (резюме): [[*introtext]]<br />
        Название меню: [[*menutitle]]

        <hr />

        [[*content]]
    </body>
</html>
```

`[[*content]]` указывает место, куда MODX ставит содержимое ресурса.

MODX хранит шаблоны в базе. Шаблон может быть и статическим файлом в источнике файлов.

Создание шаблона ещё не назначает его. Откройте каждый [ресурс](building-sites/resources "Ресурсы") и выберите шаблон. У ресурса один шаблон.

После того, как вы создали один или несколько шаблонов, откройте ресурс и выберите шаблон в списке **Шаблон**.

Шаблоны могут содержать любые теги, в том числе [Переменные шаблона TV](building-sites/elements/template-variables "Переменные шаблона TV"), [Чанки](building-sites/elements/chunks "Чанки"), [Сниппеты](extending-modx/snippets "Сниппеты"), и другие.

### Класс иконки в менеджере

При создании или правке шаблона поле **Класс иконки** задаёт CSS-класс ресурсам с этим шаблоном. Классы `icon-home` и `fa-home` есть в стилях менеджера.

Если поле заполнено, на узле дерева остаются и этот класс, и класс иконки типа содержимого. Какую иконку вы видите, решает таблица стилей. Пустое поле оставляет иконку типа содержимого или стандартную иконку ресурса. У папки без иконки шаблона добавляется иконка папки.

### Использование полей ресурса в шаблоне

Поля ресурса пишутся как `[[*fieldName]]`. Список полей есть [на странице ресурса](building-sites/resources). `pagetitle` текущего ресурса в заголовке:

```html
<title>[[*pagetitle]]</title>
```

Содержимое текущего ресурса:

```html
<body>
    [[*content]]
</body>
```

Эти теги принимают [фильтры вывода](building-sites/tag-syntax/output-filters). Например, уберите HTML из `introtext` и обрежьте по ближайшему пробелу на 400-м символе или правее. В конец ставится знак многоточия, не три точки. Если пробела на этой позиции и дальше нет, текст остаётся целиком:

```html
<div id="rightbar">
    [[*introtext:stripTags:ellipsis=`400`]]
</div>
```

### Переменные шаблона в шаблонах

В шаблон можно добавить TV. При сохранении MODX не проверяет, сколько TV у шаблона уже есть.

[Переменная шаблона](building-sites/elements/template-variables "Переменные шаблона") (TV) это своё поле у ресурсов с заданным шаблоном. Создайте TV с именем `bioPhoto`, поставьте тип ввода и вывода image и назначьте её шаблону BiographyPages. Поле появится у каждого ресурса с этим шаблоном.

Тег тот же, что у поля ресурса:

```html
<div class="photo">
    [[*bioPhoto]]
</div>
```

Назначьте TV шаблону, прежде чем её использовать. После этого значение правят на ресурсе. Если новой TV нет в форме ресурса, проверьте это назначение.
