## tree_root_id

-   **Имя**: ID корня дерева ресурсов
-   **Тип**: Number
-   **По умолчанию**: 0

Укажите ID одного ресурса, который должен быть корнем левого дерева ресурсов. Пользователь увидит только ресурсы, вложенные в него. Значение `0` означает корень сайта.

Значение приводится к целому числу (`(int)$this->modx->getOption('tree_root_id')`); список ID через запятую **не** поддерживается.
