---
title: "cache_format"
translation: "building-sites/settings/cache_format"
description: "Формат сериализации кэша. Меняйте только через config_options. С 3.3.0 настройка скрыта из менеджера."
---

- **Имя**: Используемый формат кэша
- **Тип**: Number
- **По умолчанию**: 0
- **Доступно в**: Revolution 2.1+
- **Убрано из менеджера**: Revolution 3.3.0

Значения:

- `0`: массивы PHP
- `1`: JSON
- `2`: сериализованные данные PHP

---

**Важно.** Не меняйте эту настройку в «Системных настройках». После смены значения в менеджере MODX пишет кэш в новом формате, а на диске остаются файлы старого формата. Сайт и менеджер перестают открываться.

С Revolution 3.3.0 настройка больше не показывается в менеджере. Чтобы задать своё значение, пропишите его в `$config_options` в файле `core/config/config.inc.php` и очистите каталог `core/cache/`:

```php
$config_options = [
    'cache_format' => 0, // 0 = PHP, 1 = JSON, 2 = serialize
];
```

См. также: [Использование Memcache](extending-modx/caching/memcache) (ещё один пример `$config_options`).
