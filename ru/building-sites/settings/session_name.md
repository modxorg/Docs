## session_name

-   **Имя**: Имя сессии
-   **Тип**: String
-   **По умолчанию**: пусто (имя сессии по умолчанию из PHP)

Используйте этот параметр, чтобы настроить имя сеанса, используемое для сеансов в MODX.

Параметр есть в каждой установке, но по умолчанию пуст, поэтому PHP использует собственное имя сессии. Устанавливайте его, только если знаете, что делаете.
