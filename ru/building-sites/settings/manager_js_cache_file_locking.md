---

**Имя**: Включение блокировки JS/CSS файлов кеша Менеджера  
**Тип**: Да/Нет  
**По умолчанию**: Да  
**Доступен в**: только Revolution 2.2.0–2.x

В 2.x: блокировка файла кеша. Ставьте «Нет» на NFS.
