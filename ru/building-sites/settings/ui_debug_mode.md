## ui_debug_mode

-   **Имя**: Режим отладки интерфейса
-   **Тип**: Да/Нет
-   **По умолчанию**: Нет
-   **Доступен в**: Revolution 2.1+

**Настройка не устанавливается по умолчанию.** MODX не поставляет системную настройку `ui_debug_mode`: ключа нет в установочном транспорте ни в 2.x, ни в 3.x, хотя запись лексикона и клиентская проверка остались. `MODx.debug(msg)` в `manager/assets/modext/core/modx.js` пишет в `console.log()` только при `MODx.config.ui_debug_mode == 1`, поэтому отладка не включается, пока вы не создадите настройку вручную (Система → Системные настройки → Создать настройку, ключ `ui_debug_mode`, тип Да/Нет).

Когда настройка включена, все вызовы `MODx.debug(msg)` выводятся в консоль браузера. Это удобно для отладки [пользовательских страниц менеджера](extending-modx/custom-manager-pages) и другого кода без поломки рабочего сайта.
