-   **Имя**: Начало недели     
-   **Тип**: Number
-   **По умолчанию**: 0
-   **Доступен в**: Revolution 2.2.2+

Определяет первый день недели в календарях. `0` (или пустое поле) — воскресенье, `1` — понедельник, `2` — вторник и т. д. Значение передаётся в Ext JS как `startDay`.
