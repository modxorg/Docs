## emailsender

-   **Имя**: Адрес электронной почты
-   **Тип**: String
-   **По умолчанию**: Установить при установке (см. Примечания ниже)

Адрес электронной почты, который MODX указывает в поле From при отправке писем, включая уведомления об учётных записях.

Некоторые хосты не разрешают MODX отправлять письма, если адрес From недействителен для размещённого домена. При установке `emailsender` получает адрес, введённый для пользователя admin, и он может не подходить для домена. Если MODX не отправляет письма, укажите здесь действительный адрес для домена.
