## session_handler_class

-   **Имя**: Имя класса-обработчика сессий
-   **Тип**: String
-   **По умолчанию**: MODX\Revolution\modSessionHandler

Для сеансов, управляемых базой данных, используйте полное имя класса `MODX\Revolution\modSessionHandler` (значение по умолчанию). Оставьте поле пустым для стандартного управления сеансами PHP или укажите свой класс. Короткие имена классов из 2.x автозагрузчик не разрешает.
