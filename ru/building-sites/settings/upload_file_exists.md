---
title: 'upload_file_exists'
description: 'Настройка upload_file_exists разрешает или запрещает загрузку файлов с уже существующим именем.'
translation: "building-sites/settings/upload_file_exists"
---

**Name**: Check if upload file exists  
**Type**: Yes/No  
**Default**: Yes  
**Available In**: Revolution 2.8+

Если включено, при загрузке файла с уже существующим именем вы увидите ошибку. Если выключено, существующий файл тихо заменят новым.
