## Что такое веб-ссылка?

Веб-ссылка — это ресурс, который перенаправляет на другой URL. Целью может быть внешний адрес или ресурс в дереве MODX.

Поле `type` у веб-ссылки равно `reference`, но MODX выбирает поведение по `class_key` и классу `MODX\Revolution\modWebLink`. Устаревшее значение `type` на маршрутизацию не влияет.

Шаблон веб-ссылки не рендерится: `modWebLink::process()` отправляет перенаправление до вывода шаблона. Переменные шаблона, привязанные к веб-ссылке, при перенаправлении не показываются.

## URL цели

Поле `content` хранит цель. Числовое значение считается ID ресурса: MODX строит полный URL через `makeUrl()` и перенаправляет туда. Нечисловое значение считается URL; сначала MODX разбирает теги вроде `[[~12]]` или `[[+placeholder]]`, затем перенаправляет.

Числовая цель должна существовать. При сохранении MODX отклоняет несуществующий ID.

## Код ответа

По умолчанию веб-ссылка отправляет `HTTP/1.1 301 Moved Permanently`. Код меняется в поле **Код ответа** на вкладке **Настройки**.

Значение хранится как свойство ресурса `responseCode` в пространстве имён `core`. Примеры:

```text
HTTP/1.1 302 Found
HTTP/1.1 307 Temporary Redirect
```

Код 301 кешируют браузеры и поисковые системы. Пока цель может измениться, используйте временный код.

## Веб-ссылки в меню и тегах ссылок

По умолчанию меню и теги ссылок ведут на URL самой веб-ссылки, а запрос запускает перенаправление.

Включите [`use_weblink_target`](building-sites/settings/use_weblink_target), чтобы теги ссылок и `makeUrl()` сразу возвращали URL цели. По умолчанию настройка выключена.

## Пример: ссылка в подвале

В меню подвала нужны ссылки на условия использования, политику конфиденциальности и страницу «Связаться с нами». Страница «Связаться с нами» уже есть в основном дереве и не должна попадать в главное меню.

Создайте неопубликованный контейнер «служебные страницы», поместите туда ресурс «Связаться с нами» и добавьте веб-ссылку на этот ресурс в контейнер меню подвала. Меню получит ссылку на страницу, не перемещая её.
