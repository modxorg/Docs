## Что такое статический ресурс?

Статический ресурс представляет файл в файловой системе. Поле `content` хранит путь к файлу, а не его содержимое. MODX читает файл во время запроса и возвращает его; файл не копируется и ссылка на него не создаётся.

Как и другие ресурсы, статический ресурс имеет ID, отображается в дереве, может входить в группы ресурсов и попадать в меню и результаты поиска.

Путь может содержать теги MODX. Базовый путь можно хранить в системной настройке или строить [сниппетом](extending-modx/snippets).

## Где могут лежать файлы

Путь разрешается относительно [`resource_static_path`](building-sites/settings/resource_static_path), по умолчанию `{assets_path}`. Настройка и поле `content` могут содержать теги, а последовательности `../` из пути удаляются.

Абсолютный путь вне этой базы используется только при включённой [`resource_static_allow_absolute`](building-sites/settings/resource_static_allow_absolute). Эта настройка позволяет пользователям менеджера читать любой файл, доступный процессу PHP, поэтому не включайте её без доверия ко всем пользователям менеджера.

Если файл отсутствует или недоступен для чтения, MODX отдаёт страницу ошибки со статусом 404.

## Типы содержимого и вывод

Статический ресурс использует [тип содержимого](building-sites/resources/content-types), как и любой другой ресурс. Тип задаёт MIME-тип и расширение файла в URL.

Для текстового типа содержимого (`Двоичный` — Нет) MODX читает файл и выводит его как документ. Шаблон применяется, теги в файле разбираются.

Для бинарного типа содержимого MODX отдаёт файл потоком:

- `Content-Type` из типа содержимого.
- `Content-Length`, если размер известен.
- `Content-Disposition`: `attachment`, если у ресурса выбрано вложение, иначе `inline`.
- [Пользовательские заголовки](building-sites/resources/content-types#polzovatelskie-zagolovki) типа содержимого.

Затем MODX отправляет файл через `readfile()` и завершает запрос. Шаблон не используется, теги не разбираются. Браузер получает байты без изменений.

## О псевдонимах

Не добавляйте расширение файла в псевдоним: его задаёт [тип содержимого](building-sites/resources/content-types). Например, статический ресурс с псевдонимом `test` и типом PDF отдаётся как `test.pdf`.

## Шаблоны

С пустым шаблоном MODX выводит содержимое файла. Если вы используете свой шаблон, чтобы добавить метатеги или переменные шаблона, включите `[[*content]]` в место, где должно появиться содержимое файла.

Бинарный статический ресурс обходит шаблон полностью.

## Скачивание

Выберите **Прикреплённый файл** в поле **Местонахождение содержимого**, чтобы отдать файл с серверным заголовком `attachment`. Чтобы заставить браузер скачать уже отдаваемый файл по ссылке, добавьте HTML-атрибут `download`.

```html
<a href="assets/files/report.pdf" download="report.pdf">Скачать отчёт</a>
```

Браузер может показать PDF в окне или скачать его в зависимости от настроек. `attachment` или атрибут `download` делают поведение явным.
