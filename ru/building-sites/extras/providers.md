MODX скачивает пакеты у поставщика. Это удалённая служба. С ядром поставляется поставщик modx.com. У сайта их может быть сколько нужно.

## Что такое поставщик

Поставщик задаёт адрес службы, с которой скачиваются пакеты.

Поставщик modx.com доступен по адресу `https://rest.modx.com/extras/`. Этот адрес вписывают в поле **URL сервиса**.

> [!WARNING]
> Скачивайте пакеты только у поставщиков, которым доверяете. Поставщик отдаёт код, который работает на вашем сайте.

## Добавление поставщика

Откройте **Пакеты** в верхнем меню, затем **Установщик**, затем **Поставщики**. **Создать** открывает окно.

| Поле | Что вводить |
| --- | --- |
| **Название** | имя поставщика в списке |
| **URL сервиса** | адрес службы |
| **Имя пользователя** | имя для этого поставщика |
| **Ключ API** | ключ для этого поставщика |
| **Описание** | свободный текст |

При сохранении MODX проверяет поставщика. Если служба не подтверждает адрес, запись не сохраняется.

Каждый запрос передаёт:

- **Имя пользователя** и **Ключ API** из этого окна
- идентификатор установки, тип базы данных и версию MODX
- имя хоста, версию PHP и язык менеджера

## Загрузка у поставщика

1. В меню кнопки **Загрузить пакеты** выберите **Выберите поставщика**.
2. Укажите поставщика.
3. Подтвердите кнопкой **Сохранить и перейти в обозреватель пакетов**.

Откроется менеджер пакетов. Слева категории этого поставщика, справа пакеты.
