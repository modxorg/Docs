Провайдер транспортных пакетов — это удалённая служба, из которой MODX скачивает пакеты. С ядром поставляется один провайдер — провайдер modx.com, — а у сайта их может быть сколько угодно.

## Что такое провайдер

Провайдер — это базовый URL REST-службы. MODX дописывает к нему фиксированный маршрут и читает ответ как XML:

| Маршрут | Что возвращает |
| --- | --- |
| `repository` | репозитории провайдера и категории в них |
| `package` | пакет по сигнатуре |
| `package/versions` | версии пакета |
| `package/update` | новейшая версия пакета |
| `home` | статистика провайдера |
| `verify` | ответ, что служба является провайдером |

Провайдер modx.com — это служба по адресу `https://rest.modx.com/extras/`.

> [!WARNING]
> Скачивайте пакеты только у провайдеров, которым доверяете: провайдер отдаёт код, который работает на вашем сайте.

## Добавление провайдера

Провайдеры живут на вкладке **Providers** страницы Package Management: **Extras** в верхнем меню → **Installer** → **Providers**. Кнопка **Create** открывает окно с полями провайдера:

| Поле | Значение |
| --- | --- |
| `name` | имя провайдера в списке |
| `service_url` | базовый URL службы |
| `username` | имя, которое уходит в запросах |
| `api_key` | ключ, который уходит в запросах |
| `description` | свободный текст |

MODX проверяет провайдера при сохранении: он спрашивает у службы `verify` и ждёт ответа, что провайдер подтверждён. Провайдер, который не отвечает, не сохраняется.

Каждый запрос к провайдеру несёт:

- `username` и `api_key` провайдера;
- данные установки: `uuid`, тип базы, версия MODX, хост и версия PHP, а также язык менеджера.

## Загрузка с провайдера

Чтобы скачать пакет у провайдера:

1. в меню кнопки **Download Extras** выберите **Select a Provider**;
2. укажите провайдера;
3. подтвердите кнопкой **Save and go to Package Browser**.

Браузер пакетов откроется с категориями провайдера слева и пакетами справа.
