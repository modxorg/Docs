> [!IMPORTANT]
> Проверяйте свою тему менеджера после каждого обновления MODX. Тема может конфликтовать с изменениями нового выпуска, а файлы, которые выпуск добавляет, тема никогда не подхватывает.

## Как устроена тема

Менеджер построен на шаблонах Smarty. Файлы стандартной темы лежат в `manager/templates/default`. Системная настройка `manager_theme` хранит имя каталога внутри `manager/templates/`. Менеджер сначала читает файлы этой темы, а недостающие берёт из `default`.

В MODX 3 поставляется только тема `default`. Остальные приходят со сборкой, с дополнением или делаются вами.

Тема покрывает не только страницы менеджера. Из неё же берутся шаблоны виджетов панелей и TV, а также контроллеры ресурсов.

## Переопределение одного файла

Чтобы оформить только страницу входа, скопируйте файл:

`manager/templates/default/security/login.tpl` → `manager/templates/my-brand/security/login.tpl`

Затем задайте в `manager_theme` значение `my-brand`. Файл из `my-brand` заменит файл из `default`.

**Создайте каталог до того, как выберете тему**
Настройка это выпадающий список каталогов `manager/templates/`. Значение нельзя вписать руками. Сначала создайте `manager/templates/my-brand/`, потом выберите его в **Админ → Системные настройки**.

## Что обязано быть в теме

Эти файлы читаются из каталога темы, без отката на `default`:

| Файл | Что ломается без него |
| --- | --- |
| `images/modx-icon-color.svg` | Значок сайта в шапке менеджера. |
| `images/modx-logo-color.svg` | Логотип на странице входа. |
| `images/login/default-background.jpg` | Фон страницы входа. |
| `email/default.tpl` | Создание пользователя: шаблон письма не найден. |

**Стили страницы входа тема не перекрывает**
`security/login.tpl` подключает стиль темы `default` по жёстко заданному пути. Чтобы оформить его, положите `css/login.css` в каталог темы и поправьте ссылку в своей копии `security/login.tpl`. То же с браузером файлов: его `browser/index.tpl` подключает `css/index.css` темы `default`.

Стили самого менеджера тема перекрывает. Положите `css/index.css` в каталог темы, и шапка подхватит его через плейсхолдер `{$indexCss}`.

## Где должна лежать тема

Каталог темы ищется внутри `manager/templates/`. Это часть каталога установки, и обновление его перезаписывает. Держите файлы темы в своём репозитории и восстанавливайте их после обновления.

**Обновление с Evolution сбрасывает тему**
Когда установщик обновляет сайт с Evolution, `setup/includes/upgrade.install.php` возвращает `manager_theme` в `default`. Обновление внутри MODX 3 настройку не трогает.

## Переопределение контроллера

Контроллер переопределяется так же. В пути вместо `templates` стоит `controllers`. Файл в теме называется так же, как в `default` (`<action>.class.php`). Класс внутри него называется `<Action>ManagerController` в глобальном пространстве, например `SecurityLoginManagerController`.
