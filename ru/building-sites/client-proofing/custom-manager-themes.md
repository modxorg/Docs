**Важно**: проверяйте пользовательскую тему менеджера после каждого обновления MODX. Тема может конфликтовать с изменениями нового выпуска, а файлы, добавленные выпуском, тема никогда не подхватит.

## Как устроена тема

Менеджер построен на шаблонах Smarty. Файлы темы по умолчанию лежат в `manager/templates/default`. Системная настройка `manager_theme` хранит имя каталога внутри `manager/templates/`, и менеджер сначала читает файлы этой темы, а к тем, которых в ней нет, обращается к файлам темы `default`.

В MODX 3 поставляется только тема `default`. Остальные приходят со сборкой или с дополнением, либо делаются вами.

Тема охватывает не только страницы менеджера: из неё же резолвятся шаблоны виджетов дашбордов и переменных шаблона, а также контроллеры ресурсов.

## Переопределение одного файла

Чтобы оформить только страницу входа, скопируйте файл:

`manager/templates/default/security/login.tpl` → `manager/templates/my-brand/security/login.tpl`

Затем задайте в `manager_theme` значение `my-brand`. Файл из `my-brand` заменит файл из `default`.

**Создайте каталог до того, как выберете тему**
Настройка — это выпадающий список каталогов `manager/templates/`, и его значение нельзя вписать руками. Сначала создайте `manager/templates/my-brand/`, потом выберите его в **Admin → Системные настройки**.

## Что обязано быть в теме

Эти файлы читаются из каталога темы, без отката на `default`:

| Файл | Что ломается без него |
| --- | --- |
| `images/modx-icon-color.svg` | Значок сайта в шапке менеджера. |
| `images/modx-logo-color.svg` | Логотип на странице входа. |
| `images/login/default-background.jpg` | Фон страницы входа. |
| `email/default.tpl` | Создание пользователя: шаблон письма не найден. |

**Стили страницы входа не темизируются**
`security/login.tpl` подключает стиль темы `default` по жёстко зашитому пути. Чтобы оформить его, положите `css/login.css` в каталог темы и поправьте ссылку в собственной копии `security/login.tpl`. То же самое с браузером файлов: его `browser/index.tpl` подключает `css/index.css` темы `default`.

Стили самого менеджера темизируются: положите `css/index.css` в каталог темы, и шапка подхватит его через плейсхолдер `{$indexCss}`.

## Где должна лежать тема

Каталог темы ищется внутри `manager/templates/` — это часть каталога установки, который перезаписывается при обновлении. Держите файлы темы в своём репозитории и восстанавливайте их после обновления.

**Обновление сбрасывает тему**
При обновлении в режиме Evolve скрипт `setup/includes/upgrade.install.php` возвращает `manager_theme` в `default`. Проверяйте значение после каждого обновления.

## Переопределение контроллера

Контроллер переопределяется так же, только вместо `templates` в пути стоит `controllers`. Файл в теме должен называться так же, как в `default` (`<action>.class.php`), а класс внутри него — называться `<Action>ManagerController` в глобальном пространстве, например `SecurityLoginManagerController`.
