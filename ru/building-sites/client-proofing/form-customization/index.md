## Что такое настройка форм

Настройка форм позволяет менять формы менеджера: спрятать поле, переименовать его, подставить другое значение, перенести TV на другую вкладку.

Раздел находится в **Admin → Form Customization** и требует права **customize_forms**.

## Три слоя

> Профиль → Набор → Правила

**Профиль** — это набор наборов, и его можно привязать к группам пользователей. **Набор** — это набор правил, привязанный к странице менеджера. **Правило** — одно изменение, которое набор вносит в форму.

Правила не правятся отдельно: они пересобираются из трёх сеток набора при каждом его сохранении. Смотрите [Правила настройки формы](building-sites/client-proofing/form-customization/rules "Правила настройки формы").

## Как это хранится

Профиль хранит наборы, а набор — свои правила. Список полей и областей, которые можно менять, хранится в справочнике и заполняется при установке MODX.

## Какие формы можно настроить

Только страницы ресурса: **Create Resource** и **Edit Resource**. Страницы чанка, сниппета, пользователя или группы пользователей настройка форм не покрывает.

Набор привязывается к одному из трёх действий:

| Действие | Набор действует на |
| --- | --- |
| Create Resource | Страницу создания ресурса. |
| Edit Resource | Страницу редактирования ресурса. |
| Create & Edit Resource | На обе страницы сразу. |

В последнем случае набор покрывает обе страницы, а список полей и областей он предлагает взятым со страницы редактирования ресурса.
