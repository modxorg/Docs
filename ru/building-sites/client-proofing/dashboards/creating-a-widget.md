## Создание базового виджета

Откройте страницу панелей управления (**Админ → Панели управления** в верхнем меню) и перейдите на вкладку **Виджеты**. Нажмите **Создать**. Откроется экран создания виджета. На нём эти поля:

| Поле | Что в нём |
| --- | --- |
| **Name** | Имя виджета. Оно должно быть уникальным. |
| **Description** | Краткое описание виджета для внутреннего использования. |
| **Widget Type** | Тип виджета. Для первого виджета выберите «HTML». |
| **Size** | Один из семи размеров: Quarter, One Third, Half, Two Third, Three Quarters, Full Size и Double Size. |
| **Permission** | Право менеджера, которое нужно пользователю, чтобы виджет появился. Пусто: виджет виден всем. |
| **Namespace** | Пространство имён, с которым связан виджет. Оставьте «core», если вы не пишете дополнение. |
| **Lexicon** | Лексикон, который грузится вместе с виджетом. По умолчанию «core:dashboards». |
| **Properties** | Произвольные свойства виджета, которые хранятся в JSON. Виджет-файл или виджет-сниппет получает их как `$scriptProperties`. |

Когда вы вводите имя, под полем появляется текст, повторяющий ввод. Это перевод имени: он ищет ключ в лексиконе виджета. Введите ключ существующей записи, например `w_configcheck`, и увидите переведённое имя.

В содержимое виджета вставьте:

``` php
<p>Hello, world!</p>
```

Виджет должен выглядеть так:

![](dashboard-create1.png)

Сохраните виджет.

### Назначение виджета панели по умолчанию

Вернитесь на главную страницу панелей управления, откройте вкладку **Dashboards** и найдите панель по умолчанию. Щёлкните по ней правой кнопкой мыши и выберите **Редактировать**. Откроется страница редактирования.

Нажмите **Добавить виджет** над таблицей виджетов. Выберите **Hello World** в выпадающем списке и сохраните. Виджет добавлен на панель. Перетащите его на позицию №2 между виджетами **Configuration Check** и **MODX News Feed**:

![](dashboard-create2.png)

Сохраните панель.

> [!NOTE]
> Добавление виджета через страницу панелей помещает его в **шаблон** панели. Если панель [настраиваемая](building-sites/client-proofing/dashboards "Панели управления"), виджет появляется у всех существующих пользователей этой панели и у новых.
>
> Добавление виджета прямо на странице панели добавляет его только текущему пользователю. Остальные его не увидят, пока виджет не добавят в шаблон.
>
> Виджет, добавленный в шаблон, приходит к существующим пользователям со стандартным размером и в конце списка, а не с тем размером, который указан в шаблоне.
>
> На крупном сайте добавление виджета в шаблон создаёт запись размещения для каждого пользователя с личной копией этой панели. Учитывайте это, если важна производительность.

### Просмотр виджета

Нажмите логотип MODX в левом верхнем углу. На панели будет новый виджет.

![](dashboard-create3.png)

## Удаление виджета

Виджет удаляется на вкладке **Виджеты**, и при этом он убирается со всех панелей, где он был размещён. Виджеты, которые поставляются с MODX, удалить нельзя.
