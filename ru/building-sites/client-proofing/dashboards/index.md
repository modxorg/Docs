## Что такое панели управления

Панель управления — это страница, которая открывается при входе в менеджер. Логотип MODX в левом верхнем углу ведёт на неё же.

На панели может быть сколько угодно виджетов: блоков с содержимым. Виджет — это файл, сниппет MODX, обычный HTML или PHP-код. Виджеты можно располагать в любом порядке.

Каждой группе пользователей назначается своя панель. Так разным пользователям достаются разные панели.

Если пользователь состоит в двух группах, используется панель его основной группы. Основную группу задают на экране редактирования пользователя.

## Штатные виджеты

В MODX поставляется семь виджетов:

| Виджет | Право |
| --- | --- |
| MODX News Feed | — |
| MODX Security Feed | — |
| Who's Online | — |
| Configuration Check | — |
| Buttons | — |
| Recently Edited Resources | `view_document` |
| Updates | `workspaces` |

Последние два видны только пользователям с нужным правом, поэтому у обычного пользователя их на панели нет.

## Настраиваемые панели

У панели есть параметр **Customizable** (настраиваемая). Если он включён (по умолчанию включён), MODX клонирует раскладку виджетов панели для каждого пользователя при первой загрузке. У каждого появляется личная копия: можно менять порядок, добавлять и убирать виджеты, а также менять их размер, не затрагивая остальных.

Если **Customizable** выключен, все пользователи видят одну и ту же раскладку и не могут менять её для себя.

У панели есть и второй параметр — **Hide Left-Hand Trees**: он прячет деревья слева, пока показана панель.

### Как изменения шаблона распространяются на пользователей

Раскладка виджетов, которую вы настраиваете на странице управления панелями, служит **шаблоном** настраиваемой панели. Когда вы добавляете или удаляете виджеты в шаблоне, изменения применяются ко всем пользователям, у которых уже есть личная копия этой панели:

- **Добавленные** в шаблон виджеты автоматически появятся у всех пользователей с личной копией панели.
- **Удалённые** из шаблона виджеты исчезнут с личных панелей всех пользователей.

Другие личные настройки, например порядок виджетов, изменения шаблона не затрагивают.

Изменения, которые вы делаете прямо на странице панели пользователя (например, закрываете виджет кнопкой или добавляете виджет с самой панели), затрагивают только этого пользователя и не меняют шаблон.

Виджет, добавленный в шаблон, приходит к существующим пользователям со стандартным размером и в конце списка, а не с тем размером, который указан в шаблоне.

## Права

Страница менеджера с панелями и любые действия с виджетами требуют права **dashboards**. Сама панель показывается любому пользователю, которому разрешён вход в менеджер.
