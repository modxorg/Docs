## Что такое панели управления?

Панель управления в MODX это страница, которая отображается при первой загрузке менеджера MODX или при нажатии ссылки «Панель управления» в левом верхнем углу экрана. Панели управления могут содержать неограниченное количество «виджетов», то есть блоков с разным содержимым на панели. Вы можете расположить виджеты в любом порядке. Виджет может быть файлом, сниппетом MODX или обычным HTML.

Каждой группе пользователей в MODX по умолчанию назначается панель управления. Это означает, что вы можете выдать разным пользователям разные панели через группу пользователей, к которой они принадлежат.

Если пользователь входит в две разные группы, он увидит панель своей основной группы. Её можно задать на экране редактирования пользователя.

## Настраиваемые панели

У панелей есть параметр **Customizable** (настраиваемая). Если он включён (по умолчанию включён), MODX клонирует раскладку виджетов панели для каждого пользователя при первой загрузке. У каждого появляется личная копия панели, которую он может переставлять, дополнять виджетами или очищать без влияния на других.

Если **Customizable** выключен, все пользователи видят одну и ту же раскладку и не могут менять её для себя.

### Как изменения шаблона распространяются на пользователей

Раскладка виджетов, которую вы настраиваете на странице управления панелями (Панель управления -> Панели управления -> Редактировать панель), служит **шаблоном** для настраиваемой панели. Когда вы добавляете или удаляете виджеты в шаблоне, изменения применяются ко всем пользователям, у которых уже есть личная копия этой панели:

- **Добавленные** в шаблон виджеты автоматически появятся у всех пользователей с личной копией панели.
- **Удалённые** из шаблона виджеты исчезнут с личных панелей всех пользователей.

Другие личные настройки, например порядок виджетов, изменения шаблона не затрагивают.

Изменения, которые вы делаете прямо на странице панели пользователя (например, закрываете виджет кнопкой или добавляете виджет с самой панели), затрагивают только этого пользователя и не меняют шаблон.

## Настраиваемые панели

У панелей есть параметр **Customizable** / «Настраиваемая». Если он включён (так по умолчанию), MODX при первой загрузке панели клонирует раскладку виджетов для каждого пользователя. У пользователя появляется личная копия: можно менять порядок, добавлять и убирать виджеты, не затрагивая остальных.

Если **Customizable** выключен, все пользователи делят одну раскладку и не правят её лично.

### Как изменения шаблона доходят до пользователей

Раскладка виджетов на странице Dashboards → Update Dashboard — это **шаблон** настраиваемой панели. Добавление или удаление виджетов в шаблоне применяется ко всем, у кого уже есть личная копия:

- **Добавленные** в шаблон виджеты появятся у всех пользователей этой панели.
- **Удалённые** из шаблона виджеты пропадут у всех личных копий.

Личный порядок виджетов от правок шаблона не сбрасывается.

Правки прямо на странице панели пользователя (кнопка закрытия виджета или добавление с самой панели) затрагивают только этого пользователя и не меняют шаблон.
