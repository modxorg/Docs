Виджет панели управления хранит своё содержимое в одном из четырёх типов. Тип сохраняется вместе с виджетом, и его значение важно, когда вы пишете виджет сами.

| Тип | Что делает | Значение в базе |
| --- | --- | --- |
| [Файл](building-sites/client-proofing/dashboards/widget-types/file "Тип виджета панели управления - Файл") | Выполняет файл с диска. | `file` |
| [Сниппет](building-sites/client-proofing/dashboards/widget-types/snippet "Тип виджета панели управления - Сниппет") | Выполняет сниппет MODX. | `snippet` |
| [HTML](building-sites/client-proofing/dashboards/widget-types/html "Тип виджета панели управления - HTML") | Показывает обычный HTML. | `html` |
| [Inline PHP](building-sites/client-proofing/dashboards/widget-types/inline-php "Тип виджета панели управления - Inline PHP") | Выполняет PHP-код, как сниппет. | `php` |
