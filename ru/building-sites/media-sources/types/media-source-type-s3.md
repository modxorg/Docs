## Тип источника файлов - Amazon S3

Этот тип источника файлов подключает Менеджер к корзине Amazon S3 (или к S3-совместимому хранилищу через `endpoint`).

### Доступные свойства

| Имя | Описание |
| --- | --- |
| `url` | Обязательное. Базовый URL объектов в корзине. Часто `https://myaccount.s3.amazonaws.com/` или `https://s3.amazonaws.com/myaccount/`. Если превью не открываются, а сами файлы доступны, добавьте в конец URL косую черту. |
| `endpoint` | Необязательная S3-совместимая конечная точка (например `https://s3.<region>.example.com`). Для Amazon S3 оставьте пустым. |
| `region` | Регион AWS корзины (пример: `us-west-1`). В Revolution 3.x по умолчанию: `us-east-2`. Неверный регион часто даёт пустой список в медиабраузере. Укажите регион, в котором создана корзина. Если после верных ключей и имени корзины список всё ещё пуст, очистите `region`, сохраните, затем введите нужный код региона (или оставьте поле пустым и сохраните ещё раз). |
| `bucket` | Обязательное. Имя S3-корзины для этого источника. |
| `prefix` | Необязательный префикс пути внутри корзины. |
| `key` | Обязательное. Access key ID для корзины. |
| `secret_key` | Обязательное. Secret access key для корзины. |
| `no_check_bucket` | Если «Да», MODX не проверяет существование корзины. Нужно, когда у ключа нет прав на list/create bucket. |
| `imageExtensions` | Расширения через запятую, для которых строятся превью. **По умолчанию**: `jpg,jpeg,png,gif,svg,webp` |
| `thumbnailType` | Формат превью. **По умолчанию**: `png` |
| `thumbnailQuality` | Качество превью от 0 до 100. **По умолчанию**: `90` |
| `skipFiles` | Имена через запятую, которые скрывать при просмотре. **По умолчанию**: `.svn,.git,_notes,nbproject,.idea,.DS_Store` |
| `visibility` | Видимость Flysystem по умолчанию для **новых файлов**: `public` или `private`. **По умолчанию**: `private`. У S3 поддерживается видимость файлов, не папок (`visibility_dirs` = false), поэтому Set Visibility для каталогов недоступен. |

В MODX 3 источники медиа работают через League Flysystem (для этого типа — AWS SDK v3). Кастомные классы источников должны опираться на Flysystem API, а не на хелперы файловой системы до 3.0.
