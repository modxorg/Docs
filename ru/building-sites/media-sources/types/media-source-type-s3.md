## Тип источника файлов - Amazon S3

Этот тип источника подключает менеджер к корзине Amazon S3 или к S3-совместимому хранилищу через свойство `endpoint`.

В MODX 3 источники медиа работают через League Flysystem, для этого типа — с AWS SDK v3.

## Доступные свойства

| Имя | Описание |
| --- | --- |
| `url` | Обязательное. Адрес, по которому отдаются объекты корзины, например `https://myaccount.s3.amazonaws.com/`. **По умолчанию**: `http://mysite.s3.amazonaws.com/` |
| `endpoint` | Необязательное. Конечная точка S3-совместимого хранилища, например `https://s3.<region>.example.com`. Для Amazon S3 оставьте пустым. |
| `region` | Регион корзины, например `us-west-1`. **По умолчанию**: `us-east-2` |
| `bucket` | Обязательное. Имя корзины. |
| `prefix` | Необязательное. Префикс пути внутри корзины. |
| `key` | Обязательное. Access key ID корзины. |
| `secret_key` | Обязательное. Secret access key корзины. |
| `no_check_bucket` | Когда включено, MODX не проверяет существование корзины. **По умолчанию**: `false` |
| `imageExtensions` | Расширения через запятую, которые считаются изображениями. **По умолчанию**: `jpg,jpeg,png,gif,svg,webp` |
| `visibility` | Видимость новых файлов: `public` или `private`. **По умолчанию**: `private` |
| `skipFiles` | Имена через запятую, которые нужно скрывать. **По умолчанию**: `.svn,.git,_notes,nbproject,.idea,.DS_Store` |
| `skipExtensions` | Расширения через запятую, которые нужно скрывать. **По умолчанию**: пусто |

## Регион должен совпадать

Регион должен быть тем, в котором создана корзина. Неверный регион — самая частая причина того, что в медиабраузере нет ни одного файла.

**Пустой регион не заменяется значением по умолчанию**
`us-east-2` — это только значение, с которым поле начинается. Сохраните источник с пустым полем — и пустое значение останется, а соединение с корзиной не установится. Укажите регион своей корзины.

## Превью и видимость

Превью объекта — это адрес самого объекта. Этот тип не создаёт миниатюры, поэтому у него нет свойств `thumbnailType` и `thumbnailQuality`. Миниатюры страницы создаёт тип «Файловая система».

Тип поддерживает видимость файлов, но не папок. Пункт **Указать видимость** появляется только для файлов, а свойство `visibility` задаёт значение для новых файлов.
