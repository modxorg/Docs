## Тип источника файлов - Файловая система

Этот тип источника позволяет просматривать каталог сервера, на котором работает MODX.

В MODX 3 драйвер — League Flysystem с локальным адаптером.

## Доступные свойства

| Имя | Описание |
| --- | --- |
| `basePath` | Каталог, на который указывает источник, например `assets/images/`. Он относительный, когда включён `basePathRelative`. |
| `basePathRelative` | Относительный ли `basePath` к каталогу установки MODX. **По умолчанию**: `true` |
| `baseUrl` | Адрес, по которому отдаются файлы, например `assets/images/`. Он относительный, когда включён `baseUrlRelative`. |
| `baseUrlRelative` | Относительный ли `baseUrl` к адресу установки MODX. **По умолчанию**: `true` |
| `allowedFileTypes` | Расширения через запятую, которые нужно показывать, без точек. Пусто — показываются все расширения. |
| `imageExtensions` | Расширения через запятую, которые считаются изображениями. **По умолчанию**: `jpg,jpeg,png,gif,svg,webp` |
| `thumbnailType` | Формат создаваемых миниатюр: `png`, `jpg`, `gif` или `webp`. **По умолчанию**: `png` |
| `thumbnailQuality` | Качество создаваемых миниатюр, от 0 до 100. **По умолчанию**: `90` |
| `visibility` | Видимость новых файлов и папок: `public` или `private`. **По умолчанию**: `public` |
| `skipFiles` | Имена через запятую, которые нужно скрывать. **По умолчанию**: `.svn,.git,_notes,nbproject,.idea,.DS_Store` |
| `skipExtensions` | Расширения через запятую, которые нужно скрывать. **По умолчанию**: пусто |

**`skipExtensions` работает только в окне браузера**
Дерево файлов скрывает имена из `skipFiles` и расширения из `allowedFileTypes`. Свойство `skipExtensions` оно не смотрит. Окно браузера скрывает все три.

## Видимость файлов и папок

Источник файловой системы несёт видимость файлов и папок, которую даёт Flysystem.

- У приватного объекта в дереве файлов вместо обычного значка папки или файла показывается `icon-eye-slash`.
- Нажмите на файл или папку правую кнопку мыши и выберите **Указать видимость**, чтобы сделать объект публичным или приватным.
- Свойство `visibility` задаёт значение только для новых объектов. Уже существующие объекты оно не меняет.
- Для смены видимости нужны право `directory_chmod` и критерий `save` политики источника.

Некоторые адаптеры и некоторые типы файлов отклоняют смену видимости. Причина — в журнале ошибок.

## Права новых файлов и папок

Ядро задаёт права новых объектов само, через видимость Flysystem:

| Объект | Публичный | Приватный |
| --- | --- | --- |
| Файл | `0644` | `0600` |
| Папка | `0755` | `0700` |

Изменить это можно настройками `new_file_permissions`, `new_folder_permissions`, `private_file_permissions` и `private_folder_permissions`.

## Защищённые системные каталоги

Браузер не переименовывает и не удаляет каталоги, которые совпадают с путями установки ядра: `assets`, базовый путь, `connectors`, `core`, `manager`, `processors` и путь ядра xPDO. Источник на корень MODX не даст снести эти папки из дерева файлов. Источники для повседневной работы делайте под `assets/` или под другим деревом вне ядра.
