## Upgrading to Revolution 2.0.0-rc-2

Read this page only if you:

- Write translatable Extras for Revolution
- Write plugins for Revolution

## Lexicon Changes

The RC1 lexicon system held back Extras development and a stable multi-lingual distribution, so it was replaced. What changed:

- Dropped the `modLexiconTopic` and `modLexiconLanguage` tables.
- Changed the `topic` field on `modLexiconEntry` to a varchar with the topic name.
- Refactored `modLexiconEntry` so database records hold **only** overridden entries; the rest are cached from the lexicon topic files (`.inc.php`).
- Rebuilt Lexicon Management as a grid for overriding entries: you edit existing entries only, and an edited entry shows in green as overridden.

Benefits of the new approach:

- Easier translation.
- Faster lexicon loading: files and arrays instead of database objects.
- Lexicon edits no longer break your upgrade path.
- Smaller `core.transport.zip`; faster builds and setup.
- Easier development: a `lexicon/` directory under your Namespace path (as in most Extras), laid out as `lexicon/[language]/[topic].inc.php`, is parsed automatically and listed in Lexicon Management; build scripts no longer call `modPackageBuilder::buildLexicon`.

**All packages using lexicons must be rebuilt for 2.0.0 RC-2.** Drop the `buildLexicon` call from build scripts and put lexicon directories under the namespace path, as in [this component](http://svn.modxcms.com/svn/modx-components/doodles/trunk/).

Core translations are now packaged in SVN.


## Plugin Changes

Deprecated Plugin Events were removed in RC-2 and new events were added. See the [System Events](extending-modx/plugins/system-events "System Events") page, or the [exhaustive list in the code](http://svn.modxcms.com/svn/tattoo/tattoo/branches/2.0/_build/data/transport.core.events.php).

Some events are model-centric: they run from within the `mod*` classes, so they fire wherever the call originates — even when a third-party Extra changes the object, for example when it creates a user. Typical model-centric events:

- `On*Save`
- `On*BeforeSave`
- `On*Remove`
- `On*BeforeRemove`
