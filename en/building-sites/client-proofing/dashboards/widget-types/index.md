---
title: "Widget Types"
description: "The types of Dashboard Widget in MODX and the value each of them is stored with."
---

A Dashboard Widget holds its content in one of four types. The type is stored with the widget, and the value matters when you write the widget yourself.

| Type | What it does | Stored value |
| --- | --- | --- |
| [File](building-sites/client-proofing/dashboards/widget-types/file "Dashboard Widget Type - File") | Runs a file from the filesystem. | `file` |
| [Snippet](building-sites/client-proofing/dashboards/widget-types/snippet "Dashboard Widget Type - Snippet") | Runs a MODX Snippet. | `snippet` |
| [HTML](building-sites/client-proofing/dashboards/widget-types/html "Dashboard Widget Type - HTML") | Shows straight HTML. | `html` |
| [Inline PHP](building-sites/client-proofing/dashboards/widget-types/inline-php "Dashboard Widget Type - Inline PHP") | Runs PHP code, like a Snippet. | `php` |
