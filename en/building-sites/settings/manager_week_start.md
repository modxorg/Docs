**Name**: Week start  
**Type**: Number
**Default**: 0 
**Available In**: Revolution 2.2.2+

Defines the first day of the week in date pickers. Use `0` (or leave the field empty) for Sunday, `1` for Monday, `2` for Tuesday, and so on. The value is passed to Ext JS as `startDay`.
