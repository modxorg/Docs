## cache\_handler

**Name**: Caching Handler Class
**Type**: String
**Default**: xPDO\Cache\xPDOFileCache

The fully qualified class name of the cache handler. It can be set to a custom caching class you provide, or to `xPDO\Cache\xPDOMemCache` if you have memcached installed.
