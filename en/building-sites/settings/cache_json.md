**Removed in MODX 2.1.0.** The setting was replaced by [`cache_format`](building-sites/settings/cache_format), which selects how cached data is serialized.

---

**Name**: Cache JSON Data
**Type**: Yes/No
**Default**: No
**Available In**: Revolution 2.0.x only

On 2.0.x, setting this to Yes stored cached data in JSON format. It has no effect in current versions.
