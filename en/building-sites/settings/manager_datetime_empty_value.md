---
title: "manager_datetime_empty_value"
description: "Text shown in the manager when a date or time value is empty."
---

**Name**: Datetime Empty Value
**Type**: String
**Default**: `—` (em dash)

The text shown in grids and forms when a datetime field has no value. Leave it empty to show nothing at all.

The setting is read by `modManagerDateFormatter` (`core/src/Revolution/Formatter/modManagerDateFormatter.php`).
