**Removed in MODX 2.5.1.** The manager no longer ships an HTML5 cache manifest, so the setting has no effect.

---

**Name**: Use HTML5 Local Cache in Manager
**Type**: Yes/No
**Default**: No
**Available In**: Revolution 2.2.0–2.5.0 only

On 2.x, this experimental setting enabled HTML5 local caching for the manager.
