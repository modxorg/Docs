## which\_element\_editor

**Name**: Editor to use for Elements
**Type**: Richtext Combo
**Default**:

Select which RTE you would like to use when editing an Element.

**Note:** in MODX 3 this setting is installed but never read. Element and resource editors both use [`which_editor`](building-sites/settings/which_editor); changing `which_element_editor` has no effect.
