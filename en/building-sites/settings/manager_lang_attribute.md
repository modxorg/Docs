**Removed in MODX 3.0.** In MODX 3 the manager language is detected automatically and stored in the user session; users can change it on the login screen or in their profile. The HTML/XML `lang` attribute follows that language.

See [System Settings changes in 3.0](getting-started/upgrading-to-3.0/system-settings) and [Manager language](getting-started/upgrading-to-3.0/manager-language).

---

**Name**: Manager HTML and XML Language Attribute
**Type**: String
**Default**: en
**Available In**: Revolution 2.x only

On 2.x this was the language code used for the manager's HTML and XML `lang` attribute.
