## settings\_version

**Name**: Settings Version
**Type**: String
**Default**: set at install/upgrade (the current MODX version)

The current version of MODX. The value is written by the installer and updated during upgrades, for example `modx-3.2.0-pl`.

Do **not** change this value! Changing it could seriously affect your system.
