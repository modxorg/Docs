---
title: "enable_template_picker_in_tree"
description: "Open the template picker when creating a resource in the resource tree."
---

**Name**: Enable the Template Picker in Resource Trees
**Type**: Yes/No
**Default**: Yes

When enabled, creating a new resource from the resource tree opens a template picker window first, so the editor can choose the template. When disabled, MODX opens the regular create-resource page and applies the default template.

The value is read in `manager/assets/modext/widgets/resource/modx.tree.resource.js`.
