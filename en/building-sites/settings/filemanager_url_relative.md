**Removed in MODX 3.0.** The file manager is configured through [Media Sources](building-sites/media-sources) instead.

---

**Name**: Is File Manager URL Relative?
**Type**: Yes/No
**Default**: Yes
**Available In**: Revolution 2.0.0–2.x only

On 2.x this worked with [filemanager_url](building-sites/settings/filemanager_url). With No, `filemanager_url` was treated as an absolute URL. With Yes, the path was built from the MODX base URL.
