## compress\_css

**Name**: Use Compressed CSS
**Type**: Yes/No
**Default**: Yes

When this is enabled, MODX will use a compressed version of its custom CSS stylesheets (`*-min.css`). This greatly reduces load and execution time. Disable only if you are modifying core elements.
