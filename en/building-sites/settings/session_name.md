## session\_name

**Name**: Session Name
**Type**: String
**Default**: empty (PHP's own default session name)

Use this setting to customize the session name used for the sessions in MODX.

The setting exists in every install but is empty by default, so PHP uses its own session name. Only set it if you know what you are doing.
