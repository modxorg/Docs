---
title: "manager_logo"
description: "Logo shown in the manager header."
---

**Name**: Manager Logo
**Type**: String
**Default**: (empty — the site name is shown as text)

URL or path to an image shown in the manager header next to the site name. When it is empty, the header shows only the site name as a link.

The value is read by the manager layout (`manager/assets/modext/core/modx.layout.js`). The image is not resized by MODX, so use a file that fits the header height.
