## site\_unavailable\_message

**Name**: Site Unavailable Message
**Type**: String
**Default**: [[%site_unavailable_message]]

Message to show when the site is offline or if an error occurs.

This message is displayed only when [site\_status](building-sites/settings/site_status "site_status") is No **and** no [site\_unavailable\_page](building-sites/settings/site_unavailable_page) is configured. If an unavailable page is set, visitors are redirected to that page instead.
