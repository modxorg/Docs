---
title: "inherit_parent_template"
description: "Removed in MODX 2.7.0. Replaced by automatic_template_assignment."
---

**Removed in MODX 2.7.0.** It was replaced by [`automatic_template_assignment`](building-sites/settings/automatic_template_assignment), which controls how a new resource picks its template (`parent`, `sibling`, or `none`).

---

**Name**: Inherit parent template
**Type**: Yes/No
**Default**: Yes
**Available In**: Revolution 2.5.0–2.6.x only

On 2.5 and 2.6, a new resource inherited the template of its parent by default. When set to No, new resources used the default template instead.
