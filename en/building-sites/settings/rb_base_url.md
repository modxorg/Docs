**Removed in MODX 3.0.** The resource browser was replaced by Media Sources; use a [Media Source](building-sites/media-sources) to configure the URL of your files.

---

**Name**: Resource Browser Base URL
**Type**: String
**Default**:
**Available In**: Revolution 2.x only

On 2.x this was the virtual path to the resource directory used by the resource browser. It was usually generated automatically; on IIS it sometimes had to be entered manually.
