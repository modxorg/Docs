---
title: 'upload_file_exists'
description: 'The upload file exists setting allows or prevents users from uploading files with the same filename.'
---

**Name**: Check if upload file exists  
**Type**: Yes/No  
**Default**: Yes  
**Available In**: Revolution 2.8+

When enabled an error will be shown when uploading a file that already exists with the same name. When disabled, the existing file will be quietly replaced with the new file.
