## Default TV Output Type

This is the output type a TV uses until you pick another one.

A single text value is printed as it is stored. For a **Check Box** or **Listbox (Multi-Select)**, `||` is removed and the chosen values are joined with nothing between them.

## Output Properties

This type has no fields of its own.
