## String TV Output Type

This output type allows you to change the case of string output, such as upper case, lower case, sentence case, or capitalize.

## Output Properties

| Name   | Description                                                                   |
| ------ | ----------------------------------------------------------------------------- |
| Format | Change the case of the output string. Options: none, Upper Case, Lower Case, Sentence Case, Capitalize. |

## Examples

| Format           | Example Input   | Example Output |
| ---------------- | --------------- | -------------- |
| Upper Case       | hello world     | HELLO WORLD    |
| Lower Case       | Hello World     | hello world    |
| Sentence Case    | hello world     | Hello world    |
| Capitalize       | hello world     | Hello World    |
