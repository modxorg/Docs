## Rich Text TV Output Type

This output type places a textarea on the page and starts the rich text editor in it. It does not print the stored HTML as page content.

## Output Properties

| Name | Description |
| --- | --- |
| Width | Textarea width. The form starts at `100%`. |
| Height | Textarea height. The form starts at `300px`. |

If you leave **Height** empty, the textarea is 400px tall, while the form suggests 300px.
