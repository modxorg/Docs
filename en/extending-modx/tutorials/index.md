Each tutorial takes one MODX job from start to finish.

- [Developing an Extra, part 1](extending-modx/tutorials/developing-an-extra "Developing an Extra") — build the skeleton of a working Extra: Namespace, model, lexicon, Snippet.
- [Developing an Extra, part 2](extending-modx/tutorials/developing-an-extra/part-2 "Developing an Extra, part 2") — the Manager page: controller, grid with search and inline editing, create and update forms.
- [Developing an Extra, part 3](extending-modx/tutorials/developing-an-extra/part-3 "Developing an Extra, part 3") — the build script that packages it all into a Transport Package.
- [Using Custom Database Tables](extending-modx/tutorials/using-custom-database-tables "Using Custom Database Tables") — describe your own tables in an xPDO schema, generate the model, create the tables, read and write records.
- [Custom Fields in the Manager](extending-modx/tutorials/custom-manager-fields "Custom Fields in the Manager") — add your own field to a Manager form with a Plugin.
