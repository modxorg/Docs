Each tutorial takes one MODX job from start to finish.

- [Developing an Extra](extending-modx/tutorials/developing-an-extra "Developing an Extra") — build a working Extra: Namespace, lexicon, Manager page, grid, form, and the transport package that installs it.
  - [Part 1](extending-modx/tutorials/developing-an-extra "Developing an Extra") — the skeleton.
  - [Part 2](extending-modx/tutorials/developing-an-extra/part-2 "Developing an Extra, part 2") — the Manager page: grid, create form, inline editing.
  - [Part 3](extending-modx/tutorials/developing-an-extra/part-3 "Developing an Extra, part 3") — the build script that packages it.
- [Using Custom Database Tables](extending-modx/tutorials/using-custom-database-tables "Using Custom Database Tables") — describe your own tables in an xPDO schema, generate the model, create the tables, read and write records.
- [Custom Fields in the Manager](extending-modx/tutorials/custom-manager-fields "Custom Fields in the Manager") — add your own field to a Manager form with a Plugin.
