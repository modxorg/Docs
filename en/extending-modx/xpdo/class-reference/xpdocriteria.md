`xPDO\Om\xPDOCriteria` is the base criteria class that holds a SQL string and its bindings. `xPDOQuery` extends it, and it is the type returned by [xPDO.getCriteria()](extending-modx/xpdo/class-reference/xpdo/xpdo.getcriteria "xPDO.getCriteria") when a class defines predefined criteria.
