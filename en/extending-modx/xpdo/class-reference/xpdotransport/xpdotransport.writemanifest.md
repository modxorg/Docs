## xPDOTransport::writeManifest

Writes the transport manifest (`manifest.php`) that records the package signature, version, and the vehicles and artifacts it contains.

## Syntax

``` php
boolean writeManifest ()
```

## Example

``` php
$transport->writeManifest();
```
