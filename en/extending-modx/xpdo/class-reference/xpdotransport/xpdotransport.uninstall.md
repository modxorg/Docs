## xPDOTransport::uninstall

Uninstall vehicles in the package from the sponsor xPDO instance.

## Syntax

``` php
boolean uninstall ([array $options = array ()])
```

## Example

Uninstall this transport package:

``` php
$transport->uninstall();
```
