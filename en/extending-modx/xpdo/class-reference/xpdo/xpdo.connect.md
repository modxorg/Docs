## xPDO::connect

Creates a PDO database connection for use by xPDO. Returns true if the connection was created successfully.

## Syntax

``` php
boolean connect ([array $driverOptions = array ()], [array $options = array ()])
```

## Example

``` php
$xpdo->connect();
```
