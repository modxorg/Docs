## xPDO::getLogLevel

Returns the current log level of the xPDO instance, as an integer constant (for example `xPDO::LOG_LEVEL_INFO`).

## Syntax

``` php
integer getLogLevel ()
```

## Example

``` php
$level = $xpdo->getLogLevel();
```
