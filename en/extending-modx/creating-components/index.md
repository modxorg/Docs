This course walks through building a real MODX component from scratch: a mailing-list extra ([Sendex](https://github.com/bezumkin/Sendex) by [Vasily Naumkin](https://github.com/bezumkin)), which we will then publish for the whole MODX community.

Approximate plan of the first course:

- [Workplace setup: MODXCloud and PhpStorm](extending-modx/creating-components/customize-the-workplace)
- [Component structure: what `assets`, `core` and `_build` are for](extending-modx/creating-components/component-structure)
- [Git basics and the first commit on GitHub](extending-modx/creating-components/git-basics)
- [Design the logic; define the schema and database model](extending-modx/creating-components/work-logic)
- [Build and install the first alpha package](extending-modx/creating-components/package-build)
- Admin UI on ExtJS: mailing groups and subscribers.
- Admin UI on ExtJS: newsletters bound to a group.
- Test the interface; distribute the package.
- Front end: a snippet that shows the user's available subscriptions.
- Front end: subscribe and unsubscribe.
- Testing, final package build.

The list is a draft — we are writing a new component, not dissecting an existing one, so expect it to change.

[Download PhpStorm](http://www.jetbrains.com/phpstorm/download/) now: the 30-day trial covers the whole course, and all examples target this IDE.

Also decide where you will develop: a local machine, a virtual machine or hosting. A [free MODXCloud account](https://modxcloud.com/signup/lab-account.html) is one option.
