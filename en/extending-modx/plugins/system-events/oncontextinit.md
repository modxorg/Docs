## Event: OnContextInit

Fires after a Context is successfully initialized.

- Service: 1 - Parser Service Events
- Group: Contexts

## Event Parameters

| Name       | Description                                         |
| ---------- | --------------------------------------------------- |
| contextKey | The key of the Context that was initialized.        |
| options    | An array of options used to initialize the Context. |
