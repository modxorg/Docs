## Event: OnMediaSourceGetProperties

Fires after the properties of a Media Source are collected, allowing them to be manipulated.

- Service: 1 - Parser Service Events
- Group: Media Sources

## Event Parameters

| Name       | Description                                                     |
| ---------- | --------------------------------------------------------------- |
| properties | An array of the Media Source properties.                        |
