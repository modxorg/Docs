## Event: OnPackageRemove

Fires after a package is removed or purged via the package manager.

- Service: 2 - Manager Access Events
- Group: Package Manager

## Event Parameters

| Name    | Description                                                       |
| ------- | ----------------------------------------------------------------- |
| package | A reference to the modTransportPackage instance that was removed. |
