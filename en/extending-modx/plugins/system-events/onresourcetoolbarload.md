## Event: OnResourceToolbarLoad

Fires when the Resource tree toolbar is loaded in the manager, allowing plugins to modify the toolbar items.

- Service: 1 - Parser Service Events
- Group: Resources

## Event Parameters

| Name  | Description                                                 |
| ----- | ----------------------------------------------------------- |
| items | An array of toolbar items, passed by reference.             |
