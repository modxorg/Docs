## Event: OnTVInputRenderList

Fires while the list of TV input render directories is collected, in `modTemplateVar::getRenderDirectories()` and in the `GetInputs` processor.

- Service: 1 - Parser Service Events
- Group: Template Variables

## Event Parameters

| Name    | Description                                        |
| ------- | -------------------------------------------------- |
| context | The context key the directories are collected for. |
