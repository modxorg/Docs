## Event: OnTVOutputRenderList

Fires while the list of TV output render directories is collected, in `modTemplateVar::getRenderDirectories()` and in the `GetOutputs` processor.

- Service: 1 - Parser Service Events
- Group: Template Variables

## Event Parameters

| Name    | Description                                        |
| ------- | -------------------------------------------------- |
| context | The context key the directories are collected for. |
