## Event: OnResourceCacheUpdate

Fires after a Resource's cached page is cleared.

- Service: 1 - Parser Service Events
- Group: Resources

## Event Parameters

| Name | Description                             |
| ---- | --------------------------------------- |
| id   | The ID of the Resource whose cache was cleared. |
