## Event: OnElementNotFound

Fires when the parser cannot find an element while processing a tag in the content.

- Service: 1 - Parser Service Events
- Group: System

## Event Parameters

| Name  | Description                                                      |
| ----- | ---------------------------------------------------------------- |
| class | A reference to the modElement derivative class it tried to load. |
| name  | The name of the element/tag                                      |
