## Event: OnPluginEventBeforeRemove

Fires right before a Plugin is disassociated from an event.

- Service: 1 - Parser Service Events
- Group: Plugin Events

## Event Parameters

| Name        | Description                                             |
| ----------- | ------------------------------------------------------- |
| pluginEvent | A reference to the modPluginEvent object.               |
| ancestors   | An array of ancestors for the remove cascade operation. |
