## Event: OnTVOutputRenderPropertiesList

Fires while the TV output render property processors collect the directories holding render property definition files, so Plugins can add their own directories.

- Service: 1 - Parser Service Events
- Group: Template Variables

## Event Parameters

| Name    | Description                                        |
| ------- | -------------------------------------------------- |
| context | The context key the directories are collected for. |
