## Event: OnResourceTVFormPrerender

Fires before the Template Variables tab is rendered in the Resource editor (both when creating and editing a Resource).

- Service: 1 - Parser Service Events
- Group: Resources

## Event Parameters

| Name     | Description                          |
| -------- | ------------------------------------ |
| resource | The ID of the Resource being edited. |
